这周一直在东北玩，参加皮划艇比赛，今晚和小伙伴视频了45分钟，讲了很多东西，但我感觉她听不进去，也很难消化，就把其中的几条记下来，留给未来的自己，看看自己半年或一年后能消化几成。 \
\
 一，外柔内刚 \
 小伙伴讲到自己车被撞对方全责之后，保险定损的时候不够强硬，被定损员加了很多模棱两可的东西，导致修完车理赔遇到麻烦。 \
 然后我想到前两天看《长安十二时辰》里面的一段话： \
 背景就不多交代了，  何孚说：“ \
 “  我六岁失怙，孤身流浪千里，才学会了该装痴处则装痴，方能达成心愿。 \
 似你这等，锋芒过于外露，以为懂得天地大道，就事事皆在掌控。其实呢，不过是未经世事，小儿痴语罢了。不然你的靖安司呢？ \
 阿爷说，  外柔内柔，人辱之，外刚内刚，人毁之，外刚内柔，人轻之，唯有外柔内刚方成大器。

” \
 最后一句我加粗了，我觉得这句概括的既简洁又明确。剧中说这句话的人物原型是贺知章，86岁，在朝廷混了几十年，三朝元老。政治上的修养很高，几句话就概括了精髓。 \
 我觉得小伙伴外柔内柔，所以到处被人欺负，出险被定损员欺负，工作上被上级和同事欺负，生活中也搞不定很多事情的原因还是太软，宁愿在内心和天天回家吐槽，也不敢当面怼回去，我每天耳朵都听出茧子了，劝了半天，一点用也没有。 \
 反倒我自己，还是过于年轻气盛，外刚，不懂得退后一步，也搞砸不少事情。（不举例了） \
 外刚内柔更是没有用，身边这种人比较少，可能也是我不愿意和这样人一起玩吧。 \
 愿我们都能成为外柔内刚的大器之才~~！ \
\
 二，思考并行动 \
 具体话题的源起就不说了，反正就是知乎上看了帖子，大意是我们为什么会连续错过比特币，买房，炒股牛市等很多很多发财的机会。文中的结论是大部分人不愿意思考，头脑长在别人头上(比如天天问股评价某某股能不能买的人)，不仅自己不动脑，也会把风险和失败都归咎到别人头上(都是xx推荐，害得我亏钱)。即使过了思考着关，行动也卡住了剩下大部分人，比如比特币，很多人即使了解了比特币是什么东西，也比较相信，但买币比较麻烦，还是卡住了很多人。（原文大概这个意思，所以我们一直在错失发财的机会） \
\
 然后在这个问题上，我批判了小伙伴不愿意思考的几个地方， \
 比如我们一起约好每天听某门《得到》的课程，晚上一起讨论一下课后习题，小伙伴就不怎么思考老师提出的问题，几天之后每天听课程也无法坚持下来。 \
 比如需要动脑或者烧脑的剧小伙伴总是喊看不懂，最近反而迷恋起完全不用动大脑的泰剧。 \
 其他的比如就省略了，都是一些肤浅的东西。 \
\
 反观我自己，感觉在思考上做得还行，但是这两年行动力下降得太多了，几年前敢想敢做的事迹已经越来越少，很多事我想了很久，然后现在只有做了一点或者一点没做，太遗憾了。 \
\
 三，好得环境要珍惜 \
 这两天参加皮划艇比赛，技术总监给大家上了半小时的进阶技术科，大家都说好。很多人都说以前学得都不对路，浪费了很多精力，走了很多弯路，感叹自己被耽误了，早点遇到名师可能自己会更强。 \
 我设想了一下，如果我现在还在苏州，我可能会羡慕杭州的水上运动环境，有很多厉害的教练，比如这里的皮划艇徐教练，比如很多厉害的基层游泳教练。苏州城市等级低一点（不是省会），所以体育/文化/教育资源会落后什么的。 \
 但是，我现在在杭州生活啊，这个教练我认识啊，我去过他的俱乐部啊，他的俱乐部离我家不算远（9km），离我公司更近（4km），对于杭州的城市规模来讲，已经很近很近了，比较我从西湖区的家去西湖旁的苹果店修手机还要17公里路程呢。 \
 然后我为什么没在这个教练的俱乐部学习呢？嫌远，嫌贵，还没下决心练好皮划艇吧。事实证明嫌远嫌贵都是伪命题，其实不远，而且年费会员很便宜，只要我想学愿意吃苦。所以啊，还是决心不够。都是自己的问题，客观环境真得已经很好很好了！ \
\
