今天是2019-08-25 周日，随便写点东西 \
\
 早上大约八点醒，十点起。最近一个月睡眠质量下降了，一般都按照八小时睡眠定闹钟，以前都是睡到闹钟响再醒，现在都是闹钟响之前一两个小时就醒了，然后翻来覆去，听听广播什么的，就是睡不着，也不想起床，难受至极。 \
\
 早上10:30-12:00做了leetcode的比赛151. 最近常在leetcode上练手，感觉对自己的写代码技能提升挺快的，快速实现，系统库里常用的数据结构玩得越来越熟了。leetcode的题目相比oj上acm的题目来说，更简单，不用考虑输入输出，题意也不绕弯，基本都是裸得操作，练习起来很容易上手，一场比赛1.5h，也节约时间，出错了会给出错误用例什么的，不像acm题一样会卡很久。总之是性价比很高的刷题地点。 \
 另外现在用python3刷题，帮助我很快学习了py3的用法，每场比赛之后看看大牛们的py代码，真是优雅漂亮啊！ \
 希望不久的将来能用js,go刷题，学习新的语言。 \
\
 12:00-13:30 一边吃饭，一边看vlog。先看了《翠西》，后来又看了小伙伴推荐的《你好，竹子》等好几个up主的东西。感觉自己还是喜欢有脑子的博主，有些好看但是没营养的完全看不下去。当然自己也很想做vlog，感觉自己现在是有趣的生活有了，摄影器材有了，但是策划/拍摄/剪辑一窍不通，还有很长的路要走啊，希望年底前能剪一两个像样的vlog出来。 \
 一个小伙伴最近也开始剪vlog了，以生活和美食为主，虽然没有旁白，不是很好看，但我每次都第一时间回复和鼓励，有勇气尝试的人都很了不起，值的被鼓励~ \
\
 13:30-15:30 看书，最近对老共秘史有点兴趣，看了家里的书橱，还有有几本的有料的书的，今天开始看前美国财长鲍威尔的《与中国打交道》，还没看到太多的料，当然这本书更主要的是对经济改革的建议，政治涉猎应该不多。 \
\
\
 15:30 -16:00 开始写这篇日志，电脑很卡，处理了一会儿。窗外下雨了，最近特别懒，运动基本减到零，需要一个重启的机遇啊，比如中签杭马？比如报个在杭州的50 or 100km越野比赛？ \
\
