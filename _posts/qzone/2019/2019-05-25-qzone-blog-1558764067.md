去年下半年开始几乎就没报任何体育赛事了，为数不多的几个也是不用训练，直接参与就好了。 \
\
 最近报了6-23宁波梅山湾的游泳马拉松13.5km的比赛，6.5h关门，难度非常大，以我现在的状态，不训练根本不能完赛。 \
\
 从这里开始记录备战的过程： \
\
 5-12 周日 甘玲水库，500m 今年第一次下水，没有同伴，不敢游太远，只在岸边扑腾了500米就起水了，膀子非常酸，抬不起来。 \
\
 5-14 周二 西湖区文体中心，1200m。四月份刚开业的游泳池，50m \* 25m 四个2.2m的深水区泳道，非常适合训练，只游了1200米，膀子依旧很酸，肌肉还没适应，划水完全划不动。 \
\
 5-18 周六 龙坞龙尾巴水库，1700m，骑车去和朋友们一起玩，水质很好。看到一个女孩带着脚蹼游得很快，我家里的脚蹼找不到了，赶紧买了一个新的，带脚蹼先把水感找到。 \
\
 5-21 周二，西湖区文体中心 1500m。换了新的近视镀膜泳镜，一点不起雾，很好，万能的淘宝，不到30块钱。 \
\
 5-22 周三，西湖区文体中心 2100m，500\*3+50\*2。铁三心率带换了电池，可以了解自己的心率的，猛冲之后心脏扑通扑通直跳也才155左右，不用担心心跳过速身体吃不消啦。 连游了两天，两边腋下磨烂了，疼痛不已，晚上在家直接用剃须刀把腋毛都剃光了，结果晚上还是因为腋下疼醒了，起来涂抹了一些芦荟胶。 \
\
 5-24 周五，西湖区文体中心，1600m， 500\*3+50\*2，最后不带脚蹼50自能到1m的，恢复得还算不错吧，去年最快的时候好像也就50s左右吧。 \
\
 下周计划： \
 周日参加环法诸暨自行车赛，晚上有空的话游泳排酸。 \
 下周5/27-6/2争取天天游泳，最不济也要保证3次吧，距离可以适当加长，2000-2500左右，一个半小时应该够了。周末参加皮划艇比赛。 \
 6/3-6/9争取保持每次3000左右。周末去水库拉个长距离，6-8km左右，带上能量胶，摸底。 \
 6/10-6/16 赛前冲刺，每次3000左右 \
 6/17-6/23 赛前减量，恢复体力。6-23比赛日，争取关门前完赛~！
