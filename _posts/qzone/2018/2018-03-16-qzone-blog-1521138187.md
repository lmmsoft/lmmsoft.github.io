28岁的最后一天，其实不算太成功哎 \
\
 周四，白天上班，可是毫无精神，原计划上午写专利文档，下午重构代码+周会，晚上跑步的。结果上午只看了一些别人的专利文档，了解了专利该怎么写，午饭后也没散步，直接回办公室了，本应该看看技术书籍的，结果聊聊微信，水群和朋友圈，也就混过去了。下午写了一会儿专利文档，但是没完全写完，中间断断续续还逛了不短时间的电商，多抓鱼买了基本二手书，淘宝买了IC卡的卡贴，顺便用安卓手机的mafare classic tool把两张门禁卡的信息发给了卖家，卖家帮忙写卡，此外还逛过京东，只是没下单而已。晚上本来要运动，连晚饭都没吃，结果继续在淘宝和京东上逛，研究了一晚群晖nas，专利弄到很晚才写完，到家已经十点半了。。。 \
\
 最近日子过得稀里糊涂，工作积极性不算太高，产出也不能让所有人满意；借了一大堆书没看；下个月有大铁，训练强度一直没跟上；三月下旬计划中的旅行也取消了；后面还有一大堆事等着去做。。。 \
\
 这两年自己的主观能动性下降很多，精力与生产力也大不如前，那种说干就干的行动力好像没有了。拖延的事情，签下的债务越来越多，比如2017年的年终总结还没写，之前计划的对定居苏州的四年半的总结也没有，时间都哪里去了呢？ \
\
 最近看了电影《三块广告牌》，看的时候觉得一般，回味起来却有很多角度值得玩味。 \
![图片](/images/qzone/a34feaea1c3bf6b13dee0fa8.png)\
\
 女主实在太强了，一点不怂，就是干，想尽一切办法，不惜与所有人做对，就是要为女儿的案件讨个说法。 \
 我自己好像已经丢掉了很多这样的热血，变得无所谓，逐渐迈向娱乐至死的边缘，陷入阶级陷阱~ \
\
 从搬家来杭州之后，我就对生活状态很不满意，似乎又没有办法改变这一切。现在把宝全部押在搬家上面，希望能重新开始，过上自己喜欢的生活，祝愿我能成功~（好像这是我29岁的第一个生日愿望）
