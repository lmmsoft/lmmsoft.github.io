上篇日志是2018-09-03写的，转眼间三个多月了，变化很大，主要是以下两点 \
\
 0. 换工作，11-12入职杭州美登科技，开始做全栈工程师 \
 1. 结婚，11-19在杭州办了女方这边的婚礼 \
\
 之前几年都在做安卓开发，说不上很喜欢，只能说是干一行爱一行吧，技术上没有钻得很深，有点混日子的感觉。 \
\
 今年换工作的时候没做好准备，再加上"资本寒冬"，找工作也不是太顺利，手上的offer都有自己不太满意的地方。 \
\
 最后"听从内心"，放弃了家里人觉得很“理想”的offer，降薪加入现在的公司，并从零开始，改行做全栈工程师，技术栈主要是 JS (knockout + React) + Python(Flask)。 \
\
 现公司算是个小而美的团队，身边的工程师都挺靠谱，几个业务线的架构师技术很NB，公司现金流稳定，除了给的钱和预期差距较大，其他倒是没太多不满意的地方。 \
\
 工作刚好一个月，虽然工作时间很弹性（朝九晚六），但是业余时间要逼迫自己学很多新的技术，压力还是很大的。 \
\
 最近在追《奇葩说》第五季，很粉詹青云，看了些关于她的报道，在港中文辩论队的时候，经过了很严格的训练，大量阅读，大量思考，大量实战，终于练就成了辩论冠军。想想我自己，也应该用相似的方法，多看技术文档，思考，并且多写代码实战。常把自己放到一些不是太舒适的区域，锤炼自己的能力。 \
\
 最近在做2019年的计划，有一条就是工作之外，用工作中的技术，写点自己喜欢，有趣的程序。大概曾经在13年/14年的时候，我的月度计划就有过这样的内容，可惜后来就荒废了。后来嘛，注意力转移到旅游和运动上去了，然后事业发展就大大停滞了~ 19年得好好训练自己，要不然房贷都要还不起了~ \
\
 至于结婚，有空再补当日的情景吧~
