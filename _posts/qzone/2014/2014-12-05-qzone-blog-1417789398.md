 地点：办公室 \
 人物：男A刚走，偌大的办公室只剩男D一个人 \
\
 393写了最近项目的一些情况，这里做点更新，再加点大家的喜怒哀愁，写出来舒服一点，反正同事都看不见这里。 \
\
 旅行回来一周，产品也上线一周，项目上也有了不少变化。 \
 D负责的模块上线后在网上被用户吐槽，于是第二天代码就被紧急注释掉了，发了一个新的更新。 \
\
 D本周遇到的最大挑战，就是小老板把scrum时间从下午两点改到上午10:30，迟到的请大家吃饭。而D每天11点之后上班，明眼人都知道这条规定是针对谁的。果然，周五D又迟到了，一番不愉快的争执之后，D还是决定请大家吃饭，给小老板个台阶下，ABC都用不去吃这种屁股投票的方式，支持了一下D。 \
\
 唯一的女孩子，E，因为受不了巨大的压力，决定换组，这周会做一些收尾的工作，下周一去新老板那里报到。 我公司最近出现的一些支持自由换组的政策还是不错的，能让大家迅速从不喜欢的项目中解脱出来，也能帮公司留住一些人，毕竟这些干得不开心的人能力都不差，跳槽出去的话，对公司都是损失。对员工来说，好处是不用太过忍耐，坏处是之前几个月的工作白干了。 \
\
 A的工作顺风，最大的忧愁来源于妹子，妹子在老家杭州工作，杭州的IT氛围比苏州好，所以妹子一直催促A回家工作，而A在组里顺风顺水，发展机会挺好，妹子和个人发展之间，压力不小。 \
\
 B比较得意，新feature里面，他的模块效果最好，老大也最看中这一块，规划中的新项目，他也抢到了最肥的肉，得意洋洋。 \
\
 C其实是个内向的小男生 ，但这周勇于对小老板说，不想own xx feature，的确出乎大家意料之外，小老板也比较郁闷，只能说：“我无所谓，我来own吧，我不在乎流量，只要大家都开心就行” \
\
 小老板估计也挺郁闷，初来乍到，没想到大家是士气都不高，唯一的姑娘两周就跑了，想提升士气做的一些决策，比如例会提到上午，反而弄得更大家更不开心，团队不好带啊，尤其是面对一群都很有想法的小伙子。 \
