 有时候我也在想，为什么以前在扣扣空间能写这么多字，换个地方什么都写不出来？ \
 直到最近接触“自由写作” 的概念，才有了些答案。 \
 "自由写作"追求的是  思绪的流淌  ，只要把想到的东西都转化为文字就可以了，  并不在乎文章的思路，结构，那是后期修改的工作  。 \
 对我来说，打字比手写更迅速，更能保持思维的一致性；网页里码字比写过工具更有压力（担心自动保存不靠谱，想早点关掉网页）；而且在空间写流水账一般都在深夜，疲劳至极，需要尽快写完睡觉，所以精神比较集中，噼里啪啦就写下来了，不知不觉就写了很多。 \
\
 写其他东西时，比如博客，总想写篇比较成熟的，会不时回看，会不停修改，所以速度总是上不去，拖延很多，产量很差，  久而久之，也就写不下去了。 \
\
 这篇是自由写作，本扣扣空间所有的文章几乎都是自由写作，可惜写完自己都不愿意再看一遍，错字不改，离题了也不管，可读性很差，扔在那里不管，时间久了，大家看得很费劲，我自己也找不回来了。 \
 反观那些认真写，改过好几次的东西，质量真能让自己满意，对外展示的时候，效果也很不错，比如最近几年的年终总结，认真写一篇  ，够用一整年。 \
\
 果然，撤了半天“自由写作”，还没进入主题，思路果然TMD自由。 \
\
 1 \
 最近几个月都在用OneNote管理自己的日程。 \
 每天会在表格里填写一件大事，三件中事，五件小事。 \
\
 大事定位在一小时以上，比如看国家德比，吃大餐。 \
 中事半小时左右，比尔整理旅行账单，整理拍的照片。 \
 小事一般用于提醒自己做些生活琐事，比如倒垃圾，还信用卡。 \
\
 也不是每天都会填满，空空如也我会认为这是失败的一天，最后画个叉，全部做完我会认为这是成功的一天，后面画几颗星。 \
\
 养成这个习惯后，每天很大一块精力就用在刷to do list上了，画星的快乐是短暂的，大部分时候都带着叉叉睡去，并不安稳。 \
\
 2 \
 日程表的后面一页是“欲望清单”，一个更可怕的东西。 \
\
 要去的地方，要学的技能，要做的事情。。。全是欲望，大部分前面都没有表示完成的小钩钩。 \
\
 早起看的时候还有点东西，现在越看越累，什么都不想做。 \
\
 最大的欲望已经变成——“好好得睡一觉”。 \
\
 3 \
 搬进新家三个月了，对我的生活有什么影响呢？ \
\
 父母打来的电话里，多了：“要收拾房子！每周要打扫一次卫生！东西不能乱丢！衣服要经常洗！院子有空也可以清理一下！有空把次卧的那堆物品收拾一下！等我们来了再帮你修窗户，另外近光灯也要修一下，晚上开车非常危险！” \
\
 经常我会想，房子给我带来的幸福多一点呢？还是负担多一点呢？我和房子是什么关系呢？ \
\
 是屋子给我提供服务呢？还是我替它打工？ \
 比如 \
 那个从来不趴的书桌，为什么要每周擦灰呢？ \
 次卧那堆物品，我都几个月没用了，为什么还要整理呢？放那里不就行了么，又不碍事，要用的时候直接拿就好了。 \
\
 整理当然是提高生产力的事情，但为了整理而整理不是。 \
 新家提供了更宽敞的【起居空间】【创意空间】【生产环境】，而不是别人眼里干净，好看，高大上。 \
\
 前几天看了个极简主义的小屋设计，好喜欢，这两天也开始把家里往简单的方向改造，比如堆砌柜子，留出更多行走空间。藏起用不到的物品，眼不见心不烦。 \
\
 4 \
 这几周尤其得累，白天工作做不完，压力很大，一直对做的项目和自己发展方向之间的关系有些怀疑，不知道未来的方向在哪里。 \
 什么是放之四海皆准的程序猿，哪些行为是在外企里温水煮青蛙？ \
\
 有时候会想起大学里的一些经历，各种错误的尝试让我迷惘了几年，然后一个无比正确的internship offer又把我一路带到今天。 \
\
 然后就在想，  到底怎么做，才不辜负这段青春？  或者，从来都别无选择，只能被生活推着走，漂到哪，就过什么样的日子。 \
\
 永远有做不完的事，即使把今天的做完，之前积压也赫然在了，压得人喘不过气来，似乎永远也没有完成的那一天。 \
\
 5 \
 我不愿被欲望，被生活，被工作绑架，那么，然后呢？问题来了~
