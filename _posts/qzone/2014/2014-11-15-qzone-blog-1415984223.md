【最近的项目】 \
 1. 最近工作非常累，太上皇依旧威严，小老板也挺push，老大把四周的任务缩成三周，小老板把三周压成两周，最后大家加班加点，居然完成了！ \
 2. 这个项目一共旧人，太上皇锤炼听政，小老板负责一切，剩下四个干活的男生，三个女生，有趣的是女生都在北京，男的全在苏州。 \
 3. 东西虽然赶在今天做完，但下周事情还是不是，修bug，刷UT,另外AT要不要搞都悬而未决，还有修技术难关尚未攻克，挺烦人的。 \
 4. 众生相： \
 a. 太上皇依旧威严 \
 b. 小老板初来乍到，动力十足，朝九晚十一，周末都在加班，虽然鸡血十足，但也暗暗喊苦，每天下午三四点种的时候头晕目眩，喊我们去打乒乓球放松一下。。。 \
 c. 男A，能力最强，做的事也最难，向来很拼，两周的活一周就搞定了，然后开分基，帮我们几个 \
 d. 男B，前项目一哥，有经验，有能力，但不愿意帮助大家，自己按时工作，做完走人 \
 e. 男C，态度端正，座位和大家比较远，所以基本在自己座位上单打独斗，勤勤恳恳，深受小老板好评 \
 f. 男D，能力有限，心浮气躁，不Push不干活，小老板最不放心的绝色。做的是最边缘，最简单的模块，是众人看笑话的角色，最后勉勉强强赶在截止日期把代码完成，逃过一劫

g. 女E，唯一一个正式干活的女孩子，异地办公更为不易，抄一段她今晚九点的朋友圈吧：  **“下班回家的路上，要猝死的感觉，坑爹的两周终于过去了，周末要好好养养我的已经肿了的的都是血丝的眼”** \
 h. 女FG，都是vender,没什么事，呵呵~ \
 ps: 男D是我 \
\

【乱想】

1. 机会转瞬即逝，能抓住就试一下，能争取就别放弃——写给犹豫不决的自己

2. 最近找我聊offer的不少，真是IT行业蓬勃发展的一年，我能看到很多机会，却一直没鼓足勇气尝试——写给被这里小资生活困住的自己

3. 无所不能真得太难了，其实抓紧一段时间，专攻一小块，或许后面会舒服很多——写给爱好太多的自己

\

 【下面的计划】

0. 下面再拼一周，按时完成工作，争取不被大家笑话

1. 然后开始度假，斯里兰卡+新加坡。记得去年十一月从三亚度假回来写的日志里，就提到特别需要这次的休息，实在是太累了，不是闲得慌要出去玩，真是需要远离工作，好好思考未来。

2. 回来之后就十二月了，我准备定位为【整理月】，今年做了好多事，去了好多地方都没来得及总结，再不整理就没机会了，2014算是生命里又一个精彩的年份，我要好好地记录下来。

3. 随后，新年的钟声即将敲响，在哪里跨年呢？之前不是在家就是在学校，这次，我想换个地方。比如东海之滨？又比如泰山之巅？我想赋予2015的开始一些意义，然后，超越2014里的，让我又爱又恨的自己。
