好久没在空间写日志啦，好怀念去年此时每天对着屏幕怒码千字  流水账  的肆意的时光，一气呵成，一吐为快。 \
\
 ———————————————————— \
 起因是早上舅妈给我发了篇 \
 [《最美城市——六朝古都金陵】有没有你没看过的风景？》](http://mp.weixin.qq.com/s?__biz=MjM5MTQ5MjQ3Mg==&amp;mid=200109746&amp;idx=1&amp;sn=78ba4717aafb774f683e2f457cd337ca&amp;scene=1#rd) \

（点开可以用手机看）其实就是一堆南京的风景照。 \
\
 然后我开始对比现在生活的城市和南京的不同。 \
\
 路旁的绿化哪儿都可以修，但参天的梧桐大道需要时间的积累； \
 城市内外或多或少都会有些山水，配上寺庙陵园等人文元素才更有味道； \
 到处都在翻新老宅老巷，但曾经住在这里的人，留下的风流往事，历久弥新，永不湮灭~ \
\
 除了几个教堂，这篇日志里出现的景我全都看过的，中学之前倒没去过几个，大部分都是大学四年慢慢攒下来~  （小学在县城读，和市区隔了长江，大桥拥堵，进城不易；中学倒是在新街口，可是没那闲心和意识到处乱跑） \
\

回想高考填志愿时，最想去的三个城市:北京南京西安，最后的选择，四年的时光，倒也真没忘初心~  （本来还想宣扬大学时候在计算机机房度过了很多周末时光，后来发现，该玩的的地方差不多都跑过了，没亏待自己啊） \

出生的城市，成长的环境，对我的影响蛮大的。从这个角度来看，或许也能明白住在哪些城市会让自己开心吧~ \
\
 展开说，就是： \
 城市，我喜欢有历史气息的； \
 户外，倒是每年至少爬一座山； \
 虽然，最近三年跑海边的次数更多。 \
\
 在北京的时候，我倒是有心用周末玩些遗迹，比如骑车去卢沟桥，去八大处，跑跑野长城，周末还会跑到圆明园福海边上里面看书(插一句，我老板说他读大学时还偷偷跑到福海里面游过泳)，还真是很享受这种城市生活~ \
 来苏州后，颇有一阵子不怎么出去玩，周边的山，就是山，没有庙；城里的景点，也没太提起我的兴趣，我总说：“这些有名的园林，自然会陪各种亲友一起去，没必要自己独闯”，后来有天陪mentor夜游平江路，听曲+小吃，一下就找到了感觉，这就是我心中小桥流水的江南景象吖。 \
\
 再补充点案例： \
 在河南玩的时候，洛阳许畅中牟安阳南阳，光是这些地名就让我兴奋一阵子了。 \
 在台北玩的时候，看当地人编的杂志，每天晚上泡书店，随意得暴走小巷，乱吃各种路边摊，是另外一种我喜欢的旅游方式~ \
\
 延伸： \
 1. 我猜我不会喜欢上广州深圳， 因为离汉文化圈太远。 \
 2. 我很想去欧洲玩，那些的首都，什么伦敦、巴黎、马德里，布拉格、莫斯科。。。爱死了~ \
 3. 从这个角度说，湾区对我的吸引力下降了，东海岸好吖~ \
 4. 一分钟之前，约了lucas明年一起三国文化游，河南湖北，有机会再入个川，爽歪歪。我们约好明年就这么玩半个月~~~ \
\
 说了半天废话，一句话总结：又  知道了一件自己喜欢的事，棒极了~ \
\
