一 \
 最近生活还是不怎么正常，每天11:30到办公室，夜里面1点左右下班，荒唐！ \
\
 为了记录生活状态，并强迫自己思考，我决定每周来QZ写这样的总结。 \
\
 二 \
 其实，总结这东西，我并没有少写，比如昨晚发了  [这个](http://lmmsoft.github.io/notes/a_week_without_wechat_moments/?from=qz)  ，花了6个小时做出来，效果不错，我看到的分享大概有5人，首发三小时内，平均在线大约10人，鉴于85%用户在打开10秒之内关掉，这活跃度比我之前任何一篇博客都好。 \
\
 但是，这种总结，虽然看上去漂亮，交互也不错，但自己明白，内容挺空洞的，读的东西，内化了么？做的菜，有几个品种？回到的质量，到底有多少呢？ \
\
 三 \
 就算是技术再烂的工程师，也可以做出漂亮的工作总结（比如我哈）； \
 就算是一个即将倒闭的公司，也可以包装出漂亮的报表； \
\
 很多好看的东西，都是幻觉啊。 \
\
 四 \
 这篇的标题叫《主线》，主要觉得自己： \
 小怪打得不错，但主线剧情走得太慢； \
 短期目标完成度不低，但长期目标荒废得比较厉害。 \
\
 五 \
![图片](/images/qzone/ad23fa463b63e1ef0ee7c4d9.jpg)\
\
 说白了，就是毕业一年，啥好玩的程序都没写过。 \
 本来能给自己生活，熟悉朋友留下的创造力和价值，都被商业和市场耗掉了。 \
\
 大学时候还经常捣鼓好玩的小程序， \
 现在呢， \
 被日常工作的琐碎和无聊， \
 下班后完全不愿再碰程序， \
 只想着怎么玩， \
 如何放松比较好。 \
\
 所以， \
 还是要感谢榕姐  [@777.](http://user.qzone.qq.com/511472480/)  ， \
 虽然是我在帮你写程序， \
 而且周末两天都搞到夜里两点多， \
 但也感谢这个机会， \
 让我找到一个切入点， \
 去写点好玩的程序（上图是我抓了自己这几年所有照片里的GPS数据，然后在地图上描点）， \
 找回曾经的一些感觉。 \
\
 六 \
\
 突然发现，可以安静的在办公桌上写点程序，而不是不停地刷微博，人人； \
 突然发现，书架上P0的书籍，我都不爱看了，反倒是角落里面颇有几本有兴趣的； \
 突然发现，周末不想出去玩了，在家安静一点，把拖延了好久的事情都做掉了，也挺好的； \
\
 生活总在变化， \
 最近的一些变化，都在往好的方面发展， \
 喵喔~ \
\
 七 \
 主线是什么呢？ \
 下周再写噢，嘻嘻~
