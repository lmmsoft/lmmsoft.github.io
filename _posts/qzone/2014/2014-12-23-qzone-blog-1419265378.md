生活中有很多点滴，后来都记不住。 \
\
 比如某天，通过某种途径，知道了谁谁谁的名字，没想到，很久之后，我们竟然能一起共事，一起做很多有趣的事情。 \
\
 搞生日聚会这样的活动的时候，如果我来组织的话，最可能出现的环节，可能就是每个人说说和寿星是怎么认识的，第一印象如何，现在最想对寿星寿星说的话是什么，然后切蛋糕，如果惊喜一点，会把这一段做成视频，现场放一下，回去之后也更有纪念价值，今年kimi生日就这么弄的，视频赶时间，减得很粗糙，但回看时的感觉远比照片好。 \
\
 跑题了，其实今天想说的，是晚上发生的几件小事。 \
\
 1. 朋友圈点了赞，然后有小伙伴私聊，问我和xx是怎么认识的。人人和微博可以直接看到共同好友，也不怎么稀奇，反倒是微信只能通过好友圈共同点赞来观察，反而激发了大家的热情。我和xx一年多前就加好友了，也不知道是怎么认识的，只记得从他所在的传媒圈里，认识了很多很有趣的人，可惜好几个后来都离开媒体了，xx去了特斯拉，aa创业搞新媒体，bb似乎也跳了。。。不知不觉，这些有才华的人，都离开了大他们大学时学的新闻系，现在都和互联网沾了点边，有意思~ \
\
 2. 晚上吃饭时，右边的同事跟我说，你不知道自己在外面是什么。后来我又想起，“我现在舍友还在问我，你是不是有个叫萌萌的学妹，好像很漂亮。学弟啊，你真是给学长张脸了啊，哈哈！” \
\
 3. 最近在做总结，发现今年认识的新的小伙伴屈指可数，基本都是公司里认识的，下班之后似乎还没有太多的往来，生活圈的多样性不怎么样。以前在北京工作的时候，认识的有意思的人比现在多很多，在一起产生的有趣的连接也多很多，生活里的惊喜远超现在。这一年，所有的收获几乎都在预期了努力里出现的，而去年似乎是不是都会有意外的惊喜。 \
\
 4. 晚上在豆瓣上看个人，是我今年看的一本书的译者，跑到他主页扫荡了一圈，totally beyond expection，贴一下他的豆瓣签名： \
 blog地址：  [hanlei.name](http://hanlei.name/) \
 教过外语 \
 编过程序 \
 干过导游 \
 做过外贸 \
 Borland Delphi产品专家，微软最有价值专家 \
 喜欢暴走、照相、看电影 \
 曾经在  [CSDN.NET](http://csdn.net/)  和《程序员》杂志任总编 \
 现任21世纪新媒体CTO \
 与人合著有《网络媒体教程》，合译有《Beginning C# Objects中文版》 \
 译有《梦断代码（Dreaming in Code）》、《Elements of C# Style》和《代码整洁之道（Clean Code）》 \
 没想到这家伙无所不能啊！ \
 后来去看他的博客，前几篇居然全是在写吃！而且写得还挺好！！回想起来，我是从哪里发现他的豆瓣账号呢？从一个专门写吃的少女的关注列表里，他们互粉中！！！ \
 妈蛋，这个微软MVP程序员，不仅字写得好，而且还超级会吃！！！ \
\
 5. 前几天写贝加尔湖游记的时候，发现了个博客，是个文字，摄影俱佳的姐姐，去过的地方超级多，把我吃成真子集的样子，他也从北京坐火车到莫斯科，中间挺的站都和我很像！她也去过斯里兰卡，四姑娘山二峰，所以看她以前博文的时候，我有很强的带入感，很明显看出来她比我会玩很多，无论是线路规划能力，途中发现美景和摄影能力，回来后的文字张力，都很牛，于是就很好奇她的背景。 \
 好一番搜寻(她没有简介，只能通过细读博客，挖掘微博的方式旁敲侧击)之后，发现是个老师，在南京林业大学任教，怪不得，每年两个寒暑假，玩得真是爽！估计年龄也不小了，家里面人似乎也不着急，真好！ \
\
 6. 本来有个标题的，写岔了，就改成乱写吧。 \
 7. 本来以为一会儿就能写完，没想到花了一个多小时，中途还因为电脑高温断电，损失文字若干，真是郁闷！ \
