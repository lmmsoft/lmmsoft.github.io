1. 做了程序员之后，身体越来越差。 \
\
 2. 昨晚赶在父母到达之前到家，21:30，下班路上景观灯还亮着，本周第一次看到。 \
 晚上陪妈妈看电视（他们不在的时候，电视机从没开过） \
 和父亲彻夜卧谈（说了很多互联网与生活结合的案例，比如海淘的转运链，电商为何比淘宝送货快很多，本地互联网公司的崛起，张亚勤为什么跳槽到百度。。。告诉父亲我所在的行业是如何改变中国人的生活的） \
\
 3.早上起床，吃妈妈准备好的早餐，然后去踢球。 \
\
 10:00开球，过人，配合，技术都在，队友都主动把球传给我，说明今天踢得不错。 \
 10:20的时候，我趴在了草坪上，头晕，想吐。 \
 一开始是同事的嘘声，“明明这么快就萎了，最近不行啊。。。” \
 然后坚持了一会儿，呼吸都赶到困难，实在踢不了了，就退场，回家咯。 \
\
 4. 回家的路，和下班的差不多，大概6公里。今天是最难走的一次。  平时两个油门的轻巧  ，今天竟然头晕，发困，四肢无力，还停在路边休息了一会儿，感觉过了好久好久才到了家。 \
 到家后故作镇定，但还是没撑过中午，吃过饭就让父亲带着去医院，X光，验血。 \
 还好没大病，咽部完全增生，慢性支气管炎，吃药再加上长期的慢慢条理就可以了。 \
\
 5. 身体严重不适的情况，最近几年越来越频繁。 \
 今年有记忆的，就有三次： \
 第一是某次飞机起飞，第一次出现严重头昏+耳鸣的情况； \
 第一次是在爬雪山，高反+疲劳，度过了两天煎熬的日子，冲顶那段的痛苦，至今难忘； \
 第三次就是今天，踢着踢着就不行了，幸亏没苦撑，见势不妙就撤了，管不了嘘声了。 \
\
 6. 每年冬天都留下了最痛苦的回忆，大学时没暖气，有期末考；工作之后又了空调，工作压力却远胜大学时期~ \
 我开始讨厌季风气候了。 \
