今天是近来状态最好的一天，记录一下日常：

\

早上睡懒觉，中间醒了几次，玩手机，然后上班。

\

#上班

\

中午12点到达公司，一楼被西西姐姐看到了，大喊，明明你迟到了，明明你迟到了，我作出嘘声的动作也不听，好尴尬，赶紧逃离大厅~

\

#午饭

\

上楼之后和约好的同事吃饭，结果人家看我上午没来，和自己团队的人去吃了，郁闷。

\

因为自己组的小伙伴也全都去吃饭了，只能看聊天工具里还在线的人了，约晓朋哥， 结果他自己带饭了，约叶炜，结果他要去勾搭前台的妹子吃饭。。。好在叶炜告诉我本来带了盒全家的快餐，可以给我，对这样的“重色不轻友”的表示赞赏！

\

吃饭的时候正好还有几个熟人，聊得还挺不错，话题包括粗粮公司米多等等。

\

本来晓朋想问我有关西伯利亚大铁路的事情的，结果我把地图上坐标点展示出来之后，旅行完全抛弃到一遍，开始探讨旅行app了。。。

\

一会儿wiliam来了，我就找借口停止的旅行app的交流，去看看william的新座位。william的老板很有领导力，刚升到首席，就直接吃进了另一个开发小组，然后把自己组十个人全搬到楼下下来，迅速加入新团队，搞开发。

\

看到william前面的小妹吃饭时没锁电脑，我在想可不可以把她的代码都revert掉？后来看到屏幕上快递查询的功能，想想还是算了，不要欺负新来的妹纸啦~

\

然后去找周涛，选了个会议室1-1，研究十一行程。周涛本来要去青海湖，敦煌，额济纳的，被领队放了鸽子，于是想和我一起去四姑娘山，我正愁没人一起呢，一拍即合。迅速完成电话预约，出行，装备等探讨。

\

然后再找晓朋，发现他新ship的项目挺有意思的，而且特别快，上次见面还没这东西，这次见面都TM上线了，完爆了我公司平均速度啊！聊得正兴起，收到老板邮件，2点重要会议，只能意犹未尽得离开。

\

# 重要项目

\

重要会议时宣布下一阶段做什么。之前做了好几个月的东西被法律部门卡到了，不能ship，只能临时换项目做。大概是把以前做废的一个项目捡起来重做吧，本来这个项目还不错，20M用户，后来被360杀了一圈，只剩0.1M用户了。。。现在要把它重新完善，还是有很多事可以做的，也能学不少东西。国庆前几天大家都好好想想，国庆之后再开始干活。

\

开完会，快三点了，处理了一堆杂事，比如查查年终奖发了多少（少得可怜，伤心）/域名续费/吃零食/拙政园3D拼图，等等。

\

# 旅行

\

然后周涛告诉我行程确定，一起定行程和机票，花了若干时间，国庆的机票太贵了，不好定啊~~~

\

具体行程如下：

09-30 苏州到虹桥，虹桥飞成都

10-07 成都到重庆

10-08 重庆飞虹桥，虹桥回苏州

\

其中虹桥飞成都的单程机票1500多，真坑爹！

\

\

# 晚饭

\

晚饭和周涛吃的，主要研讨装备的事，比如帐篷，防潮垫，冲锋衣，等等，约好明天下午去户外店瞧瞧。

\

# 运动

\

回公司后，先去三楼打乒乓球，自动发球机真帅！

\

然后去四楼打桌球，新买的球台挺不错的~

\

# 聊项目

\

运动结束，8点多，去隔壁client team，聊聊他们几个项目的进展，看看有没有合作的机会。他们把某个项目的vender全砍了，预算全部用来做推广，真是孤注一掷拼了啊~

\

然后回到办公室，和尹欣杰打了个电话，主要是表达愧疚，昨天让他调研江浙的徒步线路，最后还是去了四川，把他抛弃了，怪不好意思的。

\

然后发现老板居然回来加班了，9点多啦，不科学。后来看邮件，原来是明天就回老家，还有点事要收尾。后来进去聊了一会儿，问了些困扰好几天的疑惑，有的问题大家都没有答案，还需要产品做出来后靠市场的检验，我们公司太注意安全了，比如隐私数据不能随便搜集，导致在做产品规划的时候，不能用第一线的数据进行分析，挺郁闷的。

\

# 夜战

\

老板10点多回家，其他同事都走光了，办公室只剩我，熟悉的节奏啊，果断开电脑外放听歌，然后把又一堆小杂事做完。比如买书，请10-08的年假，等等。

\

后来去chrome store里面搜微软的产品，结果大部分都是山寨的，比如有两个"必应词典"，都不是我们做，我们自己也没做。因为用户基数小，现在我们组至少要做百万以上用户级的项目，市场可能要千万，小的不值得花时间，毕竟不是创业公司，不过看到有山寨的第三方，我还是挺开心的。

\

后来夜战搞到两点多，中间还确定了明晚和后晚的行程。

\

下班，路上发现油箱空了，屁颠屁颠跑去加油，最后三点多到家，打了一会儿扣扣游戏，写完这篇日志都四点多了。

\

明天计划：下午买户外用品，晚上松鹤楼吃大餐。签证在还喊着要休学，要出家的小伙伴，现在带着漂亮的女朋友到处旅游，这两天到苏州，约明晚一起吃饭，问我有没有妹子，求带上一起。。。哎，没有，真是一把辛酸泪啊。。。

\

后天一堆人去新区吃日料，嘿嘿~

\
