1. \
 睡醒了爬起来干活，却发现事情永远做不完。。。 \
\
 蓦地已经儿童节了，虽然我的心态比较年轻，但已经好久好久没有体会到【无忧无虑】的快乐了吧~ \
\
 2. \
 之前一直以为可以 “用上半年的辛苦求职，换来下半年的幸福安逸” \
\
 下半年的确做了很多想做的事情，但完全谈不上安逸 \
\
 抱着“有些事现在不做，一辈子都不会做了”的态度，我在拼命完成很多以前没有机会做的事情，想给大学生活画个漂亮的句号 \
\
 比如出去玩，已经完成了台湾和香港的行程，但游记欠着还没动笔； \
 比如《写在毕业前》系列，已经5篇了，每篇都有几十次分享，后面还会开源图书馆插件，GPA查询几个东西，还有几个总结要写，都要花不少精力； \
 比如今天的求职经验分享，我是唯一一个做幻灯片的，30页都配上了很可爱的背景，昨晚搞到两点，反正我自己很喜欢~ \
\
\
 3. \
 赶鸭子上架，殊不知能力总有限 \
 欲望无止境， 也不知何时是个头 \
\
 4. \
 生活没有规律，身体一天天暴露出各种问题，传递着什么信号？ \
 想做的事太多，毁掉的事情也很多， 暗示着什么？ \
\
 5. \
 很多年前看过帖子  [《  曾经的你与完美的一天  》](http://hi.baidu.com/lmm333/item/3b2c47a93ae09517a9cfb7d4)  ，讲的是  多少二世被叫做贝利马拉多纳， \
\
 能获得“二世”封号的年轻人也必是天赋异秉，但套用一句流行的台词：“我猜得到开始，却猜不到结尾”， \
 事实上那些曾经被誉为巨星接班人的少年并不都尽如人  意地平步青云，有些人如流星一闪而过，有些人在盛名之下迷失彷徨，当然也有人走出光环，寻到了属于自己的天空。 \
\
 当时很受触动，小时候搞奥数获得的所有自信，在复读之前毁于一旦，至此和过去做个了了断~ \
 现在，花了整整四年时间从泥沼里走了出来，可不想再误入歧途，跌入下一个深渊~ \
\
 6. \
 沛沛说得对，我将迎来思维极速变化的三年，大脑越来越好使，极速进化~ \
 过于一年，已经有这样的感觉了 \
\
 下面两年，会在一个从未接触过的陌生里城市里度过，气候环境，和家乡很相似的~ \
 不知这一方的水土，会培育怎样的我？ \
\
 7. \
 “  每个城市都是一个社会参考系，都为人的价值观提供了一种可能。在不同的地方生活过，才会让我更清楚自己该去过什么生活  ” \
\
 我不知道苏州具体的情况，但我可以猜想她的样子~ \
 没有一线城市的浮躁，更好的空气，更低的物价，更少的应酬 \
 这都是符合我下一阶段规划的~ \
\
 上一阶段学的是生存，现在生存问题基本解决，生活的幸福程度会是新的考验~ \
\
 关于生活，我需要多一点时间， 多一点空间，再好好得想一想~ \
\
 8. \
 现在是2013-06-01 02:47 \
 夜深人静 \
 基友正在我身后熟睡 \
\
 足球赛季基本结束，熬夜的需求也没有了吧？ \
 是不是可以试着过几天规律的生活？ \
 按时起床，用餐，睡眠？ \
 列出计划，定期阅读 \
 尝试关掉电脑，断开网络，回归现实？ \
\
 真的可以试试哈， \
 今天就开始~
