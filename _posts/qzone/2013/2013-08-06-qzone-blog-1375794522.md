\
 几天人人上和一个同学的私信： \
\
 A:上次我参加的那个海选，我进了下一轮了，要80进12，我知道我肯定进不了再下一轮，那我要不要去参加啊。。。。想听听男性思维的意见。。。。

B要

B经历比结果重要

A可是那些大学生高中生啥的真心是秒杀啊

B光脚不怕穿鞋的，都过了一轮了，后面的不用太在乎结果咯 \

B要是我，就抱着玩一玩的心态咯，反正没什么损失

B不是么？

A我太怂了，还是不想去了。。要背两分钟的南京介绍英文稿子，还要唱一首英文歌，要花好多时间准备，周六就比了，好艰难。。。 \

B别呀，让暑假生活更有趣唉，同时也设定更高的目标，挑战自己，不努力，永远不知道自己的上限在哪里~ \

A萌萌姐的最后一句话戳中我的励志点啊。。。好纠结。。。我真的能力达不到，稿子背不出。。我就当自己没那个能力，认了。。。

B擦

B不行

B还有好几天呢

A(哭)(哭)

B试一试，你的对手也背不下来，就拼谁能坚持~

B第一轮不是这样就过来了么？

B加油，你可以的(赞) \
\
 A是同学，B是我。 \
 —————————————— \
 其实我最喜欢的也是这句话“  不努力，永远不知道自己的上限在哪里~  ” \
\
 曾经一度我对生活都快绝望了，觉得我不应该如此的，可是我看不到希望。 \
 曾经我看过心理医生，解决自信心失掉的问题。 \
\
 所幸，好运常伴，还是一步一步走过来了~ \
\
 然后，现在我就很像知道，自己的上限在哪里？ \
\
 我知道，二十几岁是上升的最好的时光，我现在没有家庭，甚至连女朋友都没有，也没和父母住在一起。 \
 所有的决定都是自己作出的， \
 所有的困难都要自己坚强解决（柔弱的一面可以通过萌萌的形象释放）， \
 所有的快乐都靠自己主动寻找~ \
 social，但不依赖 \
 所有的喜悦，可以在一个角落独享。 \
\
 多自在的时光啊~ \
\
 不知道这时光能持续多久，也不知道该怎么打破，就这样一天一天地随缘，也好~
