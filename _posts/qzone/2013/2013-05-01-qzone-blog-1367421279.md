除了台湾的游记其他都完成了 \
\
 换个角度就是：有时间地点限制的都搞定了，进一步说就是我的自制力太差 \
\
 每天泡在网上，其实空虚得很 \
\
 这两天在线下参加了一些活动 \
\
 昨天下午和小学同学玩，唱K，晚上逛大街，喝奶茶， 河边撒尿，看电影，吃夜宵~ \
 （小学同学，工作之后差异越来越大，话题似乎也不是很多，一边唱歌，一边玩玩手机） \
\
 今天一天和表哥表妹表嫂一起，吃饭，聊找对象，聊求职，聊减肥，逛批发市场，打游戏机WII，百家湖散步~ \
 （从小玩到到的表亲，就跟亲兄妹一样，现在表哥工作忙碌，在南京和上海直接奔波，表妹更是远在波士顿留学，大家每年相聚的机会也就这一次吧，话题不少，相互之间的关心很足，建议也都很中肯） \
\
 参加这样的活动是必要的，我不能只靠网络生活，但我在唱歌、吃饭的时候，还是有很强的刷新鲜事的欲望，虽然刷不出太多有意思的东西，吃饭的时候也一定会拍照。。。 \
\
 我近年的个人发展在走电子化道路，其实也是摸着石头过河，比如：个人云的搭建，文档电子话，重度使用社交网络等。我知道很多事有益处的，但有些其实没那么美妙，有空得好好调研并思考下，解决现有的“空虚，浮躁，碎片”等问题。 \
\
 另外我也要更多得活在线下，萌萌仅存于网络，明明应该是更精彩的生命体，现在明显反了，这样不好~ \
\
\
