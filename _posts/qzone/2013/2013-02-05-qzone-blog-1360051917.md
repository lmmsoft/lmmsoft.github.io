 ———————————————————————————————————————————— \
\
 知乎上看到一个问题： \
\
 ~~我是一个武汉大学工科的女生，但是以后想进入高盛或者进军金融，我大二会读双学位，请问我现在应该怎么准备？ \
 针对问题，把所有挖苦的回答都反对+没有帮助，我喜欢了两个：第一个是 \
 建议你先在大一的时候去旁听一下金融相关课程，确定你是否真正喜爱它。 \
 我是个理科生，我一度以为自己热爱金融经济相关，并选择了现在的大学。 \
 现在我大三，大学期间挂过三门课：微观经济学，宏观经济学，货币金融学。~~ \
\
 原谅我删掉问题，那不是主题 \
\
 —————————————————————————————————— \
\
 我最喜欢的是这个回答： \
\
 1、抓紧时间学英语。 \
 2、抓紧时间融入这个圈子，认识学金融的人。同学？朋友？老乡？学长学姐？教授？都可以吧。 \
 3、抓紧时间找个和金融相关的地方实习一下。爱好是一回事，真正严肃地做起来是另一回事。 \
 4、认真记录并思考。我真的热爱这个领域吗？我具有从事这个行业所必需的条件吗？我应该从哪个具体的职位进入这个行业？我希望取得的成就是什么？我应该如何制定计划？我还能做其他事情吗？ \
\
 我觉得这是放到任何一个行业都说得通的答案。 \
\
 回忆自己最近一年的经历 \
 我无意识走出的路基本和这个答案一样： \
\
 加各种好友=&gt;进入某个圈子=&gt; \
 找了相关实习=&gt;认识更多好友=&gt; \
 实习结束回家之后=&gt;认真记录并思考 \
\
 所谓的【英雄所见略同】^o^ \
\
 —————————————————————————————————— \
\
 想想自己这一年内学到的东西，基本分为三块：1老板教的 2好友教的 3网上看的 \
 网上看到的  大  部  分  也  是  社交网络上好友的信息流 \
 所以，我从各路好友那里学到的东西最多 \
\
 我一直回应父母：“这个时代的年轻人，从同龄好友那里学到的东西，一定比从老师那里学到的更实用” \
\
 有时候我也会叹息，如果能早遇到谁谁谁，早知道什么事，现在的生活肯定大不同 \
 更多的时候，是庆幸： \
\
 比如没遇到yxj，我就不会这样粗去玩 \
 如果没有ltj，我也到不了那些地方 \
 没遇到震震、家鸣，我也不会有这些.NET技术，给后面的实习打下基础 \
 如果肉神没在MSRA实习，我也不会敢找人内推 \
 。。。 。。。 \
\
 昨晚日志里说我喜欢《云图》你的这句话： \
 “我们生命的不朽性质在于，我们的言语和行为的后果” \
 我觉得进化出语言和文字是文明最奇妙的地方 \
 它让人与人之间有了更多的的Connection与Influence，生活一下子就丰富起来了~ \

 看完的亲帮忙顺手填一个简单的问卷，帮助我给大家提供更好的内容： \
\
 只要三个数字就可以了： \
\
 第一个数字：总体评分：3代表，2还不错，1一般，0差劲 \
 第二个数字：图片评分：3有意思，看了又看，2一般，看了一眼，1太差，压根没看，0不填 \
 第三个数字：文字评分：3有意思，看完了，2没看完就放弃了，1我是来看图的，0不填 \
\
 比如333就代表佳作，100代表打酱油哈~ \
