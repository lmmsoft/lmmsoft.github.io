简单叙述下今天的经历，觉得无聊的话直接跳到分割线后面的"今日主题"《没实现的梦想》： \
 \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_ \
 1. 二次答辩是这样的：昨晚所有人已经查重，有个抄袭60%昨晚就接到通知，所以我应该是毕业无忧的 \
 2. 早上高臻知道这个情况后打电话给我，让我去参加答辩，我的手机掉从床缝掉到墙角，后来回电也没人接听，遗憾错过的 \
 3. 最好情况是我答辩后获得院优（校优查重5%以内，我肯定不肯能）虽然没去答辩，只能是良，但还算命大，毕竟没有因此而失去毕业机会，或者很麻烦地整改文章，我已经很满意了~ \
\
 4. 上午拍民国装，白色的 \
 5. 中午请了6个同学吃饭，饭桌上约好下午拍黑色民国装（很开心，如果没和大家一起吃饭，估计我的毕业照里就不会有民国装咯） \
 6. 下午拍照，过程中大家顺便把照片拍成了鬼片（上一篇转载的日志）挺好玩的~ \
 7. 晚上从7点睡到10点，现在夜里睡不着了~ \
\
 ———————————————— \
\
 今晚收拾宿舍，发现不少东西，都是回忆。 \
\
 其中有一张纸，是篇英文作文，题目是 "the same time next year"（明年此时） \
 虽然没有标明时间，但应该是大二上所写，畅想的是我大三上的生活： \
\
 （翻译——评注）如下： \
 1. 我在准备ACM/ICPC广州站的比赛——大三那年没有广州站比赛，我也没有能在对内选拔突围，最后结果是没参加过regional \
 2. 我会很多算法，包括：图论、DP、数据结构——最后结果是我根本不会图论和DP，数据结构只会面试题中那些，诸如线段树什么的，我都不会 \
 3. 我在POJ上做了超过500题——实际情况是，截止大三下，才做了389题，差得很远！ \
 4. 每天一题，通关USACO——实际是第一关都没打通 \
 5. 我参加了很多比赛，rating也不错——比赛参加的不多，rating惨不忍睹 \
 ————以上都是ACM，占了大部分，当时我心里想的基本都是ACM，但最后ACM生涯无果而终，因为我不努力—————— \
\
 6. 我在清华大学里上了GRE暑期班 \
 7. 我背了10编GRE单词 \
 8. 暑假去了一个地方旅游 \
\
 ————以上只能呵呵了，迄今为止没接触过GRE，我为出国做出的努力比我母亲为我出国做出的努力还要少———————— \
 ————那年暑假去了哪里玩？有的，和排骨，排骨的前女友，陆艺，另外一个同学，去了河南，包括：云台山，少林寺，开封———— \
\
 结尾： \
 (大学里)有过很多很多的想法，最后大部分都没实现； \
 有过很多很过的规划，大部分没落实； \
 设想过很多很多未来的路，最后走到了没想到的地方~ \
\
 大梦一场，回忆有好有坏。 \
\
 大三那年，我的实干能力有了不少提高， \
 自己的感觉，从”无所事事“到了”积极主动“， \
 看到一些学弟的困惑，里面都有自己的影子， \
 劝说不会有太好的效果，他们有一天终将自己领悟吧~ \
\
 现世奔波， \
 光阴飞逝， \
 青春留白~ \
