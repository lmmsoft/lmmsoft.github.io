# 图片 这是我在MSRA last day时的合影 上图中间是我们的manager，他同时带了4个intern 下图就不解释了，哈哈~ 图片 推荐一本书《拆掉思维里的墙》

一、书中给出了6个提升安全感的tips： \

1. 小范围地冒险； \
2. 远离太容易获得的安全感（过于关心父母，永不犯错的任务，养老般的工作）； \
3. 少看凄惨电影书籍，远离没有安全感的人，看干净明亮的电影和书籍，跟简单快乐的人相处； \
4. 做一个恐惧保险箱； \
5. 做成功日志； \
6. 直面恐惧，彻底反弹。从更高的层面谈安全感，安全感是给回来的，不是拿回来的。如果你准备从父母、老公、孩子那里获得安全感，那安全感是求不来的；但如果像刘丽一样用自己微薄的洗脚收入资助一百多名贫困儿童，那么安全感是可以给回来的。 \

娄： \
 安全感需要能力来支撑,100分的能力，能给自己100分的安全感 \
 -&gt;能力需要自我考察+自我修炼 \
 -&gt;小范围冒险，逐步探索自己能力的极限在哪 \
 -&gt;多做事，多修炼，提升自己安全感 \
\
 二、如何掌控自己的生活。 \
\
 作者说我们要做高脚杯，先做好自己，在影响和帮助别人；而不是漏斗，先失去自己去满足别人。 \
\
 那是不是父母就有权掌握我们的生活了呢？作者的观点是，自己的生命自己是大股东，父母亲戚是参股人只能给予意见，真正掌握自己命运的人只能是自己。而且当自己的观点和父母相左时，要选择我爽，父母暂时不爽，最终会爽的双赢模式。而不是选择我不爽，父母暂时爽，而后大家都不爽的双输模式。 \
\
 娄： \
 我把父母当做高优先级的资源来对待，提升IO的优先级；但生命被父母掌控，那还真是悲哀，尤其是我发现自己能看得比他们更远之后。

\
 我现在和父母之间的【观念矛盾】也很大，我把父母当老板来看，我把要做的事情想明白了，你要问，我都能有理有据，你要是不讲理，我就没办法了。 \
