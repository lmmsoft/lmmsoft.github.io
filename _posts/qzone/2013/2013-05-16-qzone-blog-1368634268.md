 这篇在人人上也是2万次分享的文章，讲的的她的三段感情经历； \
\
 第一段是初恋，七年里只在一起了两个月吧，而且多数故事都是悲伤的（ps:这让我想起昨天的一个分享 <http://blog.renren.com/share/249488460/15793154549> 所以即使一直缺乏快乐，还是会在初恋上陷得很深吧~） \
\
 第二段是大一和大二，“  但那些我还不够好的年岁里，在我身边陪伴着我的人是他。” ，感觉是男孩成长的速度没赶上女孩纸，然后就这么掰了~ \
 作者没笔墨太多，但对我却比上个故事更有触动，在我还不够好的岁月里，身边没有这样的陪伴。不过，我是男孩子，没有理由渴求这些~而且，理应成长得更快一些~ \
\
 第三段是大三，最忙碌，最辛苦，最需要人的时候，他不在，msn上他的安慰也在作者  哭天走地中哀婉的结束，后来也就慢慢散了~作者评价她的大三“开始了大学最糟糕的一年，却也是成就我当下漂亮生活最关键的一年”。 \
 我对这个故事也很有同感的，我有类似的经历，在外企实习过半年，那半年里还兼有找工作的重要任务和学校里层出不穷的破事，这段苦日子让我也是一个人过来的，“过得是苦日子，但回忆起来很美好”，我同样也认为是我当下漂亮生活的关键一年，找一份好的实习/工作，真的会加速人的成长。我在HK的时候对aleen说过，不要怕找到吃苦的工作，更重要的是你和谁一起工作。整天无所事事八卦的大妈，不会让你快乐，那样的清闲你也未必会真正喜欢。 \

 Q1：  感觉你很少使用社交网络,是不是生活中不需要这个东西?(我现在沉迷,戒不掉,非常痛苦) \
 A1：我工作常常非常累，经常下班9点，洗个澡10点，洗完衣服11点，然后第二天还要工作，就睡了，没太多时间玩社交网络，其实很羡慕你们读书的时候可以好好享受 \
 很多工作的人都在用社交网络，很多人在公车里、地铁里都一定要拿着手机，看小说/上网/听音乐， \
 你想戒掉是因为有更重要的事情要做，比如学习，看书，你可以set一个目标，然后奖励自己看微电影/喝奶茶等等~ \
 不要太苛刻自己，过程如果不是快乐的，这个事情不会坚持太久，想戒上网要用快乐的办法，就是不上网也很快乐那种~ \
\
 Q2:  Q3工作和生活如何平衡?我感觉工作出色的人大多数都是加班或是工作特别能吃苦的,而那些享受生活的人,感觉爬升并不快~ 最后谢谢姐姐,特别喜欢你

A23:我觉得  加班会很辛苦，升的快不快其实工作几年后没那么重要，对于女孩子来说，其实会很想要有自己的生活(用人人号和人交流就是有这种问题。。。)。至于平衡，不要把任何一方面都看得更重要，其实还是开心，如果你工作很开心，那就工作也行吖~
