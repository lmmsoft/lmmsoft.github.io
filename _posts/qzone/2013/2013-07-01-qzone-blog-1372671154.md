 3. 晚上和张江男的一些交流 \
\
 杂谈： \
 1.出租屋 \
 有宇娘和黎叔出差，住在宇娘的房间，大床，空调，独卫，厨房、洗衣机、电视机是共享的，比大学宿舍好很多。合租的都是大学同学（wlan id=njust,密码也和活动室一样），上班步行20分钟，到地铁站步行不到十分钟。 \
 一个月的价钱和学校一年一样。 \
\
 但是，这地方只能睡觉、上网，还能干啥呢？ \
\
 我在想， \
 对于宅货来说，在哪里都是自身自灭，但是对于我这样喜欢玩的人来说呢？ \
 学校宿舍虽然小，但是人多，不会闷。校园里各种活动，跑不了多远就能参与，城市里各种文化氛围，也不算太远 \
 工作了之后呢？ \
 熟人合租还好，（星姐他们就买了小霸王游戏机、桌游什么的，可以一起玩） \
 若是不熟，或是租独立的房间，是不是一个人的时光太多了呢？ \
 然后各地的挨踢企业集聚的地方，都在大郊外吧，配套不行啊，进城各种不便。。。 \
\
\
 比如上海高校的CS系，交大在西南，到西北的同济CS系要3小时，到东南的复旦CS系要2个小时，大家完全联系不起来，各搞各的，当然，各自生源非常好，学校里什么牛人都有，而且sjtu和fdu周边都有大量优质的IT公司，所以学生的发展还是相当好的。 \
\
 南京高校CS系距离同样的远，而且之间没什么联系，同学们没有相对官方性质的交流渠道，其实我感觉njust这地方学生的视野非常窄，窄到能被不懂CS的辅导员忽悠，读研还是工作，很少看到自己的观点/规划，真是捉急。至于城市氛围，学校附近的产业氛围，那就呵呵吧，真没啥值的说的。 \
\
 北京高校基本都在中关村附近，联系就很多，比如acm校赛，互派队员砸场，看上去就羡慕。然后挨踢氛围，大企业的集聚，机会太多啦！ \
\
 (好像扯远了，就此罢笔，其实我本来想谈对未来苏州生活的期待的。。。) \
