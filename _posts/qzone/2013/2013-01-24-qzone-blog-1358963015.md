last day in MSRA play foosball at noon on 13f with EricLilyChunjie~

今天是到家的第二天，注意工作是整理，今天遇到了几个片段 \
 1. 看鲁豫有约蒋方舟那一期，谈到了记忆起点的事件。我能回忆起幼儿班（大概3-4岁）的一件事，再往前短时间内想不起来了。亲，你现在最早的幼年回忆是哪一件事情呢？那些更早的记忆到哪儿去了呢？ \
 2. 下午回看照片，就拿黄花城水长城来举例， \
 a)我经历了所有过程，有些回忆 \
 b)看自己相机的照片 ，有了更多回忆 \
 c)看自己相机拍的视频，“原来过程这么有意思呀” \
 d)看正阳哥哥拍的照片，哈哈，原来被偷拍了好多哈，这些我都忘了 \
 所有嘛，虽然我有全部的经历，但能记起来的只是很少很少的一部分，即使有的部分我拍了照片，我都已经想不起那些照片里拍的是什么 \
 3. 顺着上一条：我的很多回忆不完善，我觉得我对照片的整理是相对对完善的，曾经想把陕西玩回来的照片每张都命名，限于工作量，失败了。失败还有一个因素，很多照片我都忘了当时为什么拍，拍的到底是什么，当时有什么故事 \
 4. 很多次旅行回来我都想写游记、日志，可是很多都没及时写，现在什么都不记得了，只能看照片回忆。。。根据2所述，照片只记录了整个回忆里的一小步分啊，那些剩余的回忆你们去了哪里？ \
 5. 今天还整理了电脑里的文档，现在在用印象笔记，看到几年前用txt和网页保存的大量资料，很像把他们都存到印象笔记里面去，搞了一会儿也停止了。 \
 原因： \
 1).文档太多，精力不足 \
 2.)这些文档下载之后基本都没看过一次，整理了也是白搭，虽然印象笔记的全文搜索功能还行，但我真的记不得自己记录过这些东西，以后想找估计还是通过搜索引擎吧 \
 6.顺着上面继续说，我的记忆力有啥用？尤其是搜索引擎拥有世界上最大知识库、手机上网如此方便的年代？ \
\
 说完了这些片段，本文也差不多了。 \
 很多东西我都记不住，为什么还要去做？ \
 没有全部的回忆，回忆里最甜蜜的部分，我们叫它：“好的回忆”~ \
\
 ———我是分割线——————————————————————————————— \
\
 看完的亲帮忙顺手填一个简单的问卷，帮助我给大家提供更好的内容： \
\
 只要三个数字就可以了： \
\
 第一个数字：总体评分：0-9(9代表最高，1代表太烂，0占位符，代表不填写) \
 第二个数字：图片评分：3有意思，看了又看，2一般，看了一眼，1太差，压根没看，0不填 \
 第三个数字：文字评分：3有意思，看完了，2没看完就放弃了，1我是来看图的，0不填 \
\
 比如933就代笔浑然天成的佳作，000代表打酱油哈~ \
