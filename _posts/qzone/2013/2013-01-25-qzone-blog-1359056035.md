2012-10-29 在香山赏红叶，夕阳下山时所拍

在哪里生活，就有什么样的节奏，环境改变人。 \
\
 回家两天了，50多小时没出门了，宅男生活有开始了。 \
\
 中午爸爸妈妈都回家吃饭，然后午睡，接着先后被电话吵醒，捣鼓一会儿去上班。 \
\
 住在小镇上，公司、学校和家里的距离不可能太远，小学时住的最远的同学放学回家也不超过15分钟步行，我的小学没有食堂，大家都能回家吃饭，午睡，下午继续上班上学。小日子相当闲适。 \
\
 上了中学，到了市区，很少有人中午回家吃饭，基本上都在学校食堂吃，然后午自习或者趴在桌子上休息一会儿。节奏快了一些。 \
\
\
 到了大学，下午2点才上课，有午睡习惯的孩子继续午睡，我中学六年没养成午睡习惯，中午做自己的事情。 \
\
 实习期间，工作时间的安排里只给中午留了一个小时的午餐时间。来不及回家，也没有人睡觉，下午一点大家都开始工作。节奏快多了。 \
\
 按理说每天的工作时常是差不多的，基本都是国家标准的8小时，为什么明显感觉城市节奏快呢？ \
 因为住得远，路上花的时间多？在家的时间少？ \
 反正我是没想明白。。。 \
