没事多写点废话，反正我已经决定2013-07-01封掉扣扣空间了~ \
\
 ————————————————————————————— \
\
 上午答辩 \
 7点接到高臻的叫早电话，真靠谱，把重要任务委托给靠谱的人~ \
 8点智能楼开门，我第五个，9:30左右开始 \
 我的幻灯片修缮后就比较完整了，结构清晰，该有的都有，然后提问环节，我和老师谈笑风生，达到了本科毕业的要求，良！ \
 花絮1：女老师问我QA的A是什么意思，我说question and answer \
 花絮2：女老师问我T恤的MIT是怎么回事，我说好友从美帝带的 \
 ps:后来和女老师(丁军娣)聊了一会儿，她来南理工已经三年了，在智能楼办公，我觉得比较奇怪的是她没去过计院在基础实验楼的机房，而且感觉这个老师水平有点捉急，不知道怎么留校的。。。 \
\
 答辩组长娄震老师和我是本家，给分偏高：88分，高臻明显比其他同学做的都好，85分，其他人都60或70，没有达到娄震心中的良，还有三个要挂的节奏，当然，应该不会挂，最后都会过的，我觉得，良好以上也会达到70% \
\
 娄震说的几个观点还是很不错的： \
 1. 本科生毕业设计之间的差距很大 \
 2. 他好几年没带本科生毕设，就是因为现在本科生毕设太弱 ，很少能达到他的要求 \
\
 还有个花絮是某个同学的毕设居然是抄的娄震的程序，当场被看出来了，悲剧~ \
\
 今天大家的导师是贾修一和胡雪蕾，胡也是我的导师（算了，这里就不乱说了）反正我觉得老师对毕设的要求不是很高，都靠同学自觉~ \
\
 答辩之后我在智能楼里转了一圈，顺便发现只能楼顶是开放的，可以露营  [@刘铁俊](http://user.qzone.qq.com/491507927/) \

 中午看了一会儿书，有不少货，晚上和人吹牛都用上了，我记录个提纲： \
 1. ”上帝负责给你创造理想的爱人，你要负责遇到她“ \
 2. 投资自己 \
 3. 不为生活所迫，财务自由，才能安心做自己想做的事情 \
\
 然后写点心得： \
 1. 不同作者的水平是不同的，【水湄物语】明显比【一直特立独行的猫】高，因为她们的生活积淀不同，阅历也不同，水湄30+，星爷26好像，两人职业生涯的阶段也不同~ \
 2. 水湄找的是IT男做老公，然后剖析了IT男的几个优点，嘿嘿~ \
 3. 工作后：我要办a信用卡，b思考如何理财，而不是把收入全部花掉 \
\
