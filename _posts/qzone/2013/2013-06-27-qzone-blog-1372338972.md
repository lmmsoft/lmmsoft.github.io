 今天离校了，挺充实的，大概七件事，流程如下（想看有价值的内容直接跳到下一环节~）： \
\
 8:45 起床，收拾了下宿舍，汇集了各种没送出去的小礼品，几本书、挂件、杯子等~ \
 9:00开始写床单 “我爱你，再见” \
 10:00 到达主楼，约了毕设导师胡雪蕾见面，今天周六，把老师喊道学校来，有点不好意思 \
 11:30 经四工到达明苑，在我最喜欢的位置（二楼靠窗，可以看到楼下活动和吃饭众生相），和  [@涂霞](http://user.qzone.qq.com/850984818/)  吃饭 \
 12:30 把在台湾诚品书店买的几米绘本《  如果我可以许一个愿望  》送给了chj \
 1:30 回宿舍，收拾东西 \
 2:30 离校，先送刘铁俊和黄典典去机场，然后自己回家，当时常峥和好多同学送到楼下， \
 3:30 路上车子出现胎压不足警报，尼玛，吓死了，怕耽误时间哈，不过选路比较恰当（宁杭+绕越+机场高速）提前两小时到了 \
 4:00 到达东大九龙湖校区，约了上次没见到的wyq小朋友，wyq小朋友保研去了清华软院，完成了list里面倒数第二个人~ \
 7:00 到家，住五楼，么电梯，搬了20%的行李上楼，累死我了。。。 \

 b. with 导师 \
 1. 我猜毕业前约导师聊天的娃不多，大部分整个学期也没和导师说过几句话吧，甚至研究僧读得比较水的同学也没太多和老师交流，亏了啊！ \
 2. 我从MSRA check out 前几天才开始约各种人聊天，收获超出自己意料（显然嘛，若能预料到有什么收获，还要见面干嘛），然而因为时间紧迫，很多人没来得及约，造成莫大遗憾，所以毕业前很注重和这方面，那天发状态的【  终于把list里离开南京前想见的人都见完了，16男4女，8所不同学校，请了6顿，蹭了10顿，哈哈！  】对此做了很好的总结 \
 3. 然后我看了谈话后记录的笔记，实质性内容倒不多，大部分是八卦内容，哈哈~ \
 4. timeline八卦：18NJUST本，22NJUST硕，24CHUK博，28NJUST当老师，34得子，现在  36，看上去应该是博士把后面的生物钟都推迟了，我本科毕业和老师硕士毕业同岁，没继续读，做各种事情应该不会太急 \
 5. 因为之前相互了解不够，所以我们花了不少时间了解彼此的背景，没有太多时间聊一些深一点的东西（其实我见某些人之前会去预习他所有的博客/人人日志，然后开门见山，省掉很多熟悉的时间） \
 6. 聊到生活态度，老师应该是个挺积极的人，但也会被生活琐事所烦恼，对未来会有规划，但有了小孩后随遇而安的的一些东西更重了 \
 7. 大概还聊过生活圈子/和朋友联系/工作压力/家庭生活/  p  remarital  sex/婚姻  等，老师的老公是好像本科同学，谈了很多年，所以领证前后生活没太多变化的样子~ \
