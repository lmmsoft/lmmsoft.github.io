昨晚无聊,问候了一下我所有的在线扣扣好友: \

\
 帮我做个小调查哈:

你2012年最得意的一件事/一个作品是什么呀? \
\
 然后收到各种各样的答案. \
\
 由于对隐私的尊重, 答案就不贴出来了,不过我还是要尽到义务写写总结,虽然这个结论没有想象中那么有趣: \
\
 1. 正如我设想的那样: \
\
 感觉会很精彩的人,果然说了好多有意思的事情; \
 感觉不简单的人,果然做了出乎我意料的大事情; \
 醉心于学术的人,果然不是发了论文就是搞了大项目; \
 感觉上像是混毕业的人,固然没搞出啥能让自己满意的东西; \
 感觉缺乏passion的人,确实没多少有趣的东西可以分享; \
\
 有人的研究生生活比本科还要精彩, \
 也有人在混毕业,丝毫看不出本科时期那种豪情壮志,我故意刺激了一下,似乎也没看到激烈的反应,哈哈~ \
\
 有的人年初和我说的东西果然都实现了, \
 有的人完全没和我提他年初说过的东西,我虽然记得,也不方便问@@ \
\
 有的人换了环境,生活有了很大变化, \
 在旧环境里待到第五年的两个,果然都老油条了,没啥产出(插一句:保本校研究生是不是都会遇到这样的问题?)

\
 热爱acm的,答案都如出一辙,比赛结果或是某个激动人心的过程~ \
 工作或实习的人,在  brainwash  公司说了加入XX公司是最得意的,不  brainwash  公司都没提到公司,提到的也是"开始工作,一个人生活"之类的~

\
 可能是大家彼此都比较熟悉,基本上从大的角度上看人都差不了太多,微观的话这个问题又不合适. \
\
 都是20几岁的年轻人,来点变化,每天都尝试改变一下自己? \
 负面的叫惊奇:surprise \
 正面的叫惊喜:amazing~ \
\

2.这个调查有助于好友直接的相互了解: \
\
 可能我们是异地,去年一年都没见过一次,社交网络也不怎么用,但这个问题能对对方的生活有个很好的概括~ \
\
 一下子就和远方朋友打开了话题,不是么? \
\
\

3.说说我自己的吧: \
\

2012最得意的作品是萌萌, \
 我的设定是"亲民不高贵的IT萌妹纸形象" \
 他和所有码农互动/聊天, \
 她可以方便得打开话夹子, \
 让我认识了很多人~ \
![图片](/images/qzone/2348849d055d4e1be034e70f.jpg)\
\

\

总结: \
 我觉得横向看所有人的答案,研究自己的好友圈似乎意思不大,正如上面第1点所述~

我觉得最有趣的地方在于纵向看某一个人,加深你们彼此的沟通/了解,这个更有意义~ \

\

 看完的亲帮忙顺手填一个简单的问卷，帮助我给大家提供更好的内容： \
\
 只要三个数字就可以了： \
\
 第一个数字：总体评分：0-9(9代表最高，1代表太烂，0占位符，代表不填写) \
 第二个数字：图片评分：3有意思，看了又看，2一般，看了一眼，1太差，压根没看，0不填 \
 第三个数字：文字评分：3有意思，看完了，2没看完就放弃了，1我是来看图的，0不填 \
\
 比如933就代表佳作，000代表打酱油哈~ \
