就按照时间顺序随便写写咯，蛮好玩的，说的是我和  [@陈倩](http://user.qzone.qq.com/1097859480/)  的故事~ \
\
 背景： \
\
 0. 我们没碰过面，或者说没打过招呼，不过cq看过lmm演示GPA程序 \
\
 正文： \
\
 1. cq高考完，签了南理工，想了解学校情况，在百度知道上问问题，发现个叫lmm333的家伙，主页上留了qq，遂加扣扣询问了诸如什么专业好，微软俱乐部怎么样等问题，lmm333错过面试，没加微软俱乐部，不清楚里面情况~ \
\
 2. 后来两人就没联系了，lmm333还把cq删了，cq一直没删lmm333 \
\
 3. cq大二， 在微软俱乐部里面干活，举办南京四校微俱比赛，有个叫橙衣少年的家伙带着【还没上线的南理工GPA查询系统】，最后一个登台演示，功能明显弱于前面所有同学，但和一个喷子评委互动良好，最后这家伙出人意料地赢得了比赛第一名，瞎了全场所有人的眼睛，他自己都不敢想象，成绩是cq计算的，应该没做手脚~ \
\
 4. 后来一个叫"娄明明.LAMP"的人在从网上发布了GPA查询，转发者众，cq也借此加了此人为从网好友，此人一看就是搞挨踢的ds青年 \
\
 5. 后来娄明明在从网上装妹子，人气大涨，cq还是一如既往地低调 \
\
 6. 南京四校的比赛虽然酱油，但帮助橙衣少年获得了微软亚洲研究院的实习机会。橙衣的工作恰好与微俱运营有关，他告诉cq因为申请表没写好，失去参加夏令营的机会~ \
\
 7. 毕业前，【橙色的程式员】把扣扣名字改回【那楼明明很高】 \
\
 8. 2013-06-27 cq复习不进去，翻扣扣好友， 发现个叫做  【那楼明明很高】，就去问“突然想问你是不是萌萌姐！！！娄明明”，然后发现自己“艾玛，我一直加了xxx，都不知道 ” \
\
 9. 原来萌萌姐就是她在南理工认识的第一个人,太奇妙了；另外lmm居然早就把她删了，一点觉悟都没有，活该四年都找不到妹纸！！！ \
\
 THE END \
\
\
 ps:突然想补充点，虽然我最近没这样【两个人合并为一个人】的经历，不过最近发现某个踢球认识动力院的遇到的人申到了berkeley 和  Princeton  ，好震惊啊；然后还有个仰慕很久的大牛sqybi，7-15和我一起去BJW入职，感觉也相当好~ \
