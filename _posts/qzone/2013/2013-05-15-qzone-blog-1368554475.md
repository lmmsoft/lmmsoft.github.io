2013-06-26 update \
 改名为：考公务员那些事 \
 原名：幸福的选择 \
\
 加了若干照片，已完结，可能会有续篇，不过至少是一年之后了~ \
\
 —————————————————————— \
 扣扣空间的第331篇日志 \
 我的扣扣好友非常少(100人左右),基本都是联系非常多,非常亲近的好朋友 \
\
 我喜欢这个相对私密的空间 \
 也愿意在这里, \
 不怕大家笑话地写点自己的真实想法 \
 并听取大家的意见建议 \
\
 ------------------------------------------------------------- \
\
 今晚在这里, \
 说一个幸福的事情 \
 我报考了南  京市-六合区-统计举-科办员 的公务员职位(应该是信息管理.软件开发方向) \
 通过了笔试和面试 \
 终于成为这个职位唯一的一位获得体检资格的考生 \
 这基本意味着我 \
 考上了 \

我用亲身经历证明 \
 公务员考试没媒体宣传的那么难, \
 也没有民间传闻得那样黑暗 \
\
 笔试很公平, \
 全省都做一样的试卷,公示所有进面试人员的每一门成绩不像考研一样每年都有大量的试题泄露报道 \
 面试也很公平, \
 七个评委现场打分,  有录音(不确定,感觉像是  ),  当场出成绩并由考生签字,第二天就公示了录取名单

\
 我没有任何背景 \
 考的也不是家乡的职位(我江浦人,考的六合区) \
 但是进体检了 \
\
 不要被外界(不实)的传闻和媒体(夸张)的宣传吓倒 \
 要相信自己 \
 你真的能行!!! \
\
 最初的最初 \
 我从aleen那里知道省考有小学奥数题 \
 后来她考了 \
 后来我们一起考了 \
 后来我上了 \
 有心栽花花不开,无心插柳柳成荫 \
 真是奇怪 \
\
 后来我一直说, \
 昨为中国人, \
 要参加过高考 \
 也要体验过公务员考试才算完整 \
 这两个考试大概就是[科举考试]在当代生活的两个映射吧 \
\
 大四下, \
 已找好了工作的我 \
 为体验生活,报了名 \
 整个公务员考试的流程很长,但我并没有花太多时间 \
 比赛前做了一套半卷子 \
 面试前更是有其他事忙得不可开交, \
 只在张驰的帮忙下, \
 于考前7天 \
 了解了面试流程,并模拟面试了一把 \
\
 今晚确认结果后, \
 先给父母打电话 \
 他们也一时拿不定注意 \
 于是去找邻居商量 \
 后来才给出父母的建议: \
\

爸爸完全尊重我的选择,而且两方面的利弊都说得很清楚

他还特别提到,希望我做我喜欢的事情,这样能有更好的发展~ \

真是好爸爸 ![](/images/qzone/ea8c321fa1293fb1d22f5723.gif)\
 麻麻倒是希望我做公务员,这样离家比较近,在她的视线之下~ \
 果然是麻麻 ![](/images/qzone/52993208ebb37ee0258000f8.gif)\
\
 我自己呢? \
 其实早就心有所属啦~ \
\
 幸福的烦恼是有几个差不多的好选择, \
 而我面对的[幸福的选择]则容易的多 \
\
 电话的最后, \
 我问爸爸心情如何 \
 爸爸说很开心 \
 妈妈更是激动得要睡不着觉了^\_^ \
\
 能让父母开心, \
 这也算是我现在最大的幸福了吧~ \
\

 早上传真完“放弃声明”后，还是有很多想法的，下面汇集一下： \
\
 1.扣扣状态: \
 传真完”放弃申明”，浑身轻松，也有一丝遗憾，我放弃了能看得见的安逸生活，走向了一条需要奋斗的路 ![](/images/qzone/d6c2df9d5d407befb4f5b229.png) 铁饭碗or金饭碗，谁知道呢？ \
 2. 给父母的短信： \

 3.老爸的回信： \
 这一年，吃过很多苦承受了很多压力，同时也收获了很多，如人饮水冷暖自知，可喜可贺也有可惜，这就是人生。成绩属于过去，困难还在前面，收拾心情，以饱满的精神迎接更大的挑战！爹永远支持你！！！ \

 附录1:【时间轴】 \
\
 下面是时间轴,我根据回忆,不保证精确 \
\
 去年此时,aleen告诉我,公务员考小学奥说题,挺适合我的~ \
\
 大四下,我找好了工作,觉得体验下公务员考试 \
\
 2-22 [报名]开始,我观察适合的职位,老家浦口区只有法院招学计算机的,不过要学网络的,我审核没通过,最后报了六合区统计局,原因:1收软工专业考生2离家比较近3报名人数比较少(最终29人成功报名) \
\
 3-24 [笔试] 考点晓庄学院江宁分校太坑爹了, 如果我从学校出发,如果坐第一班的地铁,是不能按时8点到达考场的,同学们必须提前一天在附近住下... 我冒险把家里的车子偷偷开出来了,早上走绕城公路-宁杭高速-江宁的天印大道-弘景大道 到达晓庄,提前半小时;下午回去走下面老路的,太坑爹了,暂不表... \
\
 4-17 [出笔试成绩] 当时我还在台湾,aleen告诉了我过了,第二名.当时我不能接电话,好着急,好在资格复审截止日期是4-26日,我23晚上到南京,24庆祝妈妈生日,25号回学校拿证明,并去六合人事局把资格复审办了. 中间在香港接到班长人人,让我和他联系,原来六合人事局找到学校,找到计院,找到辅导员,找到班长,终于联系到我. 我给田野打完电话后又给六合人事局的同事打了电话,他们非常友好~ \

我 第二名  公基66.5 行测63.8 申论190.3 总分190.3 \

第一名 赵博文  64  69.5  59  192.5

第三名 董义文  64  66.5  55.5  186

\
 5-12 [面试]我穿着西装进了考场,太紧张,在外场工作人员的建议下,脱了西装,并解开白衬衫第一个扣子... 我是第一个上考场的,一共20分钟,前几天答得还不错,但最后一题时间不够,只剩四分钟,草草了事. 当场给出成绩72.4 比较低的分数

 (第一名后来大概68，掉到第二) \
\
 5-13 电话里,我和aleen说,大家都关注我考试的分数,其实呢,我自己更关注这次的过程, 这就是我的体验之旅~ \
\
 5-14 [出面试结果]亲爱的陆露同学在我的人人上回复我的状态,告诉我进体检了,我很震惊,也很开心,确认了成绩之后,立即打电话给爸爸告知好消息,父母也很激动,然后去邻居家讨论了. 随后我告诉了姑爹小姑,aleen/尹欣杰等, 随后和aleen从HK给我打了电话,我简单介绍了下现状,并告诉他我的面试心得,"表哥只能帮你到这里了". \
\
 5-15[放弃申请] 早上接到了董姐姐的短信(昨晚从董伯伯那里拿到号码，姐姐居然10点半就睡了，公务员生活真舒服~) 姐姐有这样的经验，告诉我打电话过去说明情况就可以了。由于号码丢了，我费了一番周折，从aleen的香港号码里找到了六合区人事局同事的号码，打过去，很客气地说，对方也很客气的答复，告诉我“放弃声明”的模板。很快，我把手写的声明和身份证复印件传真过去了，又收到了回复，OK啦~随后给父母打电话，并发了短信（见上文）~ \
\
 6-17 约了初中同班同学赵博文吃饭，也就是笔试第一面试第二，后来递补我去的。 \
 zbw今年考研二战失败，正好女朋友在考公务员，就报名玩玩。 \
 笔试面试折算到100分后按50%50%加权，折算后他笔试比我多0.6分，但我面试比他高4分左右 \
\
 他和我相似，都没怎么复习，本来也不准备去。但后来我是真的不去，拒掉了，他选择去。 \
 后来他通过了体检，最近又去了一次，拿政审材料，副局长带着他在所以科室转了一圈，认识下包括局长在内的所有人，（人太多了，一下子记不清） \
 六合统计局也在六合大厦里，和报名的六合人事局是一幢大楼，统计局大概30人左右，今年只招了这一个人，这个职位前两人都高就了，前任是去年考到了南京市统计局。 \
\
 工作内容包括维护统计局的官网等，座位在 "办公室" \
\
 大致了解到这么多情况，我很开心初中同学去的，肥水不流外人田，哈哈，另外我以后也可以了解到这个职位具体工作的情况，有机会半年后/一年后我再来更新哈~ \
