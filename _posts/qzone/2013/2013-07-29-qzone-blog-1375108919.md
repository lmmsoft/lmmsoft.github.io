1. 好怀念之前那段在扣扣空间可以肆意乱写的日子，每天都把经历记录，最近没有这样的盼头，反而觉得不习惯，我还是偷偷回来吧 \
\
 2. 不是黄钻了，不过默认的信纸还是很得我心的：“记录生活的点点滴滴” \
\
 3. 有些东西，不记录就真的忘了 \
\
 最近想了一写东西，记录如下： \
\
 a. 候鸟 \
 今天中午和一个姑娘one-one，她老家在江苏连云港（在老家过暑假）、长在广东佛山（过寒假）、大学在吉林大学，在北京有过两份实习，现在在云加速； \
 然后我们聊了气候、经历什么的，这个经历过东北、华北、华东、华南的姑娘，就很有发言权啦~ \
 就气候而言，她就喜欢冬天广东的和夏天的吉林哈，真的很舒服~ \
\
 然后我就想到“候鸟” 这个词，有没有工作可以让我做个候鸟呢？总在最好的季节住在最美妙的地方~ \
 1. 旅行家什么的，当然可以，但不是我短期或中期的追求 \
 2. MS 可以WHF(work from home) ，这个理论上可以延伸，而且很多美国挨踢企业都出现过员工私自外包工作给中国人做，赚差价的同时还成为优秀员工，但这个对我还太远 \
 3. 然后我看过evernote的JD，有一个让我印象非常深刻，就是你可以自由选择工作地带你，而且可以随意更换: \

在印象笔记，我们提供的不仅是让你充分展示自我的舞台，更有六大福利让你在轻松愉快的气氛中实现自我价值：

- 福利一：无限制上下班时间；
- 福利二：无限制全年假期；
- 福利三：无限制咖啡、可乐、水果、点心全天免费供应；
- 福利四：全球六地办公室无限制移动办公；
- 福利五：免申请自主计划出差；
- 福利六：一个改变世界的机会！

 上面是官网找到的~ \
 这明显是新一代的工作氛围啊，MS有1和3，当然也有6，g比MS的工作氛围更开放，但还不至于达到2、4、5. \
\
 记得当时的文案，就是春天在东京办公，看樱花，冬天去莫斯科看雪~ \
 对我很有吸引力的哈~ \
 —————————————————————————————————————— \
 b. 沙河镇 \
 当时记下的关键词是 三轮，地摊，环境，情侣，地铁 \
 不针对关键词展开了，就说说大概印象 \
\
 背景：大学同学在北京的居住地，在北京郊外，做地铁昌平线可以到西二旗换13号线，百度在西二旗，小米在上帝（清河？） \
 人物：百度、小米、知乎的工程师 \
 居住环境：小产权房，挺便宜的，租金是3100一套，三室一厅，没有空调；小区像是安置房那种，很破，比如楼梯道是水泥的，全是牛皮鲜，然后我去 那天停水的 \
 房屋背景：房主的婚房，然后房主自己住城里面，老婆也在东三环读研究生，估计是为了结婚不得不买房子，客厅装修得很漂亮，但空调都没装，估计就是给双方亲戚看的 \
\
 感想： \
 1在北京安家太难了 \
 2走路15分钟到地铁站，三轮车10元，明显是城郊结合部的样子 \
 3地铁20分钟到西二旗，西二旗地铁30分钟西直门，就算是进城了（明清北京城就是现在的二环内） \
 4配套不太行，门口灰尘很大什么 ，不表 \
 5 大家拿着比老家高很多的工资，生活在环境还不如老家的地方 \
\
 自己： \
 1. 我在中关村上班，住在五道口，各方面都好了很多，明显有大城市的样子 ，也有在大城市生活的感觉 \
 2. 不细说，反正结论是我要享受这三个月的生活，以后就真的没机会了 \

 c. 近期计划 \
\
 part 1 吃饭 \
 1. 第一周都和饭团一起吃，回到了MSRA的圈子， \
 2. 第二周都和组里面一起吃，毕竟要融入新集体，不能总和实习的小孩子在一起的哒~ \
 3. 第三周开始one-one了，今天是第三周第一天，约了(李)明娜，明天中午是谢研~ \
\
 part 2 生活 \
 生活非常糟糕，作息非常乱，一切都是老样子，尼玛啊！！！ \
 趁这几天比较空闲，我要拟一份“简单生活声明” \
 这个可以参考这篇 http://user.qzone.qq.com/〔原账号已隐去〕/blog/1368634268 文章， \
 别人走过苦逼，进化了，我读了人家的东西，显然要少走弯路，所以考虑直接进入“简单生活状态”， 根据我的理解，简单生活状态并不影响工作的产量（甚至提升了工作的效率），最大的变化，是提升了生活的质量，过上自己满意的日子~ \
\
 反正我对这两周的现状不满意，不如早日改变 \
