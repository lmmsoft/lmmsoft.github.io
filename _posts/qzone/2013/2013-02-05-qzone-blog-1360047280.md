 —————————————————————————————————————— \
\
 前几天买了很多有关玩的书 \
 比如： \
\
 [一路吃下去:骑向台湾第一小吃摊 \](http://www.amazon.cn/gp/product/B008AUJA8A/ref=oh_details_o00_s00_i00) [我就是想停下来,看看这个世界(单身女孩,休学旅行) \](http://www.amazon.cn/gp/product/B007A9VZB2/ref=oh_details_o00_s00_i01) [迟到的间隔年(天涯、磨坊等著名论坛超经典人气帖,千万旅友狂热推荐) \](http://www.amazon.cn/gp/product/B002OED6QK/ref=oh_details_o00_s00_i03) [台湾,你一定要去(附台湾自由行推荐线路)(一部感人的家国情书,关于台湾最娓娓道来的纯美人文读本) \](http://www.amazon.cn/gp/product/B006GX8KMK/ref=oh_details_o00_s00_i06) [骑车回巴黎(封面护封的背面附赠知名漫画家高毓林亲手绘制的路书) \
\](http://www.amazon.cn/gp/product/B008F4ZBIO/ref=oh_details_o00_s00_i07) 基本上都翻了一遍，挺失望的。 \
\
 这些书基本就是写了 \
 旅行经历，经历了困难，遇到了有意思的人 ，看到了美丽的风景，趣事、美食等等 \
 我觉得没我想象的好看 \
\
 凡是自己玩过的人 \
 都有自己的故事 \
 和路上朋友的故事 \
\
 只要在路上 \
 都能遇到不同的人、不同的事 \
 美景、美食也不在话下 \
 回来之后也都有一肚子货可说 \
\
 读这些书的意义 \
 不在于从别人的书中学到多少 \
 而在于下定自己的决心 \
\
 出发！ \

\
 看完的亲帮忙顺手填一个简单的问卷，帮助我给大家提供更好的内容： \
\
 只要三个数字就可以了： \
\
 第一个数字：总体评分：3代表，2还不错，1一般，0差劲 \
 第二个数字：图片评分：3有意思，看了又看，2一般，看了一眼，1太差，压根没看，0不填 \
 第三个数字：文字评分：3有意思，看完了，2没看完就放弃了，1我是来看图的，0不填 \
\
 比如333就代表佳作，100代表打酱油哈~ \
