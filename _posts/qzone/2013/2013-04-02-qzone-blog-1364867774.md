 今晚收拾宿舍, 看到了大一时用的香水瓶, 已经见底了,我试着喷了一下,居然还有, 香味一下子倾泻在我的面前... \
 空气里仿佛又开始弥漫这那个炎热夏天的味道, 我刚进大学,一起都是新的,回忆里带着很多青涩的味道,好像是从香水里嗅出的~ \
\
 不同时期,我听的音乐不同,于是这些音乐都融入了我的情绪,再听时,脑海里都是不同时期的回忆片段. \
 曲婉婷的歌是去年下半年在北京实习的回忆~ \
 蔡淳佳的歌是大二到大三那段独学而无友的日子. \
 神秘园的&lt;月光水岸&gt;里面全是在新江中的宁静夜晚 \
 &lt;海上花&gt; 里是初中的某个迷惘的下午,不知道喜欢学什么,不知道喜欢什么样的菇凉 \
 &lt;蓝莲花&gt; 是在海南某个小村庄(演丰)的路上,骑着单车,奔向远方 \
 雅尼是复读冲刺的最后阶段,壮烈激昂 \
 one step left是第一次高考前夕 \
 ... ... \
\
 好多音乐已经融入了我的回忆,"1000个读者心中有一千个哈姆雷特"也是一样的道理吧, 大家都加入了自己对生活的理解. \
\
