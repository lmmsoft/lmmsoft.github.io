 中午约了南理工05级本科生09级硕士，刚在百度工作了一年的硕士屈啸吃饭，话题包含业余生活、运动（篮球、健身年卡）、工作压力、未来规划等等 \
 下午约了复旦计科大三的一个萌妹纸~ \
 晚上约的是复旦计科研究生二年级，本科在南理工的张珂学长~ \
 晚饭后碰到南理工09级一个很腻害的妹纸，没约出来，可能台湾了吧，然后就在房间里上上网了~ \

 具体： \
 a. 屈啸 \
 1. 我问了南理工研究生有关的情况，包括他在阿里实习一个月就被导师叫回去，回去之后也没事可做，老板的意思是“不能坏了实验室风气，大家都出去谁来干活”，我觉得：“尼玛啊，真是混蛋！！！“ \
 2. 然后在南理读研发的论文都好水啊，导师自己的论文也很水什么的，不多说了~（大家自行脑补） \
\
 b. xxx \
 1. 浙江绍兴人，高一开始练NOIP，高二省一，然后复旦千分考，自招直接录取，后来参加了高考，但档案还是被复旦拿走了 \
 2. 妈妈帮她强制选的专业，生物+一堆文科，最后录到生物（网上填志愿完全是妈妈操作，都没让女儿看） \
 3. 发现生物是个大坑，不喜欢，于是在大二升大三的时候转到计算机 \
 4. 妈妈强烈反对，居然打电话给计院院长办公室，要求拒绝收她的女儿 \
 5. 聊天过程中，明显感觉她妈妈对她的过度管理，比如电话里她会告诉妈妈每天考什么，甚至试卷最后一题没做出来什么的，我问为啥连这些都说，她答到“妈妈刷我教务处，看到我成绩出来了，只拿到B+的样子”，额，教务处密码都不保，还有什么自由的空间可言啊。。。 \
 6. 然后她妈妈还加了她的人人，她以前分享过一些重口味的东西，她妈居然打电话批评，并让她删掉 \
 7. 据说她妈希望她出国或是保研，为啥要读研也说不清，但每次回家都反对她直接工作（ps:生物本科毕业很难找工作，只能是初中生物老师什么的的，cs就很容易找工作的那种，然后生物出国比cs容易一些） \
 8. 下面换点别的话题 \
 9. 比如生活态度，软工和计科教学的不同（旦大cs和se完全分开教学，se基本都被大作业虐死，cs则蛋疼考试里的名词解释） \
\

 3. 周六要考GRE，时间非常紧张 \
