 今晚看了《非诚勿扰》记录一下我的收获： \
 1. 我喜欢有情趣，爱生活，有自己想法的女孩纸，但这样的女孩子不一定适合我 \
 2. 要解决他的问题，要么倾听，要么直接说你的问题在哪，怎么解决——乐嘉 \
 3. 要解决他的问题，乐老师太直接目的性太强，我觉得应该先从诸如爱好入手，切入他的生活，然后慢慢解决问题——女厨师 \
 4. 不能横竖一条心，一条路走到黑，要因地制宜，根据菇凉和形式思考她的”不“是”我要“还是”真的不要“的意思——黄菡说的大致意思 \
\

\
 最后赠送今晚我对妈妈说的话，她肯定没听进去。写到这里，或许你能队你有启发： \
\
 去年我在海南环岛，60%是退休老人，30%是学生，中年男子只有10%~ \
 所有人中，老家伙自行车都好，学生体力好，但车子都不行，中年人车子都不差，但青春都奉献给国家了~ \
 有个62岁的老头（退休2年）对我说，我退休后想找个业余爱好打发时间，天天打牌总不是个事，儿子就给我买了辆好自行车，一万块，平时我和俱乐部一起晚，很开心~ \
 有个中老年妇女（58岁，退休3年） 说，我以前是机关的，三高，骑车之后，体检所有指标都正常了，你看我的样纸，没觉得是58岁的人吧，感觉50左右的哈~ \
 有个中年男子，说身边人都羡慕他经常骑车出来玩啦，他就反问他们：”你们和我一样的工作和作息，空闲时间都打麻将去了，怪谁呀？“ \
\
 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ \
\
 说了半天，我是建议妈妈注意身体，别天天满大街乱跑。。。 \
 老爸的生活节奏就很好，有业余爱好，工作所占的比例逐年减少，退休之后的生活都安排的差不多了。 \
\
 废话不多说了，今晚心情不太好~ \
