\
 昨晚熬夜刷完一个姐姐博客里的十篇文章。这个姐姐一年也就2-3篇的样子，写的都是工作、生活。 \
\
 不仅篇篇精彩，而且顺着时间看下去，两篇之间的进步都相当的大。 \
 几乎每篇生活状态都会进步到一个新的层次，下一篇又会有更大的超脱。 \
 不仅生活进步大，事业也有晋  升，太完美了！ \
\
 有的东西我学不来 \
 我的东西我可以试试 \
\
 —————————————————————————————————————— \
\

\
 1. 升级NJUST GPA查询 \
 2. 读书 \
 3. 研究去台湾环岛的路线 \
\
 如果这三件事做得不错的话，我会来展示的~ \
 ———————————————————————————————————————— \
\
 看完的亲帮忙顺手填一个简单的问卷，帮助我给大家提供更好的内容： \
\
 只要三个数字就可以了： \
\
 第一个数字：总体评分：3代表，2还不错，1一般，0差劲 \
 第二个数字：图片评分：3有意思，看了又看，2一般，看了一眼，1太差，压根没看，0不填 \
 第三个数字：文字评分：3有意思，看完了，2没看完就放弃了，1我是来看图的，0不填 \
\
 比如333就代表佳作，100代表打酱油哈~ \
\
 谢谢大家 \
