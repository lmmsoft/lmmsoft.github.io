一 \
\
 我关注了一个台湾cs mm的博客一年多,通过看g+,linkedin,blog等,觉得人家:coding能力不差,学习成绩非常好,还拿了谷歌女生奖学金,硕士,发了若干paper,实习经验也很丰富,而且长得不错,生活有滋有味~ \
\
 现在再看她的状况,毕业半年,生活似乎单调了很多,工作也没有我想象中的好,我觉得这个女孩是技术很好,又有性别优势,想象中应该不输这个样子的呀? \
\
 二 \
\
 结合台湾行的一些感受: \
 1. 这一代台湾的孩子没有大陆的孩子能吃苦,岛上的生活没有大陆浮躁,更宁静,更安逸 \
 1. 这一代大陆的孩子国际化事业一定都不差,改革开放和留学潮让我们迅速追赶欧美 \
 1. 扁政府之后,台湾经济发展不容乐观,亚洲四小龙现在台湾是最差的吧 \
 1. roc的内需有限,国境太小,发展受限,在产业转型和什么,就IT而言比如: \
 a.大陆的人力成本依然有很大优势 \
 b.大陆的人才平均质量不如台湾,但优秀人才越来越多,这是个更大的金字塔,塔尖的人才数量大 \
 c.更多的公司把 \
 d. 互联网不仅仅是一个自足的行业,比如电商的巨大市场造就淘宝的繁荣, 有社交市场才有了腾讯,有在线广告市场才有了百度,台湾没这还没大的市场,缺乏出现大型互联网公司的土壤 \
 e. 微软把亚洲研究院放在了北京,IBM中国这几年接到了很多国有/私有大单,很多金融公司把亚洲的总部往上海迁(金融IT也是吸收人才的很大一环),等等,这些都有赖国家的迅速发展 \
\
 三 \
\
 现在再回过头看这个菇凉的"悲剧"(当然,不应该用"悲剧",至少她的收入水平,生活质量,人文素养还远在大陆挨踢民工之上), 不是她个人的,还是大环境造成的 \
\
 四 \
\
 前些日子在感叹: \
 古代必须拜师学艺,空有很好的素质,遇不到名师,亦是枉然 \
 现在,买书/主动学习很容易, 网络拜师也容易得多,尤其是的IT行业,互联网的发展,开源运动,让你能找到所有你想要的学习资料 \
\
 信息不对等现象已经大大缓解,只要你想学,总有足够你学习土壤,资料无限(网络书籍/开源软件),名师无限(开放课程,cousera)等 \
\
 五 \
\
 昨天在看英阿马岛战争,法国的飞鱼导弹真是神器,只是阿军9枚就击沉英军舰船2艘,击伤航母一架. \
 可是,阿军只从法国买来9枚,宣战后,法国站在英国一边,停售后面的订单,也停止了第三国的军售,阿军9枚打完就没有了 \
\
 这行业限制太严格,可能你在大陆研究武器一辈子也是那个水平,不能与国际接轨, 你的技术悲剧是行业形式造成的, 不是你不努力... \
\
 六 \
\
 扯多了 \
 收手吧 \
 还有些废话不多说了 \
\
 作个简单的总结: \
\
 我选对了好行业,赶上了好时候. \
 如果失败,都是自己的错,不能怪大环境~
