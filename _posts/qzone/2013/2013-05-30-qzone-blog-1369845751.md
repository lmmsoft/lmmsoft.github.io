好几天没发日志了，不是没写，实在是不能看，今天直接在网页上写，质量不敢恭维，很水哈！ \
\
 打个时间戳2013-05-30 00:23 \
 五月就快过去咯 \
\
 —————————————————————————————————— \
\
 今天： \
 1. 凌晨抱着电脑睡着了，手机也忘了充电（拖延症遇到了瞌睡） \
 2. 上午被二表哥的电话叫醒，10:30了，大号没电，打得小号，差点误了事 \
 3. 看到有人分享评教开始的文章，本来想发【评教助手】日志的，后来发现开源项目有点问题，就搁置了，今天白天再发哈 \
 4. 赶快出门，下雨了，然后上双龙大道前还走错了路，悲剧，后面继续悲剧了一会儿~ \
 5. 中午见到了大表哥表嫂表侄了，时隔7年，别来无恙 \
 6. 中午一起吃的，8点了快20个菜，根本吃不完， 口味很不错，价格不贵，不到500~连饮料不到600~ \
 7,. 然后去二表哥家坐坐，发现有个箱子丢在表嫂无锡的家里面了，然后下午发顺丰，估计今天白天就能到江浦了 \
 8. 下午去了夫子庙，第一次白天坐画舫，视野比夜晚好，情调稍差，好歹有点雨，也算是有点感觉~ \
 9. 然后去万达吃晚饭，没想到内环高架那么堵，迟到啦~ \
 10. 晚饭那家店最近生意不好，服务质量下降只是次要原因，关键是现在公款消费不给力！ \
 11. 然后回家，妈妈想让他们一家住新居的，可是，没有网，所以折腾一圈，还是来老宅住了，哈哈！ \
 12. 好累，我也要睡觉了，明天还有好多事要去做呢~ \
\
\
 其他： \
 1. 表嫂发现她说普通话的时候会夹杂很多英文单词，说无锡话的时候不会，我发现我说南京话的时候也不完全会夹杂英语单词，看样子家乡话的表达能力还是要强过普通话很多的~ \
 2. 中午吃完饭到表哥家，我和表哥都拿出电脑上网，都离不开网络~（他在做生意，我在借机执行人人的自曝计划） \
\
 再打个时间戳 \
