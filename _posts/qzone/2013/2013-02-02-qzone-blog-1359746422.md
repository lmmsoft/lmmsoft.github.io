\
 我对那些隐忍克制，想要改变命运，对家庭有强烈责任感，努力学习工作的人有着温暖的敬意。 \
 而对那些有反叛精神，愿意通过不断探索尝试重建价值观，坚持自己理想的人，我会毫不犹豫地给予崇拜。 \
\
 这是前天文章里新认识妹纸博客里新发的post，我很喜欢。 \
\
 其实我很奇怪，我的父亲是个保守派，母亲也是老实人，咋就养出我这个贼孩纸？ \
 当然，性格差距这么大，问题还是很多的。生活观念、态度不同，导致我和父母在太多方面没有共同语言，他们不能理解我。 \
\
 父亲虽然自身行为保守，但是对我还算开明，有些时候不同意我的观点，但是放我去做。 \
 母亲就不同了，就是不放我去做，非常固执 ，怎么说都不行。 \
\
 所以，我做事的时候得不到母亲的支持，父亲的支持也不会太多。 \
\
 因此，我做不了大事，而且现金流不足。创造力只能弄在一些小的事情上面。 \
\
 就不举例了吧，毕竟我举出来的例子一定是有利于我而不利于父母的事迹，哈哈。 \
\
 有时候我在想，如果我得到了父母的足够支持，那会怎样？ \
\
 1. 比现在牛叉很多很多，日子过得相当潇洒，不像现在这般压抑 \
 2. 某次玩大了，跌得很惨，然后好久爬不起来 \
\
 大家觉得呢？ \
