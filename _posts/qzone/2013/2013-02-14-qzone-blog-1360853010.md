 在人人上看到一个日志整理《身逢大时代》 <http://blog.renren.com/blog/230973616/895230206> ; \
 挺有意思的，说个的各地的回乡见闻，到处都在进步，到处都是计划，到处都有危机。

\
 今天和一个好友在人人上聊，说到：”我们的国家在富强，带动大家的收入、消费水平都在进步，但有些价格观念需要变化，比如卖一套房子就能粗去环游世界一圈哈~“ \
\
 然后想想，基本的温饱满足了之后，就可以丰富自己的文化生活了，大家有不同的玩法： \
 可能学会一门技能和一局赌博的花销一样； \
 环球旅行的花费和投资一套房子差不多； \
 学一门课可能和通关一个RPG投入的时间差不多； \
\
 每天看报纸、水社交网络的时间可能会惊人的多，每年见父母、亲友的机会可能很少很少 \
\
 。。。 。。。 \
\
 享受生活有一万种方法，不多说了  ~ \
