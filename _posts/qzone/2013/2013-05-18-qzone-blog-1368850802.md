空间右侧看到别人最近在山顶挥手的照片。只有天在上，更无山与齐，太漂亮了~ \
\
 登上真的是一件让人心旷神怡的事情。 \
\
 我喜欢爬山，很少做缆车，都用徒步的方式。 \
 看山间溪流岩石，看自然带变化，和好友畅谈海内奇闻，  想一番人世变换。。。 \
 爬到顶峰，眺望远方，一览众山小，开阔眼界，放大胸怀。。。 \
 过程无比享受，解决又异常精彩。 \
\
 我真的好喜欢爬山~ \
\
 下面回忆那些我爬过的山吧~ \
 【时间，顺序】 \
 小学： \
 北戴河-  [联峰山](http://lvyou.baidu.com/lianfengshan/)  （没印象了，山不高 ，我还小） \
 江浦-老鹰山（有点印象，妈妈单位组织的，山顶有电视塔，  希望  六月底和老爸去爬一次~  ） \
 四川-峨眉山（做汽车+缆车上去的） \
\
 初中： \
 2004：安徽-黄山（算是第一次爬山，爬了3-5个小时才到上面，然后发现这只是游览的开始，后面又走了二天山路，累死，下山果断缆车） \
 2005：四川-峨眉山（故地重游，同样玩法，ps:和父母单位的旅游团都玩不开。。。那也是最后一次和父母单位的旅游团玩了） \
\
 高中： \
 高中期间出去玩的机会少，没爬过大山，紫金山倒是又几次，还有一次sb把自行车扛上去，发现下山路在修，又扛下来。。。 \
\
 高中毕业： \
 2009：徐州-云龙山（这不是山） \
 2009：安徽-九华山（爬了最高的十王峰，不过上山的一半时做缆车的~） \
 2009：陕西-华山 （夜爬华山，凌晨在东峰租了大衣睡在岩石上看英仙座流星雨，太过瘾了，那次把东南西北中五个峰都水了一遍） \
\
 大学： \
 2009：安徽-云台山，尹和我按照西祠胡同上的图文攻略从后山小路上去，逃票+去了别人去不了的小景点，帅呆了~ \
 ps:2009年二战高考后玩得真TM爽，太压抑了，是要好好放松~ \
\
 2010：安徽-九华山（这次爬的是百岁宫那条线，没什么难度） \
 2010：山西-五台山（这个大朝台之旅是我经历过的最困难的徒步行程了吧，三天徒步走了完东南西北中五台，大概100kg，还是100华里？记不清，一下子也没搜到，当时漫天大雪，道路难行，容易摔倒，第二天晚上我的腿已经很疼很疼了，还有南台没爬，只能买点口服止痛药，继续上~） \
\
 2011：河南-云台山（顶峰不难，好像是2个小时上下的节奏，很多小孩子都能上去ps:其实我爬过的大部分山路上都看到小孩子了，所以我们平时玩景点的山都没什么难度，大家都可以爬哈~） \
 2011：湖北-武当山（我从琼台三观上的，缆车要排队好久，爬山也就2小时？记不清了，反正路上看到小朋友在爬，妈妈说给叔叔让道，为什么不是哥哥呢T\_T） \
\
 2012，2013： \
 果然，两年没爬山了，空虚啊！ \
\
 下一站？ \
 泰山，我一直想爬~ \
\
 爸爸有两张“昂头天外”位置的泰山照片 ， \
 一张是20几岁的时候，一张是40多岁； \
 一张瘦白，一张微胖； \
 一张活力四射，一张成熟稳重； \
 两张照片放在相册的同一位置，太有意思了~ \
 我也要拍一张泰山的照片~ \
\
 恰值毕业季， 此事可期，可成！ \
