一 \

 我给我的二月的定义是脱产期， 从月初到月末，没有一个工作日，多好啊。 \
\
 然后回忆里很多人在脱产期做了很多有意义是事情，比如出去旅行、读了很多有意义的书、体验某一种生活，等等。 \
\
 好像无一例外，脱产期过得好的人，在回来重新工作后，都焕发出新的活力。事业或生活斗殴有了长足的改变。 \
\
 然后，我就告诉自己，这是我最后的假期了，毕业后就要粗去工作咯，再难找到这么长的假期了，一定要好好利用好这仅有28天的一个月。 \
\
 脑子里最先蹦出来的，尽是些：开放课程、产品经理技能、开源软件、机器学习这些字眼。 \
\
 烦透了！！！ \
\

二 \

 “以退为进” 是我高中时的政治老师陈蜚蜚教我的， 当时的说法是加班加点学习还是上不去，不如好好休息，提高效率。跳出框架，换个角度取得更大进步。 \
\
 回想我的大学生活，不完整啊不完整！ \
\
 学业上，平均分75，渣渣啊！ \
 出去玩，也不算少，但质量不咋高，如果以基友YXJ为100分的话，我也不会超过75分。 \
 当然啦，75分和中国足球的排名一样，还算是高的了！某些方面就好像我国的人均教育、医疗投入一样，不及格！ \
\
 就比如找女朋友这个地方，0分啊，一个都没找到啊！如果算上那为数不多的失败经历话，10分不能再多了，比牛人少个0~ \
 这两年活动室没有妹纸的gg在找到工作后都很快就有了啊，他们是所有人啊，  怎么我  特么  就成了特例了呢！！ \
\
 类似的问题，比如衣着啦，比如头发啦，比如生活作息啦，我都不及格啊！！！ \
\

三

\
 二月的工作计划迄今任没完成，也不准备订那些计划了。 \
\
 不过呢，我的白板上多了这么一些字： \
\
 1. 练驾驶 \
 2. 买衣服(XX类型X件) \
 3. 买鞋子 \
 4. 理发 \
 ………… \
\

四

\
 前几天回学校没有去找导师，对啊，找导师干嘛呢，自寻烦恼，见基友、约妹纸是正道啊~ \
\
 大学生活只剩下半年了，前面三年半解决了主要矛盾，到了除杂草的时候咯~ \
\
 平衡！ \
