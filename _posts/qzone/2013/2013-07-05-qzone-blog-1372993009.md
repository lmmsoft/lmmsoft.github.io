时间轴 \
 1. 早上睡懒觉，起床码字 \
 2. 中午12点出门，和亨军一起午餐 \
 3. 下午到了西湖，本来想骑车环湖的，后来发现湖东岸都不能靠着湖骑等诸多不便，就改成全程徒步了，到一个地方在西湖地图上标记一下，期间还联系晚饭、人人微博传图、下载并收听西湖有关的歌曲、游览雷峰塔景区等 \
 4. 晚饭约了个学妹，金陵中学2006级初中实验班的（我是2005的~），她在外婆家排队+等我40分钟，我到的时候正好号也到了，嘻嘻 \
 5. 晚饭之后回到亨军屋，走路相当累，洗完澡就不行了，衣服也没洗，日志也没写，不能动啊，我的体能实在是不行~ \
\
 —————————— \
 具体： \
 a. 听故事 \
 1. 中午和亨军一起吃饭，我们聊  [@刘铁俊](http://user.qzone.qq.com/491507927/)  [@陈凯健](http://user.qzone.qq.com/895515692/)  实况菜比，被我们虐的故事，太轻松啦，以后不会遇到这么弱的对手啦~ \
\
 b. 听故事 \
 1. 晚上吃饭也是听故事，姑凉很能说，我也没啥能岔的，所幸认真听听好了~ \
 2. 姑凉初中高中都是实验班的，至少在一个校园里活了五年，共同好友很多，居然一直不认识哈，认识是装妹子好友大增之后的事情了， \
 看来一张漂亮的皮不仅是认识别人的利器，也会把人吸引过来哈~ \
 3. 然后说了很多东西， \
\
 比如学习生活：高中搞了各种竞赛，数学物理化学生物。。。都没得保送生资格，校荐南大自招考得还不错，没竞赛加分，跪了；自荐浙大自招考上，后来就学一直很喜欢的临床医学（本硕，计划读博的样子） \
\
 比如八卦：金凤仪女儿的故事（百般阻挠-&gt;默认） \
\
 比如爱好：我们都是从初中开始看国家地理，然后爱上了地理，旅行什么的。她本来还想学地理，加上编辑技术，进地理杂志工作什么的，后来还是觉得地理做为爱好，学一门其他手艺比较好。（我当年也有在南大读什么旅游管理的计划，只是我考不上南大而已，哈哈） \
\
 比如共同好友： \
 1. 发现05 06实验班学CS的不算多，但大部分在微软实习过，比如05的曹正王晨lmm，06的王明苑吴为，什么的。。。我感觉还是教育质量比较高吧，学生后期发展比较好，出去的学子都能在各自领域里做得很好，太赞了~ \
 2. 然后实验班圈子比普通班混得好很多，各种同学在各自学校都做得不错，尤其是学霸比较多，然后申请出国什么的，好多吖~ \
\
 比如大学和中学的联系： \
 1. 我们知道一个拿了fdu十佳毕业生，还有一个拿了ustc的最高的奖学金，学校都把家长、高中老师、甚至高中校长喊过去颁奖了，扬眉吐气~ \
 2. 然后各校会把优秀毕业生传回各自高中，很多学校都会贴出来把，这个的比例应该能反映出中学教育的质量，甚至我觉得比高考分数更有长远意义~ \
\
 得最多的还是菇凉的游记： \
 1. 她的人人上有，有空我要去详细看看 \
 2. 大一加了摄影协会，后来买了相机，每次出门都一个手登山杖，一手单反；大一暑假去贵州支教20天~ \
 3. 大二约了一个好友，利用周末时间，骑小破车跑遍杭州的大小景点；大二暑假本来想去云南支教+玩，后来干脆不去，来年纯玩了 \
 4. 大三暴走黄山、雪中泰山等等，攒了一年的攻略，在云南徒步一个月，四川20天，7-1入滇，8-1入蜀，一个人上路，一路拐人，各种玩~ \
 5. 攻略超级强大，在云南31天，每天的安排都算好了，旅社都是提前2个月订的，床位非常有保证，然后有29天都按计划行动，太强啦！！！ \
 6. 现在大四暑假，在邵逸夫医院实习，收心啦~ \
