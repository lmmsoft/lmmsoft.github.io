 12-05-10 玄武湖 （很悲伤的一天，百度霸面等了一天仍不给机会，有人的照片也比单纯是景色的丑） \
\
 其实这篇是2013-03-01 晚想写的，但是拖延了，我也不想恋战，快速写完，不考虑质量咯 \
\
 ———————————————————————————————————————— \
\
 以我和一个好基友的聊天内容为基础： \
\
 背景：基友在赌博，无心学术，找了一个培训班的工作，每个周末去上课，课酬还不错 \
\
 我的观点：这是典型的用时间换金钱案例，时间花掉了，收获只有时间，其他的经验和未来的工作毫不相干，没有隐形价值 \
\
 我的反问：  咋就不用时间换未来的收入呢？ \
\
 基友答：  看不到未来 ![](/images/qzone/b527edf448c6b1d9d5896bd9.gif)\
\
 我的回答：  我去年此时可没想到今天噢，但我知道自己走的路不歪。。。做学生时就要好好玩哒，赚钱的事情工作后再去，赚到钱就走人吧，(培训机构)不是久留之地~~ \
\
 ———————————————————————————————————————— \
\
 然后我就问自己一个问题： \
\
 “  去年此时可没想到今天噢”，我生命中是不是每一刻都不能真确想象一年后的样子呢？ \
\
 其实，上大学以前，都是可以想象的，甚至我考试的成绩也是可以想象出来的，只是我不愿意承认我是个学渣 \
\
 上大学之后，基本没想象过了，时代发展太快，我也是个喜欢新鲜事物的人，这几年自身的变化确实大。 \
\
 工作后，我会是什么样子？想象自己的未来和完成职业规划是两码事，一个是按部就班，稳扎稳打；另一个是amamzing &amp; surprise~ \
\
 我想，40岁之前最好每年都有惊喜，退休后最好生活能够稳定吧~ \
