今天想到几条，先写一点，以后慢慢补充~ \
\
 0. 严格【记账】，最近花钱如流水，以后也不要做月光族~ \
 1. 搞张suda/seu/ustc的【借书证】，经常去浏览群书，尤其是非技术类的~ \
 2. 保持【桌面整洁】，这样会提升工作效率和心情 \
 3. 【早睡早起】虽然我知道这对你很难 \
 4. 【少即是多】房间里少带东西，少带书籍，提高单品利用率(这两天收拾学校宿舍，太多投资浪费了~) \
 5. 【坚持运动】的习惯，比如每日慢跑5km，每周骑行100km，每周一场足球等等，有一个能坚持的就好了~ \
 6. 【坚持写作】 写作让人深刻~ \
 7. 【行动力】“为那些真正想做的事，付诸行动”感想敢做，每月都要有一件一年内难忘的事情 \
 8. 【反馈】 每周至少总结一次，不自省容易变成老油条 \
 9. 【主题阅读】 人人上的分享杂乱无章，只有广度。深度需要专业书籍配合主题文章~（每月抽两个半天阅读思考写作，不算过分） \
 10. 【工欲善其事必先利其器】为效率投资，比如换一个不卡的手机~ \
 11. 【专注】 混饭用的硬技能不能落后，软技能 \
 12. 【博客】 到了经营个人博客的时候了,八月前对社交网站的使用进行重新（定位/划分时间/优先级） \
 13. 【饮食】 抽空研究膳食、不会有错的； \
 14. 【充电】别在办公室呆太久，晚上和周末要有另一番世界~ \
\
 未完待续~
