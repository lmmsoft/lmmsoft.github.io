昨天进城玩了一圈，随便写点吧，以后机会不多了~ \
\
 时间轴 \
 1. 上午去医院看爷爷 \
 2. 中午和叔叔姑姑表妹一起吃四川酒家 \
 3. 下午和汤包、神猴 \
 4. 晚上看舜天的猪协杯 \
\
\
 感悟 \
 1. 讲到考公务员问题，叔叔说，很多人先从容易进的基层进去，然后再谋求调动/重考，这样攒了工作经验，成功率也高，比一步到位靠谱 \
 2. 低调，就不会有太多人去针对你做一些事 \
 3. 底子厚的人，总归是有好的出路，有的人可能因为某一次两次正确的选择而突飞猛进，但底子厚的人厚积薄发，稳定输出，健康发展~ \
 4. 混日子的人，迟早受到惩罚，而且在一些大的选择或拐弯点上，特变能检验黑猫白猫~ \
 5. 续3，专业呀，学校呀，都是次要条件，决定一个人发展的还是某些内在的特质，听了些老同学的故事，原来那些牛光闪闪的家伙，多年不见，现在也各种神奇~ \
 6. 四川酒家是几十年老店，但是现在的管理、服务质量，实在是太差劲了，怪不得这些年走了这么大的下坡路~ \
 7. 猪协杯，算了，没什么好说的 \
