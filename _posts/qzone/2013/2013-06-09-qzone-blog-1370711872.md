 再说今天的经历吧： \
 （好困，没功夫上图了） \
 part1：翠屏山 \
 1. 9点闹钟，快10点才起床 \
 2. 出发，撞空调，瘪了一块T\_T \
 3. 11:10到达翠屏国际城，龙兄带我去爬翠屏山，山下这房子真是好地方，跑步散步什么的， 环境真心好 \
 4. 12:00到龙兄家坐坐，龙搜在家剥毛豆，家庭主妇的样纸哈~ \

5. 和龙兄吹牛到中午12:30，银行对私前台太累，五月辞职了，龙嫂是对公前台，三月也裸辞了。毕业的第一年，真难熬~ \
 6. 12:30龙兄龙嫂带我去吃【人民公社】，口味不错，量也大，3人5个菜，根本吃不完 \
 7.席间一如既往地吃牛，我和龙兄都是比较二的人，很对胃口，哈哈！ \
 8. 后来基本在聊工作，我介绍了我的情况，他们也介绍各自的规划，都是想回归老本行(本科专业)的意思。 \
 9. 大家都谈谈对于工作，职场的理解，针对一些问题交换看法，不细表了 \
 10. 饭后散伙 \
 11. 我联系了在南广读书的邻居小弟弟，但是他有课，今天不能接待我，无论我怎么说都不行，若干短信来回后，我放弃了去南广的计划 \
 12. 我知道他是个乖孩子，不会翘课的。。。不多说了，反正我不是好学生。 \
\

part2：东南大学 \
\
 SEU昨晚联系了四个人，今天见了三个，非常满意 \
\
 1. 16:00-17:15和芹姐在一起，我们游览了九龙湖公园，里面有个垂钓池，租鱼竿10元/下午，鲫鱼13元一斤，挺有意思~ \
 2. 和芹姐的交流内容集中于找工作，后来给她讲了我的求职经历，我感觉讲的不怎么样，据她晚上的状态里说”富有正能量“~ \
 3. 芹姐是积极进取的人，培优班的，成绩非常好；我感觉她是那种想法不很多，但总能把事情很好完成；而我似乎完全相反，想法多，但很多事情是根本完不成的。她是比较硬的那种，我感觉自己太软了~ \
 4. 虽然我们风格差异很大，但还是有共同点的，比如都是复读生，哈哈！ \
\
 C王 \
 1. 和C王见面后就出去吃晚饭了，席间叙旧+吹牛，我着重吹嘘了考公务员的经历，仔细想想还真蛮有意思的 \
 2. c王提到一个观点”CS研究生其实学不到什么东西，基本都在实验室里做老师接的各种项目“，然后他反问”和勐这样的研究生，如何和我、兄赵这样的本科生抗衡“，很有意思的w问题，这里不展开了 \
 3. 饭后看到南门外的”秣陵杏花村“，就进去看看了，是个农庄，暂时不要钱，感觉还不错~ \
 4. 然后就一起去找兄赵吹牛了 \
\
 兄赵 \
 1. 昨晚人人上@ 了兄赵，他没回，不理我，结果很巧被我在橘园食堂外面撞见了，没办法，只得答应和我晚上见面，哈哈 \
 2. C王居然借到个讨论室，SEU也有focus room，真不容易，然后我想到我要是在主楼里接待同学，应该也找不到地方把，微软的办公楼设计还是有很多优越的地方，工作时不觉得，回来后就看到差距了，然后我估计六号门的新实验楼也没这样的设计~ \
 3. 我觉得晚上的聊天非常精彩，主要是我在问，兄赵在回答，我记了很多笔记，纸上有19条，现在没精力整理到这里来的，下面我选几个有代表性的简单提一下 \
\
 a. 《心理学》是属于个人的《哲学》 \
 b. ”KDD trace 第四，说明我就是世界前五~“ \
 c. 主人翁意识 \
 d. 调得一手好参 \
 e. 数学成绩不能表现我对数学的理解，他们（分高的），考完全忘了 \
 f. 能做东西的，比搞理论的强 \
 g. 《程序猿思维训练》 \
 h. 属于自己的”决策树“ \
 i. 观点，经验，而不是答案 \
