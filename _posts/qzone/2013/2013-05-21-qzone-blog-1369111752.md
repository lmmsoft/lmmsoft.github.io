本来应该出去吃饭的，突然有点体悟，一吐为快~ \
\
 一 \
 （算了， 还是不交待背景了，倒叙什么的，饿） \
\
 二 \
 每次进入一个新的比较好的环境都会缺乏自信，觉得自己是混进来的，然后过一年或者混熟就好多了，自己也不比他们差~ \
 进初中和大学时，应该自己分低/比较弱，所以很缺乏自信，就是这个样子的，身边的人确实都很腻害，我的态度也会很好，相对踏实，最后结果都不太差~ \
\
 三 \
 进高中时，倒是有了自信（初中是实验班，高中掉到普通班） ，做事反而浮躁，态度恶劣，最后结果也很差（复读去了） \
\
 四 \
 马上要进一家大公司，作为弱校本科，算是里面最弱的人了。我估计自己的智商也在公司的平均值之下。 \
 之前实习的半年，确实有这样的体会，一开始我做事差劲得不行，老板交待的任务总是完不成，所幸态度好，老板也愿意教我，有了不少进步~ \
\
 现在毕业又要去了， 最近心态有点浮，这不是好事，还是得【低姿态，高要求】要不然注定摔跟头~ \
\
 五 \
 总结：满招损，谦受益~ \
