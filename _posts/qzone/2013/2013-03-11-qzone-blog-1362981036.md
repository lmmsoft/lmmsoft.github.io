本来发人人上的,扣扣空间不应该发,但估计有的人看不到我的人人,而且这篇对他们有点用,就把源码放这里,可读性凑合~ \
\

这篇比较水，全是【经历】，没有太多【经验技巧】，又臭又长，写给未来的自己~

\

# 背景：

\

1. 南京某211大学 软件工程 本科

2. 学渣，平均分7X，挂过科不能保研

3. 数据结构和算法弱，《数据结构》考了69分，《算法》高一点，79分

4. 没得过奖学金

5. 没参加过数学建模比赛和 ICPC区域赛/邀请赛

6. 在学校里没有导师，没有跟老师做过正规项目，“科研训练”选的几个题目都被踢了，没有老师要~

7. 没进过实验室，没读过论文，更没做过research

8. 没做过开源项目，不会Linux，javascript，python等，更不会函数式编程

\

#分析：

\

1. GPA太低，读研的道路被封死，无论是国内还是过外，考研也完全没信心。只能去不太关注成绩的工业界试一试，找一丝容身之低

2. 由于背景、能力都太差，只能采取笨鸟先飞战略

\

# 策略：

\

## “菜鸟扫盲”

1. 大三下（2012年3月份）开始咨询一些学长，了解求职的基本过程（学长们都特别热情(\*^\_\_^\*)比如黎叔~ ）

2. 在网上搜索面经、（应届生、大街、人人的几个公共主页等），看看牛人是怎么准备的

\

## “闭关修炼”

1. 看了邹欣的《编程之美》、何海涛的《剑指Offer》，July的[博客]( <http://blog.csdn.net/v_JULY_v> )，李刚的书等等

2. 由于基础差，采取死记硬背的办法，默写常见的数据结构、算法

3. 墙上贴了几张白纸，模拟白板写代码

1. 了解各大公司面试特点，自我应试教育~

\

\

# 找实习流程：

\

## “初出茅庐”

1. 大三下（2012年3月份）开始找实习，海投

2. 简历2月份就写好了，用了cw的模板，求职受挫期间兄赵帮忙看过，删了废话（哪些是废话，我赞同[这里]( <http://blog.renren.com/blog/230940749/897283901> )的观点）

\

## “陷入僵局”

\

那一阵子好像每个周末都往南大鼓楼校区跑，各种笔试~

\

- 4-7 微软笔试（第一次笔试）

- 4-14 腾讯笔试，挂

- 4-17 微软面试（第一次面试，挂）

- 4-21 ebay笔试+面试，小米笔试（挂）

- 4-27 百度宣讲会，主持人不是度娘，没意思~

- 5-6 百度笔试（挂）

- 5-28 360面试（挂），ebay突袭电面（挂）

- 其他还参加过一个小公司和一个创业公司的宣讲+笔试+面试，了解市场情况~

\

忙了快两个月，除了最后打酱油的小公司和创业公司，其他全挂了~

\

不过确实应该挂，比如微软面试问到2个《编程之美》原题，我都看过的，一个忘了解法，另一个书上解法想起来了，变了一下就不会了，这熊样就应该挂~

\

## “意外侥幸”

- 6-1 微软校园行， 听了马维英博士的演讲，拿了一张MSRA招实习生的flyer【XXXX】, 然后看到MSRA主页上的JD，抱着试一试的想法，找肉神内推

- 6-16 六级考完，2个010的未接电话，回拨，15分钟突袭一面

- 几天之后，考完最后一门的那天，又接到二面的突袭，当时我在食堂里，刚买了米线，于是推到半小时后，赶快吃完跑回宿舍，还没拿出草稿纸，就接到了电话。。。面试里有一道dp没做出来，非常懊恼，幸运的是下午接到了offer，真是悲喜交加的一天吖~

- 事后总结：运气成分居多，问的几个题恰好以前都看过，另外六月底的时候大牛基本都找到实习了，竞争对手不强吧，总之我混入MSRA-UR组，搞web开发去咯~

\

# 找工作流程：

\

转眼间，秋招的季节来临了

\

MSRA有一系列的求职讲座，既有分别针对Dev,PM,和RSDE的模拟面试，也有求职经验分享会~

\

组里的Mangers都非常好，老板的老板给我们开过的职业规划做过咨询，我的mentor也利用周末给我们几个实习生进行过面试技巧的训练，平时的帮改简历、帮忙推荐什么的，更是不在话下~

\

\

## “当头一棒”

1. STC转正 一面二面8-18 终面8-30

2. google 9-13onsite 9-14电话告知挂了

3. 前两次面试都是非常想去的大公司，全挂，当时真的好伤心~

## “四面楚歌”

经历了"当头棒喝"之后，我必须扩大投简历的面，开始海投，开始了更悲催的一段经历~

- 网申挂：

- 其实网申挂的应该蛮多的，有个我曾经参加过实习生的面试也直接收拒信了， 所以“你的信息留在我们的库里面，欢迎下次再来”，都是骗人的，校招还是要找内推)

- 笔试挂：

- 雅虎、腾讯、百度、搜狗、豆瓣、morgan IT，亚马逊，完美时空，优酷土豆

- 微博：11-28 一面过，二面挂，[我的面经]( <http://blog.renren.com/blog/249488460/885253270> )

- 美团：11-24 一个下午三轮，感觉还行，结果挂了，[面经]( <http://blog.renren.com/blog/249488460/884691609> )

- 小米：9-22 on-site，一直没答复，@刘铁俊 也不帮我去问问，笨死咯，哼！[面经]( <http://blog.renren.com/blog/249488460/872575379> )

- 遨游：10-11 2轮挂，面经写了好像没发~

- 人人第一次：10-31 最糟糕的一次面试经历。。。(算了，这是人人的地盘，我就不多说了，面试官是搞开放平台的，嗯！)

## “峰回路转”

1. 九月份基本没什么面试，还错过了很多笔试和内推，后期才刻意去霸笔一些~

1. 十月份也没什么面试，因为笔试都挂了

1. 到了11月才迎来一些面试机会~

1. 我进入了STC的校招流程，四面之后接到了offer~

1. 在叶文大哥的照顾下，我获得了又一次从网的面试机会，三面之后接到了offer，从网的薪水是我拿到的最高的喔~

1. 之前还面了去哪儿，二面就见到了CTO，并且拿到了我第一个offer~（基本上每个小行业top1的公司我都投了，比如美团、优酷等，面试的过程其实也是加深了解的过程嘛~）

\

\

## “尘埃落定”

\

关于最终签约，有太多的因素需要考虑，我列了一张表，对仅有的3个offer进行打分，考虑了不少于：薪水、工作氛围、职业规划、培训机会、户口、所在城市(发展、IT氛围、安家难易，离老家远近)等因素，然后加权综合再加上一些对父母的妥协，作出最后的决定，签了STC苏州 ps:薪水是最少的，离家是最近滴~

\

\

## 鉴于上面干货太少，补充一点废话：

1. 网上资源很多，就看你会不会搜，搜到会不会用

2. IT行业就业形势相对较好，努力都会有回报

3. 用一个excel表格跟踪：网申、笔试、面试、offer进度，适当的时候可以礼貌得发邮件去催HR~

4. 多多和学长保持联系，不要过河拆桥，拿到内推的面试资格就断了联系。还可以约吃饭聊聊天，还可以让帮忙问问feedback呢~

5. 准备工作尽可能充分：

- 简历里每个项目经历都要准备好各种可能的问题，常见的诸如what?why?how to improve?等等

- 我简历里放了个叫"把妹助手"的项目经验，然后所有的年前男性面试官都会仔细了解，然后进入我设计好的答案里~

- 某次软件测试视频面试之前，我做了：

1. 练习常见代码

2. 基本算法、数据结构

3. 软件测试基本功

4. 查询skype面试技巧

5. 准备好若干问面试官的问题

1. 关于微软中国面试的情况，我觉得[这篇]( <http://page.renren.com/601505826/note/895922140> )写得不错~
