刚才整理书桌,把一堆杂书(包括旅游,文化,心理,灵修)收起来,放到箱子里. \
\
 大四下的开始,有好多的规划和幻想. \
 可事到如今,基本都荒芜了,毕业论文也迫在眉睫. \
 唯一有点价值的台湾行,游记也一直欠着,再不写有的回忆都要忘掉了... \
\
 手头还有不少事情要做, \
 就拿本周来说吧, \
 周日公务员复试要去的,早上七点半就要到莫愁中专了,虽然是"荣誉之战",而不是"背水一战",但还是要提前准备的吧?上周模拟了一下,很不理想唉~ \
 周日还有ACM/ICPC的邀请赛,和省考冲突了,最好的状态是省考我在前几个面试,然后火速赶回学校打酱油 \
 周六是练习赛,既然周日危险,周六就必须去啦,然后晚上有群聚等等,也是可以去的~ \
 同时周五周六还有很多认识的参赛选手来到南理工,可能要约几个吃饭逛校园什么的~ \
 周六晚上还有十佳歌手绝赛,虽然我今天睡过了,忘了去排票,但还是想能买一张票什么的.这是南理工最大的校园活动了吧,以前没去过,毕业前总该体验一回~ \
 ... ... \
\
 好多想做的事情呀,你们怎么就冲突了呢? \
 我怎么就这么弱,不能把这些书做的井井有条呢? \
\
 标题是&lt;悔恨&gt;,我悔之前浪费掉的时间,恨那些满足不了的欲望... \
 真难过T\_T \
