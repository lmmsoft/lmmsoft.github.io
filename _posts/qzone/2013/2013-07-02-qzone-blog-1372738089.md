昨天2013-07-01，体力消耗挺大的，再加上我的懒散，晚上倒床就睡了，凌晨四点才发现被子没盖，空调16度。。。还好没感冒，噢耶！ \
\
 照例先上时间轴 \
 10:30 惊醒，想起中午还有约，果断起床开始水人人 \
 11:30 见到徒弟  [@陈凯健](http://user.qzone.qq.com/895515692/)  ，一起在张江传奇广场吃了东方既白，然后甜品鲜芋仙，随后在张江艺术公园里面转了一圈，最后去了他的公司，上海华勤，在会议室又聊了好一会儿。恰好是软蛋入职的好日子，祝蛋蛋有一个美好的明天~ \
 14:00 结束和蛋蛋的见面，会汤臣三期休息，码字~ \
 18:00 和费腾学长在张江镇的川香一号见面，晚餐，详谈甚欢 \
 20:30 先把房间钥匙还给笑有泪，然后蛋蛋带我去外滩，逛商店、看黄浦江、走外摆渡桥，等等，总觉得外滩的包装不如“幻彩咏香江”？？？ \
\
 然后写点重点吧，今天比较少： \
\
 a. with费腾 \
 0. 费老穿着汗衫、大裤衩、拖鞋，骑着电动自行车就来了，很有张江男的风范！ \
 1. 费腾在创业公司工作，似乎对于行业、市场没有太多的关注，用他的话说，就是“做一天和尚撞一天钟”，真好现在的收入比原来在盛大高一些，何乐而不为呢？（ps:我追问了一些有关内部开发，软件设计考虑的问题（（对结果表示担忧））然后费老也适时终止了这个话题） \
 2. 他是这家公司工号为4的员工，但不是创始人，不必担太多的责任，比如最基本的“把大家养活” ，所以日子过得比较自在，加班也不算太多。 \
 3. 问他老东家现在怎样？他说比较惨，举个例子就是原来部门一大半工工资比他高，离职两年之后，目前只有两个比他高了~ \
 4. 还聊到其他在创业的学长，比如一个搞手机游戏的，搞了几年，不瘟不火，其实能活到今天，已经强于超过80%的创业者了吧，我觉得~ \
 5. 然后费老提到工作干得不爽的话可能会考个研什么的，我驳斥了他准备考回南京的想法（当然不是njust），告诉他南京的s.b导师一丘之貉云云，弄不好就鱼死网破了，费老在业界混了这么久，不可能看得上这些教书袋的。。。然后我建议考北大软院之类的地方，性价比高，或者去hk混个授课硕士，反正费老读书是不差钱的，他告诉他真的不知道国内还有【软院】这种奇葩的存在，回去研究研究~ \
 6. 费老板经常能引经据典，讲很多故事，仔细一问，原来他喜欢看史书，二十五史看过一些，世说新语、文心雕龙什么的，都看过，都是直接读文言的，不简单啊，真腻害！ \
 7. 然后开玩笑问为啥不考一个历史学硕士什么的，他说他圈子里这方面最好的在复旦读完中文硕士，然后回老家当社区大妈了，实在不好找工作。。。挨踢民工好歹能有口饭吃啊 \
 8. 后来费腾还有一些关于长的好看的学姐之类的八卦话题，调味菜而已，在此不表~ \
\
 b.外滩 \
 写不动了。。。 \
\
 c. 給蛋蛋职业规划的建议 \
 说了好多，在此不细说，因为不怎么系统。 \
 最后让他做一份“战略规划”给我看，一周时间，我给很多人布置过这样的作业，没人一个人完成（后来我也不追了，没精力），希望蛋蛋不要让我失望，萌萌姐的亲传徒弟啊！
