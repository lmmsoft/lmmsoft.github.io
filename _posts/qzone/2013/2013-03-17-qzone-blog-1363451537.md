今天下午看了《风雨哈佛路》，本来想找校园影片看的（我的校园生活快结束了），但是发现这只是励志片，没有我想要的校园内容。 \
\
 不过呢，我还是记录一些有感触的台词：（听译，错误在所难免） \
\
 1.  figure out my life, do people really do that?  计划我的生活，人们真的这么做么？ \
 这是在说贫民窟里很多人都没有figure out自己的生活，其实我感觉，身边没规划自己生活的人太多了，我在大三之前也没规划，日复一日地混日子，后来看到一些学长的进步过程，受到启发，也跟着走到了今天，很多都是被逼出来的。现在有了更多的自由，愈发觉得要好好规划自己的生活，混日子都是在做相似的事情，而规划能让自己做一些特别的暑期，穆里尼奥说"Iam the special one"，这一定有规划在里面，他在英超说过三大愿望(可能有误)“体验意甲，西甲，指教葡萄牙国家队”，现在一步一步，西甲和意甲联赛杯赛冠军都入手了，厮混的教练可能都想着如何保帅位，最后的下场都是卷铺盖走人，不可能像穆帅一样每次都激流勇退，让球迷和球员怀念~ \
\
 ps:说了半天，不就是"人无远虑，必有近忧" 嘛，废话真多。 \
\
 2.  I can push myself, push myself and make my life good \
 我对自己太宽容了，把自己长期放在舒适区域，其实如果平时能对自己更push一点，一定有更多的acheivement，我对自己的能力有信心，对自己的专注力和意志没信心。。。 \
\
 3.  I blow this ,but you can do this \
 这是父亲对女儿说的话，我对自己这么说：“之前搞砸的事情，都过去了，以后别再犯错了，好不好，乖~” \
\
 4. 电影讲到了生存环境的改变，今晚和别人聊天时也提到这个话题 \
 我大一时分配的宿舍很糟糕，宿舍里有两个整体打游戏的，经常周五喊一堆人来宿舍打一个通宵， 周六早上七点才睡，吵死了，我早上八点还要参加诸如模拟联合国之类的活动，矛盾非常大。 \
 s1:我约过学导王鸿轩聊过，他很友好地请我喝了奶茶，但没给我太好的建议，只能表态有空去宿舍查查~ \
 s2:我尝试在学校里与周边找过租房，甚至还考虑过让家里在学校里面买房 \
 s3:yxj宿舍是八人间睡四人，多一张床，大一下的期末，我在那里过，不仅睡得好觉，旁边宿舍有电视机，还有世界杯看（当时我们09的宿舍完全没有网络） \
 s4: 最终的solution quite simple, 暑期集训时从刘铁俊和方胖子那里听说他们902A里有一间，然后我在电话里找刚上任的高飞倒了点苦水，期末没考好什么的，就顺利搬进去了，要是田野可能麻烦一点~ \
\
 反正这些年为了生存环境，做了不少努力，最近又去yxj的宿舍，博士公寓。一个人睡两张床，配了23寸显示器，机械键盘，打印机，  哇咔咔，爽！
