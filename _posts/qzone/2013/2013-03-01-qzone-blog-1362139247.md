 红字为2013-05-26 update,距离离校一个月，一个月之后再更新一下~ \
\
 作为即将毕业老油条，我要好好享受最后半学期学生生涯的自由，本学期的主题是”吃喝玩乐“ \
\
 吃  ：约了好吃的好友yxj，把那些一直想去但没去过的餐馆吃个遍，限南京市内 \
 我们只吃了一号门周边的几个地方，错误都在我 \
\
 喝  ：控制体重，严禁碳酸饮料，散伙饭也少喝酒为宜 \
 最近每天喝各种饮料（奶茶/果粒橙/营养快线）我自己都人受不了，以后非酒桌不喝饮料！！！ \
 这学期只喝过一次啤酒，而且只有一瓶；其实喝酒的机会只有两次，还有一次拿出把车钥匙，谁知道这钥匙是真的还是骗人的呢，哈哈~ \
 体重，其实呢，我在台湾减了10斤，估计是中间有几天消耗太大，都快脱虚了吧~ \
\
 玩  ：目前能确定这几个计划： \
 搞定  1. 南京”明外廓城：一日游：开学之后，找个周末，骑车把大家耳熟能详的：沧波门、尧化门、仙鹤门、安德门走一遍，作为去年“暴走明城墙的延续” \
\
 搞定  2. 台湾环岛，准备租单车，三月底去 \
\
 3. 南京最美的100个角落( <http://photo.renren.com/photo/249253385/album-567356717> ;  ) 下个学期很有可能是我近些年在南京定居的最后半年，还有不是地方没去过，得利用周末约上同学跑跑，这个任务得做个List不停的反馈，要不然容易失败 \
 没做，难度太大，这种长线活动能的执行一直是我的弱项 \
 4. 毕业旅行，听从组织安排，我个人希望能去东海小岛，这样可以拍出很多类似《那些年》 里的照片啦 \
 服从组织安排吧，之前想施加点影响力的，有心无力现在~
