\
 这两天听家里人聊天，说到一个亲戚和老爸的一个战友： \
\
 他们都是五十岁左右，找工作都很难，之前在家赋闲/带孙子，现在都找到工作了 \
 【亲戚】在妻子朋友开的税控机厂里工作，打杂，每月收入大概2000左右 \
 【战友】在朋友的安排下，在南京审计学院的教学楼里面做保安，平均每天8小时，1800元/月 \
\
 其实我觉得他们的很不错的人 \
 【亲戚】是  家传的手艺人，  原来是搞磨具的  ，后来国营工厂倒闭，被买断工龄了

【战友】做得一手好菜，原来开过饭馆，身体也很强壮 \
\
 我问老爸：“为什么他们现在招工作这么难，最后还是靠关系，而且工资也不高，  做一些类似于打杂的活  呢?  ” \
 老爸回应：“五十岁的年龄了，还能做什么呢？” \
\
 老板的稍微好一点，由于不会电脑，上班也就是混混日子  。不过在家倒是挺有追求的，买了不少文化、历史书籍阅读，还坚持练书法。 \
\
 然后我就在想，“五十岁的年龄，精力差，上升空间也不足了，也就靠一些经验，我能做什么呢？” \
\
 以前在知乎上看到过一个问题（原谅我，没找到链接 ）大意就是【程序猿不做现在的工作，还能做什么呢？】 \
\
 然后看了一下答案，记忆里很多都是： \
 1. 项目管理、  策划  类的工作 \
 2. 有一些人在工作技能之外，还有别的能力，有些本来属于业余爱好的能力也可以用来维持生存甚至是发家致富 \
 3. 有的人可以提前过退休后的生活，基于合理的理财+对下一代的成功培养 \
\
 写到这里，不展开了（老爸跑出来催我睡觉） \
\
 写个简单的结尾： \
 1. 生存能力必须 \
 2. 其他能力应急 \
 3. 提升适应性，做好准备，提防意外的下岗或行业变革等 \

\
