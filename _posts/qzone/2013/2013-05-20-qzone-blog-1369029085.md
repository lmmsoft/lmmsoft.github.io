一 \
\
 中午在明苑门口花20元买了两本盗版的畅销书 \
\
 在这个不尊重知识产权的国家，穷人有穷的过法，一样的知识，属于不同阶层的价格 \
 就好像大陆可以买到各种各样的“地摊货”满足不同阶层人群的生活，物质上的差距没那么大，更多是品质上的~ \
\
 当然，网络的出现让知识变得廉价，学富五车已经不可能再像东方朔一样大的价值了，现在更多的是在拼行动力，应用力，实践力~ \
\
 二 \
 本文想吐的槽与上面两则观点无关~ \
 其实我翻书看到了这个（概括一下） \
 ”很多人太挫了，因为他们在做不喜欢的事情，因此缺乏气场，导致。。。“ \
\
 看看我被毕设困住的情况，就是这个样子 \
\
 我现在不喜欢我的毕设内容（选题的时候还是有一点热情的），于是我就不想做，想糊弄，又不能轻易糊弄好，于是我就被困难、拖延等问题包围，身心俱疲。。。 \
\
 我现在即使做了，也做不出什么有意义的东西，估计就是拼拼凑凑骗人的东西，大家也都心照不宣~ \
 当时呢，其实我有一些有趣事情可以做的，比如NJUST GPA，图书馆查询什么的，我都有实现了80%缺没上线的feature， 上线之后肯定有人用，能产生价值。但是我被毕设困住了，抽不出时间。。。 \
\
 在这里不喷毕设题材的无意义， \
 就我自己而言，其实我有选择的机会，也有很多种完成的办法，可我偏偏就遇到了很坏的情况，大部分问题都在自己。 \
 本来大好的青春，葬送在无聊的事情上。 \
 弱爆了好嘛！ \
\
 三 \
 ”很多时候我们不能选，所以，能选择的时候，就不要让自己后悔~“ \
