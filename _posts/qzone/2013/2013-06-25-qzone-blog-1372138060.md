这是第四个351了吧，回家之后战斗力锐减，没有在学校“写完这篇再睡觉”的斗志了。 \
\
 争取，用最简洁的语言， 速度写完这几个小故事(12:20pm) \
\
 —————————————————————————————— \
\
 一 \
\
 刚才在人人网，分享了一篇日志《毕业五到十年后，“混得最好”的群体中，有一大批是原来很屌丝的人；而处境最惨的，却是那些刚一开始就“工作很稳定”的人》 \
 我的分享评论是“别太年轻就把自己放到舒适区域。不过感觉文中态度更适合男孩子，女孩纸不如嫁得好” \
 应该说，这个原文的标题非常有穿透力，我的评论也很有趣，果然收到了一大堆二次分享提示~ \
\
 然后，奇妙的事情发生了， \
 我被原作者删了 \
\
 被删的事情不是第一次发生，我已经有了经验 \
 a. 三观不合者，我会很开心的，比如前几天好友介绍的某sb把我删了，真是谢天谢地，我还没好意思把他删掉呢 \
 b. 老同学/熟人，我会很郁闷，大家彼此了解，不至于删掉哈，此时我会回去看对方的页面， 如果对方的好友数非常少，我就能够理解了，以后也不再打扰 \
 c. 对方好友非常多，还把我删掉了，这时一般我都会去问问，当然，需要技巧突破权限的限制~ \
\
 今天就是c情况，对方好友4000+，还把我删了，奇怪，我就去留言： \
 “咦，肿木会被删掉啦？我是你的粉丝吖，你的文章都看的呢(生病)” \
\
 然后就收到了回复：“我已经加你了。你重新接受一下。不好意思，刚才一时头脑发热，把你删了，但后来，又被你的诚意打动了。看到“不过感觉文中态度更适合男孩子，女孩纸不如嫁得好”这句，有点失望，我是一个彻底的女权主义者，觉得你这种说法是对女性的变相歧视，所以，犹豫了一下就。。。我向你道歉。 ” \
\
 嘿嘿，卖个萌，就是方便~ \
\
 ———————————————————————————————— \
\
 二 \
\
 这个故事我已经记不太清了，不过那天常峥说起来，还是有一点点印象的。 \
\
 （先插一段花絮）毕业聚餐之后，唱歌(刘常都哭了)回去的路上，常峥说了对大家的第一印象，对刘铁俊是军训摔倒那次（大家应该都是，哈哈~） \
 （走入正题） 对我的第一印象比较好玩：大四和我们大一踢足球，最后3:3，哈哈~大四有个家伙“跳的一米”，吓唬我们不能毕业什么的，大家都很不爽，但也不好说什么，但我一直在场上挑衅这个家伙，比如这家伙远射歪了，我直接对他说，你这个太歪了，不行啊！(这段有待考证，  [@刘铁俊](http://user.qzone.qq.com/491507927/)  求鉴定) ，赛场的氛围显然不怎么好，那家伙拿不出实际的技术反击我，肯定也很不爽吧。。。比赛结束，我主动提出和那家伙握手，那人居然不肯握。。。（场上是对手，有血性，但场下连朋友都不愿做的人，一定走不了太远，男人的风度嘛~） \
\
 ———————————————————————————————— \
\
 三 \
\
 离校前最后一夜，继续在大刘烧烤，吴难难路过，和我喝了一杯，说对我的第一印象：“大一时他是足球队的，踢得很不好，各种失误什么的，大家都一笑而过，只有我教他，鼓励他 ^\_^” \
\
 现在想想也是，我遇到困难时，有的人就喜欢趁机酸我几句，我也乐于满足他的自负。 \
 但我平时和别人面对面的聊天中，更喜欢用鼓励的语言，输出点正能量，反正不管说什么，最后还是要靠对方自己的努力~ \
 当然，网上就不同啦，有的时候就是喜欢黑人，哈哈！ \
\
 ———————————————————————————————— \
\
 写完了，回过头来看，其实也没什么主线，也没写出啥东西，就当留点记忆吧~
