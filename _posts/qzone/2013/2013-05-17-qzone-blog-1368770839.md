本来约10点见面的，结果排毕业照耽误了时间，索性多拍几张（集体，大寝，小寝，一些熟人，ACM队） \
\
 然后只能11点见了，再学校稍微转了一圈（主楼、三号路、水杉林、冶园）然后到三号门外的那个咖啡厅吃午饭 \
\
 八车给我带了一只小熊（据说是看到我床上毛绒玩具非常多），太和我胃口啦~ \
\
![图片](/images/qzone/c62840ead430d1e0becc13a9.jpg)\
 \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_ \
\
 然后吃饭聊天，先谈人生谈理想谈规划，再谈菇凉谈妹纸谈生活 \
\
 下面写点我的收获： \
\
 1. 八车的转身太华丽了： \
\
 本科：汉语言文学（经济学二专） \
 硕士：计算语言学（有了工科背景） \
\
 实习： \
 本科：移动 \
 硕士：河北某县教育局局长助理，咨询公司（德国电信），微软亚洲研究院（行政岗），某银行（大堂/业务），券商（行研） \
\
 考上清华的研究生之后就是不一样哈，这个实习经历就很神啦，面很宽，虽然技术性越来越窄，但是为毕业求职打下了坚实的基础，口子很宽很宽啊~ \
\
 2. 还聊到券商的吃饭面试，2个面试官vs10个候选人，虽然是吃饭聊天，不直接问问题，但还是能看出软实力，不经意的几次交流，也能看出水平和准备的充分程度，吃晚饭5个进下一轮~ \
\
 3. 还聊到一些牛逼公司的面试经历，因为不是专业对口的，所有要靠本科二专学到的东西和长期攒下的面试经验来，中文的还能应付，英文的就非常困难了。最后会让你问他问题，这是挽救面试的最后机会，多问，问好一点的问题，很有效~ \
\
 4. 他已经做好本学期的最坏打算了：入党失败/找实习不理想，就当一个教训，但还是都成功了，过程花了很多努力~ \
\
 5. 比如转预备党员，就很主动给老师写邮件，问之前为什么没有他，有什么原因，缺什么材料等等，不停地追着，终于如愿~ \
\
 总结： \
 a. 我这一年很多时候是好运相伴才有了现在的结果 \
 而八车更多是靠自己的努力，【积极主动】，充分的争取和准备，才有了收获~ \
\
 b. 与之相比，我需要更多的外露，更多的与人交流，更多的争取。谁都会遇到困难，消极和积极面对的人，结果真的不一样。 \
\
 c. 我还不够主动，尤其是与人打交道方面~ （这可能是IT男的集体悲剧，但作为一个正常的人来说，我应该要避免这样的问题~） \
\
