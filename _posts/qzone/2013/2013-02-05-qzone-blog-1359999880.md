 今晚和老爸一起，看了三个小时完整版的《云图》，具体剧情观后感什么的，就不献丑了，不过有些台词蛮喜欢的，摘抄了一下： \
\
 1.  "所有的界限都是非常规的，等待着被超越。一个人可以超越常规，只要他能首先想到这么做"

\

2. “因此只有通过别人的眼睛，才能了解我们自己”

\

3. “我们生命的不朽性质在于，我们的言语和行为的后果”

\

4. “我们的生命不仅是我们自己的，从子宫到坟墓，我们和其他人紧紧相连，无论前生还是今世，每一桩恶行，每一项善举，都会决定我们未来的重生。”

\

5. “个体生命的后果会一再重现直到永恒” \
\
\
 —————————————————————————————————————— \
\
 2-4句是连续的，是克隆人在自我发现后宣言和接受审判时说的 \
\
 我最喜欢第三句  “我们生命的不朽性质在于，我们的言语和行为的后果” \
\
 这也是我一直愿意分享，愿意交流的原因。 \
\
 如果因为我的一句话、或者读了我写的一点东西，你的生活能有所不同，我很愿意看到。 \
\
 如果我的言语和行为后果能够传世呢？岂不是世界因我而不同？爽哉！ \
\
 ———————————————————————————————————————— \
\
 看完的亲帮忙顺手填一个简单的问卷，帮助我给大家提供更好的内容： \
\
 只要三个数字就可以了： \
\
 第一个数字：总体评分：3代表，2还不错，1一般，0差劲 \
 第二个数字：图片评分：3有意思，看了又看，2一般，看了一眼，1太差，压根没看，0不填 \
 第三个数字：文字评分：3有意思，看完了，2没看完就放弃了，1我是来看图的，0不填 \
\
 比如333就代表佳作，100代表打酱油哈~ \
