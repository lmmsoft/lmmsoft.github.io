本来说本月不写日志的 \
\
 但是 \
\
 有的东西，现在不写，以后也不会再写了~ \
\
 我还是快速的水过吧： \
\
![图片](/images/qzone/5fbc437b35f5562660173df0.jpg)\
 图为我在北京钟鼓楼的鼓楼 \
\
\
 今天下午人人上又多了几个好友申请，已经习惯了，都是有几到几十个共同好友的人 ，现在我都懒得去对方主页看看，根据状态或日志的进行一下“面试”，决定通过与否。 \
\
 这次不同了，有两点，1：头像 看起来像是个妹纸，难得 2：名字有点熟悉，汤晓舟~ \
\
 去对方主页看了一下，虽然只有6个共同好友，但很快辨别出对方来路：NKU MSTC \
\
 然后想了一下，知道为什么熟悉她的名字了，她是NKU MSTC chairman，我在MSRA实习时经常收到她的邮件，她的邮箱用了中文名~ \
\
 通过好友请求，打开第一篇日志看了一下：《  突如其来我想念每一个人  》  ，第一句就击中了我 \
\
 “ \
 不知道那些人现在都怎么样了，联系不上就是真的联系不上了。没有任何音信，完全没有任何音信，我像一个贼一样去追寻他们现在的日子。可是他们变得逐渐沉默。我也看不到什么。

\

连电话都没有，我甚至害怕打扰他们的生活。我害怕说什么他们又会感伤，我们失去联系好久好久了。 \
 ”

是啊，如果不通过这个好友申请，这辈子只怕再无联系的可能~ \
\
 然后就在日志下回复 \
\
 “  看到你的名字好熟悉呀，想了一会儿，原来我是管win8pioneer的，经常收到你的邮件~  ” \
\
 自我介绍之后，  寒暄了几句，然后我继续挖掘她的故事。 \
\
 日志写的很有意思，相册也还行，看上去像是很会经营自己生活的人^\_^ \
\
 我猜这么会写的人，一定有自己的博客，正准备要，在资料里找到了  [http://boiled-water.com](http://boiled-water.com/) \
\
 开了博客，又是一片天地啊，基本资料介绍之外，还真有好多好多日志， 不少多对我胃口呢~ \
\
 有意思的是《战托医生》 ，她写的win8 app，她介绍APP时说用win8的人太少，不指望大家下载她的APP。 \
\
 可我不仅用过这个APP，还给她报过bug，又是一种connection啦~

\
 ------------------------------------我是分割线-------------------------------------------------- \
\
 写到这里本该结束，不过刚才在她的状态里看到这样一个回复： \
\
 “我的基友严重阻碍了我找男友，认识的男生和她相比都弱爆了，无论是识见还是分析，逻辑能力，细心……” \
\
 我很有共鸣，给她的回复是 \
\
 我感觉我也有这个问题，希望找个男友能解决我所有的问题，其实呢，有的问题本来就是要靠基友来解决的，不能用基友的标准来要求男友~ \
\
 就此罢笔，不展开了。 \
\

\
 看完的亲帮忙顺手填一个简单的问卷，帮助我给大家提供更好的内容： \
\
 只要三个数字就可以了： \
\
 第一个数字：总体评分：0-9(9代表最高，1代表太烂，0占位符，代表不填写) \
 第二个数字：图片评分：3有意思，看了又看，2一般，看了一眼，1太差，压根没看，0不填 \
 第三个数字：文字评分：3有意思，看完了，2没看完就放弃了，1我是来看图的，0不填 \
\
 比如933就代表佳作，000代表打酱油哈~ \
\
 谢谢大家~ \
