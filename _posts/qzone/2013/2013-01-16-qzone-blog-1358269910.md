晚饭后又被姚班神牛带到咖啡厅~

先说几句废话再进入主题: \
 1. 清华校内设施真全啊,食堂里不仅有自助餐,还有咖啡厅,价格还很便宜 \
 2 怎么把手机里的照片传到扣扣空间,这是个问题 \
 3. 临近check out,每天都和很多人交流,其实有很多东西可以写,但又没时间写,应了三土的那句话:"有话说的时候没时间,有时间写的时候没话说" \
 4. 废话好像扯远了,打住 \
 5. 好像有点困,正文就简单水过了 \
\
 今晚去了清华见了两个人,都是研一,一个是姚班的,另一个是中文系下的计算语言学 \
 聊聊很多话题哈 \
 今晚只能写"大作业"话题了 \
 其实也是老调重弹 \
 南理工的大作业实在太水,以下省略抨击老师话语一万字,重点(code review, 项目废掉,难度) \
\
 说说今晚我听到的三个例子: \
 1.姚班&lt;高级机器学习&gt;的大作业,他做了一个识别[人人上和微博上同一个人]的程序,数据集就是根据自己的好友关系广度优先爬了好多数据,然后试了很多算法去找同一个人//他找了几个有兴趣的同学参与,有的还是没选这课,大作业交了之后项目还在继续,而且还有很多的地方在深挖,他们准备大东西做好之后发论文 \
 2.神牛给姚班本科大二上同学的c++课程设计做助教.同学们的大作业要求3000行,检查其实挺严格的,基本上杜绝了抄袭,当然,大家写的东西也各种强大:有objective C写了游戏,放apple store上卖的,有实现了一个很复杂的算法的,还有写小工具的,总之都是很有意义的作品 \
 3.计算语言学:实验室里面有个同学,平时搞活动,搞社团很厉害,这是说的是他发论文的事情:本科北京语言大学,中文,保研清华计算语言学,研一修了(好像是蹭的本科生课程)孙茂松的&lt;计算语言学&gt;,课程大作业,用给的语料做了一个自动对联系统,发在那个中文计算语言学组织的会议上,一作+老板通讯作者(其实没帮什么忙),人家本科是中文的,认真搞了半个学期编程,大作业就在国内的一个会议上发表了 \
\
 今天时间有限,只能叙述事实这么多,大家自由补充结论,欢迎回复讨论,谢谢~
