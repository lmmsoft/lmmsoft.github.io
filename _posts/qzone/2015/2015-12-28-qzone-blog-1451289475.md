 好久没有写比赛记录啦，每次比赛都有很多收获，不写下来太浪费了~ \
\
 昨天跑了苏州太湖马拉松2:03完赛，配速5:51，暴露出很多问题 \
\
 具体数据 \
![图片](/images/qzone/875837b9bf83848d0a31b816.png)\
 1. 开跑，入场晚了，排在后面，  5分钟才通过起点，  身边人太多，速度提不上去，输在起跑线上 \
 2. 前3公里配速是6:23/8:00/6:12，热身不够是一方面，发朋友圈也是一方面，稍微注意一下说不定就进2h了 \
 3. 后面基本在5:30的配速，心跳163左右，这大概是我现在的慢跑速度，再提速就有点吃力了，而且现在速度训练不够，几乎提不上去 \
 4. 10-15km是最舒服的阶段，身子完全热了，没仔细看配速，就盯着21km的 predict在跑，倒是很舒服，一直能保持5:30的配速 \
 5. 15km的时候算了一下，如果后面5:00配速能保持，还是可以进2h的，可惜速度几乎没变化 \
 6. 20km左右突然爆掉了，身体反应是左脚脚腕开始疼，配速在掉，难受，不知道为什么，喝水/饮料一直坚持，5km左右吃过盐丸/螺旋藻，后面能量胶也啃了呀 \
 7. 最后只能用6:00的配速冲线 \
\
 经验习得： \
 1. 参赛包里放双恢复鞋，跑完让脚放松下 \
 2. 山寨羊毛保暖袜不错 \
 3. skins压缩衣还是和我不够匹配，长袖不舒服，胸口汗比较多 \
 4. 赛前喷止痛药，比赛时预感有疼痛及时喷药，有效果 \
 5. 下次半马穿noosa tri，或许可以比nimbus跑得快一点 \
\
 今年总体总结 \
 1. 今年的几次马拉松成绩都不理想: \
 a. 欢乐跑10km46min是最佳的状态，只比姑苏区一姐酷酷慢了几秒，后面比赛都是被完爆 \
 b. 北马半程1:57，而且还是收着没用力跑的情况下，刚过半程就开始爆掉，最后430惨淡收场 \
 c. 阳澄湖健身跑6k是状态差，爆掉的典型，配速从4:40掉到6:00，痛苦不堪 \
 d. 南马跑不动，在调整状态，208完赛 \
 e. 苏州太湖马想跑快一点，还是跑不动,202，刚进折返点就看到酷酷出来了，太可怕，赛后发现她1:42PB了,女子第16，每公里都慢一分钟，成绩差距这么大，感觉能力差得不多的，就是训练，跑量，状态调整差得太多。酷酷下雨天在家搞跑步机，而我继续睡懒觉，人家每月跑量肯定上300，而我不到200，而且只靠周末进山拉练积累，训练效果没那么好 \
\
 来年 \
 1. 要想出成绩，必须科学训练，以赛代练不可取 \
 2. 3/13的苏半马是B类赛事，检验冬训效果的好机会，进2保底，要不如冬训就完全浪费了 \
 3. 周末LSD，周中就亚索800搞搞搞！ \
