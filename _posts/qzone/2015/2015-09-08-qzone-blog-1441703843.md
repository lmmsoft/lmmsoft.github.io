 2015-09-18 周五 day13 苏州 \
 【游泳课5th】  今天总训练量达到2km，1.5h \
 热身2\*200，6m25s/200m-&gt;3m13s/100m \
 12\*50浮板抬头打腿，间歇20s \
 4\*100？忘了 \
 速度测试，50\*2，大概1m08s/50m \
 休息5分钟，再连续游泳500米，不作速度要求，16m45s-&gt;3m21s/100m比蛙泳慢，哈哈 \
 心得：  自由泳可以连续游500啦，很高兴，短距离冲刺的速度也有了提升，进步比教练想象中快一些（第一次来甚至不能连续游100米），主要是水中的感觉越来越好，现在也逐渐意识到打腿的姿势缺得比较腻害，以后要多练习。 \
 今天主要思考的是偷懒问题，教练不注意的时候，完全可以偷懒，可这又有什么意义呢？又不是被家长逼着来上课的，每一分钱的投入都出自于内心的热爱，认真完成动作规范，训练量，是对自己最好的交代吖~ \
\
 2015-09-17 周四 day12 苏州 \
 【游泳课4th】 全程自由泳练习，总量2050米 \
 流程  ：先4\*100热身，大约11分钟 \
 8\*50浮板抬头打腿，要求20分钟完成（最后20分钟只搞完7组，组间休息太久）每组用时从1:35掉到1:55； \
 8\*25短距离抬头打腿冲刺，35-45秒之间； \
 200\*2，5:44和6:03,； \
 8\*25短距离全身冲刺，30-35秒之间 \
 8\*50夹板划手练习1:37到2:30之间； \
 50米打腿休息 \
 姿势  ：教练帮录像看了一下，主要是腿不行，大腿太僵硬，几乎没动，只靠小腿在打腿；两膝分得太远；左手手腕不对，左手划手不应该过中线，双手都要滑到底，呼吸时间要短一点 \

 1组3次换气（1m30s） \
 连续4组100米3次换气，组间休息30s，每组时间是3m/3m20s/3min40s/3min30s，体能跟不上，掉速度严重 \

 2015-09-09 周三 day4 \
 游泳  ：早上游泳第二节（每组100米）6组浮板打腿，花了30min，1组没浮板抬头换气，2组侧抬头换气，2组侧抬头换边，2组蛙泳打腿 \
 自由泳和蛙泳的问题都在打腿上： \
 自由泳打腿频率不够，大腿摆动不行，很多时候都是小腿，大腿太紧张，游起来后水花不够，后半程掉动作严重，换气的时候大腿停止；另外吸气后憋气不够，要等到下次吸气前再吐气 \
 蛙泳收姿势不对，要收慢一点，膝盖靠近而脚远离；翻不够向外，脚也常常没勾住 \
 足球  ：晚上8:00-10:00 踢球2h，跑动距离10.28km，平均心率134，摔了几次，右膝擦破几处。 \
 看了下每公里花的时间，基本上差不多，说明没有明显的因为体力下降而损失跑动能力的情况，技术发挥嘛，感觉后期还是有下降的，常常踢到后面进球和助攻都少了，以后继续努力。 \

 2015-09-08 周二 day3 \
 🏊  游泳  ：早上八点约了教练上游泳课，第一节，先介绍下背景（铁三爱好者，主攻长距离，目前1500米蛙泳45min，目标是1500米能用自由泳游进30min）了解下现状（蛙泳动作不规范，自由泳尚不能游长距离），然后开始训练，浮板打腿/浮板侧换气打腿/不用浮板打腿练习若干，教练的评价是体能不足，后半程频率慢，动作严重变形，周三周五再上两节课，要增加训练强度 ps：没吃早饭，没热身，下水就自由泳100米，才游了80就爆掉了。1小时课程之后教练走了，我自己又练了一会儿蛙泳，目前的主要问题是：收腿太快，要求收腿慢，翻腿的时候脚趾勾一下，然后再蹬腿。 \
