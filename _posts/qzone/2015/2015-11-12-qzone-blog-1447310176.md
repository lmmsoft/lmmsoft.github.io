十一前搞了个集中QA，一直没写，今天补上。 \
\
 【正文】 \
 玩个小游戏，你有什么问题想问我？严肃与恶搞均可，可以下面留言也可以私聊，我会选择一部分我喜欢的问题公开回答，提问十一前截止，然后我会用国庆假期发一遍日志集中回答，机会难得喔 \
\
 【Q1】  娄MM喜欢什么样的男生 \
 【A1】喜欢娄明明这样的男森，谢谢 \
\
 【Q2】是什么让你开始爱上了运动，并开始乐此不疲的参加各类比赛？即，运动的初衷是什么？ \
 【A2】循序渐进的过程吧，从小就喜欢运动啊，足球一直踢到今天，小学时暑假专门学过游泳，其他就没有专业训练了。 \
 大学学计算机，身体逐渐变差，印象最深的是大三最后一次1000米跑4m30s，跑完躺在地上半铁不能动，从未有过的难受，相比大一大二3m30~50s之间，跑完还能去踢球，简直不是一个人。 \
 工作后在外企，公司里从美国回来的比较多，我老板就是，生活工作平衡得很好，比如他来苏州的第一天就绕金鸡湖跑了一圈。身边同龄同学影响也比较大，有个同学身高身材和我一样，178cm80kg，跑了马拉松，身边跑马的也越来越多，我想他们能，我也能，于是开始训练。练了三个月后直接去跑上海马拉松，膝盖崩了，最后忍着疼痛赶在关门前到达终点，5h58min。 \
 跑步这东西应该循序渐进，5km 10km 半马 全马一步步来，我上来就搞全马，身体吃不消，过程的愉快也没享多少，太痛苦了，后来就断了。之后两年只跑了苏州金鸡湖半马，245和230，总之很慢啦~ \
 后来的转折是今天7月，想练铁，进了苏州铁人群，第一次和组织一起练，感觉特别好，因为有人带，训练的误区有人及时指出，比赛的各种信息大家一起共享，收获非常大，铁人比赛我就吸取了马拉松的教训，南京小铁，泰州半程，安亭标铁，富阳标铁+九龙山山地铁三背背靠背，循序渐进，基本每场次比赛的强度都是之前的两倍，每次都进步，每次都不是拼了老命才完成，感觉身体还富有余量，感觉好极了。 \
 回到问题，为什么乐此不疲？主要是两点： \
 1. 【结果导向】按照一定次序报了比赛，每天都有新的训练目标，需要努力，又不至于太辛苦 \
 2. 【及时反馈】训练过程每天发的朋友圈，大家的回复普遍都是-&gt;啊又瘦了；天啊，原来你一点都不胖；一道闪电亮瞎了我的双眼啊！ \
 初衷：1. 减肥 2.挑战自己 3.装逼 \
\
 【Q3】会不会有时候觉得运动占用了太多时间？ \
 【A3】会，今年7-8月基本每天2小时运动，周末比赛花的时间就更多了，平时还有大量的时间用在网上看攻略，购买装备，水群等地方。我很享受这个过程，但的确占用了很多时间，导致1业余没时间做别的事了，诸如读书，郊游等计划都搁置了2工作很难投入以前那么多热情了，现在很少加班。 \
\
 【Q4】作为一个网红，请问你成功的秘诀是什么 \
 【A4】装萌妹纸，程序猿圈子特别特别缺萌萌哒还会写代码的菇凉，我抓住了痛点，尽管我不是妹纸~ \
\
 【Q5】作为一个网红，请问你怎样应对粉丝的骚扰 \
 【A5】生活中几乎没有骚扰，网上倒是挺烦的，猥琐男还真不少，不过偶一般都不理的，那些骚扰的言语对一个男孩纸来说杀伤力真的不大，哈哈~ \
\
 【Q6】作为一个网红，请问你怎样应对有人搞错你的性别 \
 【A6】挺好玩哒，反正大家都会重新认识我，所以我在网上可以肆无忌惮地作作作~！ \
\
 【Q7】作为一个网红，请问最大的困扰是什么 \
 【A7】最大的困扰是你们觉得我是网红，而我不是。。。 \
