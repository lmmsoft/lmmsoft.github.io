好久没写了，今晚老妈带着舅舅舅妈过来了，我要陪着他们，但其实没什么事可做，就乱写点东西。 \
\
 1. 和三观一致的人一起做事是一种享受，不需要花太多精力字沟通/协调上；一个眼神就能传达意思，省心省力；做事之前不需要提前通知，做完了自然会被夸靠谱 \
\
 2. 我距离“让身边大部分人都觉得与我共事很舒服” 这个标准还有不少的距离，身边有不少榜样，真得很值得学习，和他们共事太舒服了。 \
\
 3. 个人偏好，我喜欢和什么样的年轻人一起玩呢？喜欢冒险，热衷创造，乐于分享，求新求异，精力旺盛。 \
\
 4. 个人偏好，我不喜欢和什么样的人一起玩呢？三观不合，气场不投，顾虑太多（P话太多），原则太多，不爱帮我拍照XD \
\
 5. 个人偏好，我不反对和什么样的人一起玩呢？嘴贱，自负，调皮捣蛋 \
\
 6. 我现在的日子挺安逸，但我的心对这种安逸的日子挺排斥的，所以舒适的环境/宁静的生活并不让我感到足够的开心，我必须定期折腾一下自己，搞出的东西刷刷存在感 \
\
 7. 我喜欢出去玩，但没有固定旅伴，这让我非常痛苦。a)每次都要拉人，往往拉不到人 b)远一点的旅程没法规划，比如三个月后想去的地方，变数太大，没有办法约人 c) 每次和不同的人一起玩，默契，习惯都是空谈，不能专注于行程 \
\
 8. 我的三观和父母差距过大，而他们也不是那种放手完全不管的，这消耗了我太多的精力和情绪，我必须想办法解决这个问题 \
\
 9. 三月是跑步月，我完成了一次半马，若干次夜跑，还买了跑鞋 \
\
 10. 四月是骑行月，环了独墅湖，澄湖，太湖，若干次上下班骑行，还买了公路车和一堆配件 \
\
 11. 五月我希望是游泳月，把去年此时丢掉的习惯捡回来，争取学会自由泳~
