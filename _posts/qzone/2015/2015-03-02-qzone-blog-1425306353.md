好久没过来写东西咯，最近的日程挺紧。 \
 年前天天干活，直到腊月28的夜里，几乎没松下来。 \
 春节在家呆了3天，马不停蹄地见了亲戚，朋友，同学，与曾经很熟悉的小伙伴们聊了好多话题。 \
 然后和父母一起去泰国玩了5天，大致就是白天陪父母逛吃拍照，晚上他们睡了之后溜到步(hong)行(deng)街(qu)去逛，一日当两日来用，精力消耗很大。 \
\
 这两周会非常的忙， 因为关系到2015三大愿望里面的两个。 \
 三大愿望分别关于旅行/工作/未来的生活，到期分别是三月中旬，九月，年底。 \
\
 本周是工作的核心部分的开篇，春节回来后冒出个挺适合我的机会，果断提到最高优先级去弄，争取周五前出demo。 \
 下周是今年最大的旅行愿望，自驾走孔明北伐——六出祁山的线路，应该也是这几年对我挑战最大的一次旅行，等回来之后慢慢写。 \
\
 每次旅行回来，我都会在一个小本子上写下“三观”的变化。 \
 泰国回来写的第5条是“  知道自己想要什么，知道哪里有自己想要的东西，知道怎么克服困难去争取，一路上都是快乐  ”  。 \
 我大部分浑浑噩噩，无力而忧伤的时候，其实都只是困在了第一个问题上面。 \
 前两个问题想明白了，后面的就算没完成，也不会那么得痛惜伤怀的。 \
\
 后来我意识到，只要能回答出第一个问题，你就能甩开八成的人。而说出自己的愿望就是个很好的回答第一个方式。 \
 魔力鸟赋闲在家时说过平生三大愿望是“体验意甲，重回英超，执教葡萄牙国家队” ，看看，这才几年，已经实现两个了。敬爱的莫拉蒂主席，亲爱的阿布都尝到了顺水推舟的快乐。 \
 而我，也应该想明白自己想要的到底是什么，不管是三大愿望还是五小愿望，有总比没有强。
