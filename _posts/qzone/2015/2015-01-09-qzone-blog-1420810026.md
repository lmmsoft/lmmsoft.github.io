提示： 本文纯吐槽，会充满偏见 ，愚昧和个人喜好。 \
\
 下午约了别的组一个我很敬仰小老板聊天，非常愉快。 \
 他就叫A，我现在的manager叫Boss，小老板叫C吧。 \
\
 A会给我很open的问题思考（可能他也没有答案），问题非常开发，只有一个情景，目标也很简单，最后有user，有DSQ就可以了。 \
 B太忙了，根本没时间管我，经常一周说不了一句话，更别提one:one这样的扯谈机会了。 \
 C布置下来的都是很具体的问题，我只需要做(what)，不用想为什么（why），甚至怎么做(how)都不用想，他都告诉你了，你去实现，不对再讨论。 \
\
 A的问题答案千变万化，可能试了，看数据才知道好坏，但给了你无限可能，也有很大的激发你潜能的机会，你会想方设法调动自己的资源，能力，绞尽脑汁而求答案，并且快速的反馈机制会很有成就感。 \
 B的风格也一直是给你个很大的放下，你自己去找答案，而我的  前manager会给  你很多具体的答案，会教你怎么去做，而不是某种程度上的无头苍蝇乱撞。 \
 C和PM平时搞feature design，几乎不把我们几个小弟加进去，往往就是周一的时候出来几个feature，然后让大家选，我因为leve最低，技术最差，做事最不让人放心，所以总是最后挑的，都是别人身下的边角料中的边角料，要不就是别人不愿意做的垃圾。最后没什么delivery ， performance 跟着也很差。当然现在大家士气都不高，对项目没什么激情。 \
\
 A是我们这幢楼里最年轻的资深工程师吧，小孩刚出生。 \
 B的小孩也才1岁多一年，在美帝出生才几个月就跟着父母回到国内。B在我们组完成了资深到首席研发主管的飞跃，即将开始新的征程。 \
 C的孩子上小学了，下个学习就要从西安转学到苏州，开始新的生活。 \
\
 找一个和自己match的老板很重要，EX就不错，可惜回美国了，现在的实在不来电，可能有的程序员就喜欢执行，听话不多想，遇到这种老板很开心，可惜我不是。 \
\
 今天下班前直接给小老板发邮件，意思是下周我要多写点code，而不是整体瞎JB乱调研各种杂事。 \
\
 沉没成本不小，但别让它成为你前进的绊脚石。
