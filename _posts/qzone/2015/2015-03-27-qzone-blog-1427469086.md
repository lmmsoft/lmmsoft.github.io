\
 三月份到现在为止居然只在扣扣空间“自由写作”一篇，比想象中少很多呀。其实中间有好几篇草稿，都是写了一半太困，就直接睡去，第二天醒来之后就没心情写了那种的。 \
\
 好不容易又熬到了周末，坐在工位上发呆，找不到想做的事情。 \
 每次旅行回来都会遇到这种情况，好一阵子提不起精神，纵使OneNote里记录了一堆要做的事，欲望清单里苏州的大部分都没完成，可我还是提不起精神。 \
\
 这周每天中午到约1:1，从新来的小弟到老板都有涉猎，还是蛮有收获的。 \
\
 本周最多的思考，在于选择生活的辛苦程度：选个能力范围内的容易的工作，日子会容易悠闲很多，选了太超出舒适区的工作，也许会有很大的成就感，但是艰辛/平衡/不停的挑战，都是很大的挣扎。 \
 这里有几个故事： \
\
 1. 组里面新来的小弟，刚入职半年吧，细聊时才知道，07年江苏高考，当地的状元，680分考到了清华，从小喜欢打游戏，于是就学了计算机，上了大学继续打，好像打得很厉害，比如dota进了校队什么的。 \
 今天晚上看到他在写代码，耳机里飘出的声音有些不对劲，一问，果然是dota的解说，他的意思是，他也在认真写代码，耳机里的声音随便听听而已。不过在我看来，以他的聪明程度，跑微软来做这样的项目实在是太轻松了，本可以出国，或者做更牛逼的工作，不过为了业余时间开开心心打游戏，顺便离家近，就来苏州咯 \
\
 2. 我的初中同学谷虫，也是特别聪明的一个小伙子，我大学毕业前去南信工找他玩了一次，他学的是最好的大气物理专业，根据他的说法，考试论文都太容易了，学长编个程序，搞个拟合坑次坑次的，在他看来都太容易了，不用花太多精力钻研，就能取得预期的结果，然后，预期之外对自己也没太多要求，打牌打桌游，把爱好培养好就行了。 \
\
 3.  Ethan，六  楼的一个老板，PTT的创始人，在台湾很有名，之前晒过和马英九的合影，上次看到他回台湾，又和五月天合影，而且五月天几个人手上拿的纸条，是“杜老大”什么的，他姓杜，显然这不是粉丝和明星的合影，而是明星和更大牌的会师啊。很多时候，我们都奇怪，Ethan以前自己开过公司，手下有200多人，卖掉之后早就不差钱了，为什么跑到微软总部的研究院搞研究，后来又来苏州呢？听说他的妻子是《那些年》小说里九把刀没追到的一个女孩子（沈佳仪之前），我们就更好奇他的传奇经历啦~ \
\
 4. 最后个故事就是我啦，刚入大学，我是高考分数比较低的那种，而且作为复读生，总觉得自己是个失败者。果然大一就挂科了，保研没希望，GPA又低，出国也不太可能了。 \
 后来意外混到MSRA实习，身边都是全国最牛的计算机学生，之前只听过名字大神可能就坐在你不远的地方，压力何其大。 \
 再后来惊险转正，和一堆名校的毕业生一起工作，身边都是聪明绝顶的家伙，比如前老板是伯克利本科，前前老板是清华本科，一点点小错误都瞒不过他们，胆战心惊，还有完成超出自己能力的工作，实在是痛苦。 \
 很多时候都在问自己，要是当年选择回家做公务员，现在的日子是不是舒服很多？春节回家，看到发小们都已婚，过上了幸福美满的生活，而我一个人在外面，累了的时候，也不知道怎么排解，反正鸡血现在对我是越来越不灵了，不开心的日子也越来越多。 \
