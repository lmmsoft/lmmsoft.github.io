看到好几个同龄人在尝试了每年阅读100本书之后获得了飞跃，我也一直有这样的想法。

\

某天看到苏州家的书架，都是近两年刚买的书，差不多100本吧，有些书现在不读，以后都不会读了，就像南京家里书架上的那些书一样。

\

何不在2015挑战一下自己？看看能不能把他们都读完。

\

然后我就找了下面这些与每年100本有关的文章，如果你也有兴趣，可以看看4星和5星的那些，都是我7认为比较好的～

\

-[为什么意志力是有限的？]( <http://www.zhihu.com/question/25074132> ) 1星，没什么好答案

\

- 摘抄：我相信的是方法，步骤，短期的目标，长期的方向。意志力太虚无缥缈了，太不可靠了，我不知道怎么可以提高意志力。对不可量化的指标，我都是不信任的。

\

- [知乎|如何改正阅读时时逐字阅读的坏习惯？]( <http://www.zhihu.com/question/24786273> )

\

- 只用眼睛读书，排除掉脑海里的声音。那具体怎么做呢？？练习在读书的时候屏住呼吸，每天练习一个小时。

\

- 利用手指、笔尖、光标等进行快速指读，目的在于提高阅读时眼睛的注意力，同时控制速度不给自己留下默读的时间。

\

-发现咬手指更方便

\

- [知乎|RSS 阅读器 InoReader 的使用体验如何？]( <http://www.zhihu.com/question/21278318> ) 2星，和我看法一致，inoreader好~！

# 以下均为战隼，这哥么现在每天阅读1-2小时，保持好几年了。在2011年时挑战过每天一本书，坚持了378天，看了428本书，写了378本书的笔记和书评

\

[怎样安排时间读书？]( <http://www.douban.com/note/380090647/> ) 4星，阅读的经典文章，这篇[知乎]( <http://www.zhihu.com/question/20069551/answer/13941201> )上也是三千赞，转载无数。

\

[我的目标是每天阅读一本书]( <http://www.read.org.cn/html/762-my-goal-is-to-read-a-book-a-day.html> ) 4星，思路很清晰的文章。

\

[利用四种读书笔记来加强吸收]( <http://www.read.org.cn/html/1604-read-a-book-note.html> ) 3星，四种分别是：1简评：几百字，打分，说框架，分享好友；2摘录笔记：可用OCR加速；3.思维导图；4读书心得，读几遍之后写出不错书评~

\

[小孩能用 Kindle 看书吗？]( <http://www.douban.com/note/379896656/> ) 3星，答案是不适合，纸质书对培养阅读习惯兴趣有电子书不可替代的作用，彩色的画面，没有电子设备干扰，与小伙伴分享的乐趣。

\

[读书的时间哪里来？]( <http://www.read.org.cn/html/1545-study-time-where-to.html> ) 2星，养成习惯，迅速集中思想

\

[关于读书方法的闲聊]( <http://www.read.org.cn/html/1289-chat-about-reading-methods.html> ) 3星,摘抄：“我把本进行5分制规则。3分以上的书7-8成会做笔记，4，5分的书会根据时间、环境和情况来做思维导图、精读和主题阅读。同时每读完一本书会写微博，花了上200、300个字，介绍一下要点，做个总结。”

\

[iPad、kindle阅读器与应用心得，及一些电子书分享]( <http://www.read.org.cn/html/2105-ipad-kindle-yue-du-qi-yu-ying-yong-xin-de-ji-yi-xie-dian-zi-shu-fen-xiang.html> ) 1星，受时效性影响，这篇现在参考价值不大了

\

[知乎问答整理：阅读问题（5）怎么跟别人分享一本书?]( <http://www.read.org.cn/html/2037-zhi-hu-wen-da-zheng-li-yue-du-wen-ti-5-zen-gen-bie-ren-fen-xiang-yi-ben-shu.html> ) 3星，都是不错的建议，eg “一分钟正常的语速会控制在160-200字之间，五分钟能说800-1000，练习在3-5分钟内归纳一篇文章或一个故事的要点 练习时准备一个短小的故事或文章”

\

[知乎个人问答整理：读书问题（6）如何解决做笔记与阅读之间的矛盾和读书笔记的类型]( <http://www.read.org.cn/html/2043-zhi-hu-ge-ren-wen-da-zheng-li-du-shu-wen-ti-6-ru-jie-jue-zuo-bi-ji-yu-yue-du-zhi-jian-de-mao-dun-du-shu-bi-ji-de-lei-xing.html> ) 3星，解决了我的一个很大疑问：最好第一遍快速翻一下，第二遍再细致笔记。第一遍记笔记容易把时间浪费在细节上。

\

[知乎问答整理–阅读问题（7）你有或者有过信息焦虑吗？你是怎样应对的？]( <http://www.read.org.cn/html/2109-zhi-hu-wen-da-zheng-li-yue-du-wen-ti-7-ni-huo-zhe-guo-xin-xi-jiao-lv-ma-ni-shi-zen-yang-ying-dui-de.html> ) 4星，好建议。我的信息焦虑挺严重的，最近在练习12349，剩下的几条目前还缺乏关注。
