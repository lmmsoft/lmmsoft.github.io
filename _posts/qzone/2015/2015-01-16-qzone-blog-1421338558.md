最近遇到的负能量事情好多，我也天天跑到qzone里面产生的负能量。 \
\
 不过时不时，总有些联系不多的朋友，偶然联系，给你许多的能量，照亮你一段前进的路~ \
\
 今晚想写的，是我和Vani时间轴，Vani应该是个94年的小鲜肉，挺帅的~ \
\
 2009-09 我开始的大学生活，选择了计算机专业，Vani考上了高中，开始OI生涯 \
 2010-07 我开始练习ACM，在百度空间发解题报告，经常搜到一个叫Vani的高中生的解题报告。 \
 2010-09 我大二，vani高二。我每天混混日子，不思进取；vani noip-&gt;省选-&gt;NOI银牌。我们成为人人好友，算是认识了。 \
 2011-09 我大三, vani大三。我acm练不下去，默默告别，vani保送PKU \
 2012-09 我大四，vani大一。我在北京实习，vani开始了大学生活，我约他面基成功~ \
 2013-07 我毕业，vani大二。我开始工作，vani和2010-07的我一样，开始大学第一个暑期训练 \
 2014-07 我工作一周年， vani  斩获world finals 金牌，光荣退役 \
 2015-01 我的生活一团糟，vani从hulu check out \
 2015-07 我工作两周年，vani开始Jane street实习 \
 2015-09 vani会确定去哪里工作，我在哪？ \
