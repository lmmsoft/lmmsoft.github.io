记录一下自己对相关问题思考 \
\
 【对孩子培养投资将焦虑？】 \
 比如现在有中专业的孩子学习桌椅套装，几乎家家户户都有，宝妈同事也每家都有，一个都要6k到1w，当时宝妈觉得压力很大，但是后来，我们在网易严选店里发现同样的东西只要2-3k，就放心多了，在我们心中，网易严选东西的质量是过关的，如果拼拼多多有同样低价的东西，我会选择相信，而宝妈不一定会相信，会带有偏见。 \
\
\
 【对子女教育投资的焦虑？】 \
 Q1.宝妈特别焦虑，担心教育会花很多很多钱，我是这样解释的。 \
 A1. 我们家附近幼儿园，小学，初中，都有公立，收费不贵。如果想上顶级名校，要么花很多钱买顶级学区房，要么就上很贵的私立，而我们家附近的公立还不错，完全不用太焦虑。 \
 Q2.宝妈继续担心公立学校什么都不教，课内吃不饱，课外要花很多钱补。 \
 正好看了一些视频，是我前同事做的，他离开微软后，在学军中学做信息奥赛教练，带出了十几个保送清华的学生。现在自己创业，他揭露，现在少儿编程，就靠给家长贩卖焦虑赚钱，最近还有机构捐款跑路，金额1.2亿。在这些培训机构，找了些没什么技术的老师，也教不会学生多少有用的知识，说劳民伤财不过分。 \
\
 而跟着他学，直接用现在最先进的训练方式（基于OJ，专题训练，周赛，答疑），和全球的孩子接轨，完成什么样的练习（比如codeforce的rating紫色），就能达到什么水平（比如弱省省一，强省省二，USACO铜牌这样），非常直观，非常高效，孩子是不是这块料，家长很快就能知道（比如我练了几年，cf还是绿色，基本就没什么戏了，哈哈），在cf/leetcode等平台和全球的高手同场竞技，知道自己在水平和手速上的巨大差距。 \
\
 继续推演，我和宝妈回顾了我没最近这些年学习一些技能的路径。 \
 【学潜水】淘宝上随便找教练，学得也一般。 \
 【学自由潜】选到了国内的顶级教练（后来这位教练还上过欢乐大本营），朋友圈也加到了国内最牛的几个教练，看他们在全球参赛/办赛的经历，我们大概知道了深入这项运动的路径，和顶级玩家的生活是什么样的。 \
 【玩铁三】我在微信上加了全国各种铁三圈的人，有媒体人，本地爱好者，国内知名业余运动员，职业教练，国家队选手，退役选手，赛事总监，官员，甚至还有上届里约奥运会的国家头牌。我也见证了这几年大环境的发展，也看到了职业选手在台上和退役后的生活。我自己该如何训练，现在行业里最先进的训练理念是什么？（国家队的训练方法比较落后），我自己的天赋如何，甚至自己的参赛成绩都是可以成功被科学预测的。 \
 【玩越野】同样的，圈子不算大。几年前的国家男女头牌都在我的朋友圈里，如今新人辈出，前男头牌这两年饱受伤病困扰，女头牌结婚生子，经常晒娃。 \
 【下象棋】去年疯迷过一整子中国象棋，经常看当今第一人王天一的直播，知道了现在选手都是怎样训练的：就是很电脑下，现在的人工智能比人类选手厉害太多了，第一人在直播里，经常遇到作弊的对手，很难赢啊。如果让我谈谈理解，学棋不一定会花很多钱，老师领进门，然后网上或者人工智能多练习（免费的），网上看视频，然后找找高人复盘指点（甚至可以远程指导，这样费用会远低于线下），有天赋很快也能脱颖而出。去年还专门看过《胡司令外传》，当时的象棋宫，体校训练方式，和现在完全不同。去年全国象棋赛的冠军，居然是个职业是公务员的业余选手，先拿了业余冠军，然后参数全国冠军赛，意外夺魁。他是年少时下过棋，后来高考，大学毕业做公务员，业余时间通过网络、人工智能训练，居然拿了最有含金量的比赛冠军。 \
 【皮划艇、桨板】我去年国庆报了个培训班，在千岛湖，一对四，教练是前中国国家队教练，还是美国皮艇球队的成员，美洲杯冠军。怎么教练在浙大做外聘体育老师。找到这样的教练，让我少走很多弯路，知道成长的路径是怎么样的，如果我的孩子想学习，我会让他们参加对于的青少年培训班（教练说杭州家长有很强的购买力），我自己也会在周末带娃在楼下河道了训练，很透明，也不会花很多钱。 \
 【足球】虽然我是球迷，但是我完全搞不清楚人才的培养机制，欧洲，南美是如何搞青训的，中国现在的青训水准如何？孩子喜欢的话，该如何培养？这些我目前一无所知。 \
\
 综上所述，如果能看清当前人才培养的趋势，结合环境的优势对症下药，可以少走很多弯路，费用可控，也能迅速知道孩子的天赋在哪里，如何因才施教。（比如杭州游泳是国内比较厉害的，浙江信息学奥赛全国领先，在中国踢足球没前途，哈哈） \
\
 Q3 小学阶段该做什么？ \
 A3: 从我最近的了解来看，小学阶段孩子应该多玩，首先是轻松完成课内的任务，其次是不用在课外花太多时间刷题（性价比不高）。孩子应该多玩，多尝试不同的爱好，找到相对适合自己的，在玩中培养兴趣。小学的知识点不算多，培养思维更重要，然后初中培养学习习惯，高中就一切为了高考。 \
\
 如何教育孩子，我还需要读更多相关的书籍，并在实践中优化。 \
