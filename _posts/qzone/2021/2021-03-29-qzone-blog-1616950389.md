距离上篇日志已经9个月了，又发生了很多事情。怀念大学的时候，几乎每周一篇，各种鸡毛蒜皮的小事都能记录下来，现在很多更重要的事情都没有得到记录，感觉这本身就是一件很遗憾的事情。 \
\
 先说说今年（2021年）1月到3月发生的大事情吧。 \
\
 1-1 父母来杭州生活，目的主要是照顾我妻子的，每天接送上下班，因为我们的孩子快要出生啦。2021年应该是父母60年来第一次更改定居城市，之前60年里，父亲去东北当兵2年，其他都在南京，母亲五十七年里，每一年居住城市都在南京，每年至少300天。今年他们在杭州生活的时间，应该会超过南京。 \
\
 1-21 收到录取通知书，开始在职硕士的学习，专业是CS。算是花钱买个文凭吧，后悔没有在刚工作的前几年做这件事，现在家庭的事情比较多，容易力不从心啊。 \
\
 2-10 龙湖冠寓退房。过去9个月，为了加班更方便一点，在公司附近租了个公寓，周一到周四晚上居住，这样晚上十二点下班，可以很快休息。家离公司25公里，每天来回奔波，实在太累了。春节之后因为孩子会出生，需要更多时间陪小孩，所以还是继续选择来回奔波。 \
\
 2-12 春节，今年在杭州过年，领取外省人在杭过年1000元补贴，比较老实，没有离开过杭州。 \
\
 2-26 ，我的同卵双胞胎女儿，小珊瑚和小海兔在浙江省妇幼保健医院出生。 \
\
 其他大事应该没什么了，反正都是每天上下班，周末出去转转。上班25公里，早上一般十点多到，晚上十点多到家。 \
\
\
 最近学到的一些想法： \
\
 part1，和一个在硅谷工作的gg聊天 \
\
 gg是北京985本科cs毕业，先去西雅图的微软工作了2年，做scope相关的工作(微软的大数据框架)；再去三番的脸书工作，转型做iOS开发；然后在创业公司wish工作，大概是600+号员工，后端开发，业务，微服务，k8s什么都接触到了。我在问这几次转型为什么跨度这么大？他的回答对我很有启发： 他说主要是未来想创业，所以前端，后端的研发都主动去尝试，这样未来创业的时候，就知道工作具体是怎么回事，团队如何搭配了，等等。 \
\
 回想起我自己的经历，也挺杂的，先是测开，然后是安卓，然后是全栈，现在是运维开发。但是我的转型不像他这样具有主动性，前几次都还是被迫的转型。大概只有最近一次的DevOps是我个人兴趣使然，也想在这方面多做一些工作。 \
\
\
 迫使我思考的是，基于主动的变化，和被动的变化，对人的前途，会有多大的影响？ \
\
 比如gg为了未来的某个目标，持续演进，感觉不太在乎短期利益。 \
\
 而我似乎完全相反，主要关注的是当前的某些短期利益，几乎很少思考未来要做什么， \
 比如老板给了我一个新项目，这个项目是个好机会； \
 比如团队总体的卡位比较好，有很多有价值的事情可以开展，上下游有很多合作的机会； \
 比如这个赛道是个风口，未来一片光明； \
 比如这个公司未来要上市，有一定可能拿到一些原始股，等等。 \
\
 然后我接触到下面三个概念： \
\
 【信息茧房】只看自己喜欢的言论，互联网也会总是推荐你喜欢的内容，导致你会陷入一个茧房，意识不到外面的观点。 \
 【路径依赖】之前成功的路径，会一直依赖它，导致自己会陷入某种局限性。 \
 【模拟退火】一种解决陷入局部最优解的方法，就是会在很大的区间里进行尝试，做优化，而不是在小区间里面做优化的办法。 \
\
 （信息茧房）如果每天，或者长期只和身边的同事交流，可能会深深陷入公司画的大饼里。 \
 -&gt;我需要多和不同地域，甚至是不同行业的朋友交流，我朋友圈有接近2k人，总有愿意和我深入交流的朋友吧。 \
\
 (路径依赖)如果一直重复自己擅长的事情，大概会在舒适区呆很久，而陷入某个困难后，跳不出来，因为跳的姿势不对，而我只会之前的一种姿势，新的坑需要不同的姿势怎么办？ \
 -&gt; 我现在在工作中似乎遇到了这样的问题，我的代码能力，项目管理能力，能够很好得完成现在的研发，但是我的跨部门沟通能力不行，有些事情迟迟不愿意投入，一直没搞定，老板似乎也不想代劳，而是一直提醒我自己搞定。 \
 -&gt; 我也用路径依赖解释身边朋友的问题，比如一个朋友，考试能力特别强，于是隔几年就会换个全新的行业，反正从业资格考试，复习几个月都能搞定。我理解是依赖考试的路径，但是大家都工作5年以上了，这时候可能更需要积累，而不是换赛道从junior做起。 \
\
 （模拟退火）之前听几个朋友分享他们自己模拟退火的方法，比如隔几年换个工作的城市，换个环境，一条路往上的职业发展可能会受到一些影响，但是也会遇到很多新的机会，认识很多新的人，熏陶到新的文化，也会有新的生活方式。 \
 -&gt;我自己该怎么做呢，比如现在有家有孩子，换城市的成本会比较高，继续深造也会有成本，出国会对家庭和子女教育产生更大的影响。 \
 很多人买一些锁定利率的理财产品（比如终身寿险），也是希望能买一些对未来的确定性。我现在32岁，不算早，也不算太晚，有雄心的话，还是有很多机会的。 \
\
 从现在杭州或者一些重点城市政策来说，对新人是非常友好的。新人可以摇号买房，买到一些现价盘，从二手盘倒挂的情况来看，这就是给新人送钱的机会。城里持有老破小的原住民，相比年轻人，更容易错过这些机会。 \
\
 从上面的角度来看，我在杭州限购，为了孩子换大房子的成本非常高。 \
 杭州容易落户，落户之后可以买一套住房，就是个好机会。 \
 深圳以前也是容易落户+立即买房，现在是5年社保或者三年户口，时间成本就大很多了。 \
 怪不得去年杭州抢人又是全国第一，除了产业之外，新人政策太好了。 \
\
 对于我来说，搬到其他城市，坏处是失去了不少打好的基础，好处是换换环境，看看新的机会，随着年龄的增长，机会成本会越来越大。 \
