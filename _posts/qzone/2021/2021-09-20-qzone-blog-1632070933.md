接上回《  486 IIT第一学期学习总结  》 \
\
 第一学期选的是有基础的课程（算法导论），拿了A，第二学期有些飘，吃了大苦头，且听细细道来。 \
\
 第二学期是夏季学期，算是小学期，春秋学期16周，夏季只有8周，而夏季的大部分课程只排在前5周（第五周就期末考试了）而课程和学分和教学内容和春秋学期几乎是一样的，相当于5周学完16周的课程，压力还是很大的。 \
\
 美国大学的课程强度和中国不一样，我本科阶段一学期能选10+门，据说美国本科生一学期也就选4门课。 \
 这边IIT的硕士，在校生一般每学期选三门课，不建议选超过三门（课业压力大），暑假学期如果不出去实习的话，估计是一到两门。 \
\
 我一开始有点心大，想选一门硬课，再搭配一门水课。或者看到有时间错开的两门课，比如第一门1到5周，第二门4到8周这样。 \
\
 后来观察了一圈，还真碰到了。比如CS525高级数据库在前五周，CS487大概从第三周开始更新，会有12周，前六周大概是自学，后六周应该是视频和作业。CS487是软件工程，应该算是比较水的课程，期末考试不重叠，精力上应该顾得过来。 \
 与此同时，还有硬课 CS525机器学习也传出要增开暑期课程的消息，不过后来取消了，教授说是邮件发错了。这门课相对较硬，个人是希望能用一学期，完整系统得好好学习的。 \
\
 CS525是被动放弃，CS487就是主动放弃了，因为开学后，我发现自己很难跟得上老师的进度，都是quiz 期中期末的时间在压着我跟上。每周5小时的视频，老师英语语速飞快，语音识别的翻译质量很差，听课不仅无法用倍速，往往还要停下来，重听，或者是截图记笔记等。每周实际需要的学习时间，大大超出预期。 \
\
 ———————————————————————— \
 时间有限，这里简单用时间顺序，介绍一下这一个多月的煎熬： \
\
 5-25 第一周开课。 \
 6-1 第二周开课。 \
 6-8第三周开课。 \
 6-15 第四周开课。 \
\
 6-16 quiz， 小测验，我得了 29.5/62分，得分率不到50%，不及格啊！ \
\
 6-18下午，我给教务老师发消息：“暑期只选一门CS525，准备选其他课了。时间紧，有点来不及” \
\
 6-22 第五周开课。 \
\
 6-22晚上九点，期中考试，3小时，开卷。我得了52/56分。期中考试因故延迟了，其中到期末只有一个星期的时间准备，课程还没完结。 \
\
 随后这一周一直在补课，每天看1-2小的视频，外加1-2小时的欧洲杯足球比赛，很不自觉，自控力跟不上，进度达不到要求。 \
\
 7-1 周四晚上八点，期末考试，4小时，开卷，我得了 95/110分。（因为来不及复习，我很狼狈得请了一天假在家备考，原计划是看完视频的，结果进度没跟上，上午只看了一点视频，下午跳着看了重点的视频，丢弃考试范围之外的大部分视频，傍晚勉强刷了点题目，助教给的历年真题，真题很有用，直击灵魂，虽然不能让我学会知识，但是可以心里有底，知道题型和考试范围。最后分数超出预期，很满意！） \
\
 大作业是三人组队，完成，用c语言实现数据库的基本结构，前次作业是后续作业的先决条件。 \
 大作业一：6/4截止，队友一完成的，得分 100/100 \
 大作业二：6/14截止，队友二完成的，得分80/100，大概是交作业的最后一天才开始，我和队友远程协作，他写主要部分，我做了点附加题和文档部分，核心代码大概是最后一小时才完成的，太险了。 \
 大作业三：6/26截止，队友一完成的，得分90/100 \
 大作业四：7/3截止，我完成的，期末考试之后的才提交，给了我一定的缓冲时间，可以先复习备考，再冲刺作业。得分 90/100，分数很意外，因为我写的代码有很不完整的，有很大的漏洞，部分官方的测试用例也过不了。我猜最后大家完成度都不太高，所以我混到一个不错的分数，如果让我自己评分，可能60都到不了。 \
\
\
 最后总成绩，算数平均分（非加权）87.21分，加权可能会更高一点，这门课老师比较慷慨，80分以上就是A了，我居然拿到了A。结果无比好，过程无比痛苦。。。 \
\

 ps: 这篇在草稿箱里躺了很久，乘着中秋放假在家，赶紧写完成。现在第三学期已经开学了，再过两个多月，估计又要写第三学期总结了。 \
\
 这里先提前为第三学期总结订个基调： \
\
 在学校的几年，正式埋头干事，低头学习的好时机呀，毕业之后，各种杂事就多了起来。自己的事情都做不完，更别提还要关心服务，更要照顾子女了。 \
 最近三个学期，我每个学期开学的心境都完全不同： \
\
 第一学期：下决心要读个硕士学位，我要努力学习，争取取得好的成绩。 \
 第二学期：最近工作太忙了，课程又紧，太痛苦了，争取能把这门课混过去。 \
 第三学期：最近分心分时间的事情太多了，选了两门好课，肯定是学不来的，先退掉一门。如果不是一学期一门不选要办休学手续很麻烦，我甚至可能考虑两门都退掉算了，等后面其他事情稳定下来再说。。。 \
\
 可以看出，我的生活状态，变化很大，工作重点，也不断迁移。安心读书学习，怕是越来越难咯。
