接上篇 \
\
 《 484 远程硕士学位申请总结》  https://user.qzone.qq.com/〔原账号已隐去〕/blog/1623433154

\
 上篇讲了如何选择硕士项目，申请到入学的心路历程，这篇开始讲学习的经历。 \
\
\
 IIT全名伊利诺伊理工，学校位于芝加哥市区（反正我是没去过，短期内因为疫情，也没有去的可能），全美排名大概91左右（前100，也不算太差，哈哈）。 \
\
 【学制】 \
 每个学年分为三个学期，春夏秋。春秋是长学期，大约16周，夏季是小学期，大部分课程是5周左右。 \
\
 不像国内只有秋季可以入学，这里每个学期都可以入学，但是大的开学仪式和毕业典礼每年只有一次，今年还是线上的，对于On Campus的学生，春夏学期部分课程（学生）线上，部分线下，秋季学期可能会回归线下为主的授课方式。 \
\
 【学位】 \
 授课型硕士学位，按要求修完10门课就可以毕业，无需毕业论文。如果非科班出身，需要先修 CS401+CS402 两门预备课程，共计12门课程。 \
 10门课里有3们是4xx的基础课程，有7门要求是5xx的高级课程。我是CS专业，7门高级课程里，有3门需要在三个方向里选择，剩下4门可以系内任选。CS系的AI专业，需要修两门跨专业的课程。其他我知道的，还有ECE (类似于EE)， 软件工程(IM信息管理)等，看宣传还有针对中国学生的商科，我没接触过相关的同学。 \
\
 【授课方式】 \
 我是远程学位，所以所有的课程都是线上。其实官方的线上课程也有两种，同一个班上，一部分同学是在同步的，在线看直播，和老师互动的。包括我在内的另一部分是异步的，就是看前一半同学的授课录像，然后完成作业。异步学生大概也分为三部分，美国异步学生，使用学校的blackboard系统或者zoom学习。中国异步学生，主要使用中国中介机构的lumian系统学习。原则上中国学生也可以用blackboard上同步课程，但是因为市场，网速的原因，课操作性不强。印度也有专门的班级，学习方法未知。 \
\
 同步和异步两部分学生的学习和考试内容基本差不多，稍有区别的是quiz, 因为异步学生没法做实时的课堂小测验，所以有的老师会换成extra homework, 有的老师干脆直接把测验带回家做，要求24小时内做完。 \
\
 【教学内容】 \
 教学内容包括 每周两次课程，每周一次TA 时间（中国学生有专门的中文助教时间，我选过的两门课都是来自中国的博士生），教授的office hour等。日常小作业，项目大作业，小quiz, 期中期末考试等。 \
\
 【期末成绩】 \
 期末成绩由所有作业和考试加权得得出，比如我第二学期的CS525课程，四次大作业共50分（10+10+15+15），小测验5分，期中15分，期末30分。因为是异步学习，不计出勤，可以弹性学习，还是挺适合远程的。 \
\
\
\
 【第一门课CS430】 \
 第一门选的是CS430，教材是《算法导论》，算是算法的入门课，主要讲常用数据结构和图算法，学的内容和我在国内本科的算法数据结构内容差不多，难度大一点，作业要求还是蛮高的，每次作业都要做好久。 后续还有门CS535, 是研究生课程，都是高级的图算法之类的，ACM比赛会遇到，一般大厂面试也不会遇到。 \
\
 CS430 是很多5xx课程的先修课程，包括AI方向的机器学习等课程，所以几乎所有CS系的同学，第一学期都会选这门课。 \
\
 【上课】 \
 长学期，每周两次课，每次1h15m，我的英语听力不行，常常要暂停下来，偶尔也加速播放，学完一门课大概要1.5小时以上。 \
\
 我学习进度很慢，平均落后直播1-2周，期末前几周落后太多了，来不及看视频，只能直接做作业了，最后一两节课讲了NP等期末不考内容，于是我到现在都没学。。。想想一门1万元RMB左右的学分，很亏啊。。。 \
\
\
 【日常作业】 \
 作业每次3-4题，大部分和leetcode上的题目也差不大多，需要写伪代码，或者 c++,java,python，还有给出证明等。 \
 我一般都是交作业的deadline 前几天开始看题，最后一天夜里才最终完成，第二天中午12点提交截止。 \
\
 记得最惨的一次作业，是我的孩子出生，我还在医院陪护（因为疫情，每家只允许一个人陪护，24小时都是我），出院的那一天中午12点，是截止日期。我提前两天晚上写了一点，提前一晚准备熬夜肝，因为孩子闹，加上自己精力不足，没写完就困得不行，只能睡去。早上起来搞了一点，然后跑出院手续，最后在开车去月子会所的路上，做了最后一题。到了会所，来不及入住，在大厅里连接WiFi提交的，最后那次左右还晚交了5分钟。原来的规则是晚一天扣10%，后来变成1%, 损失不算大，但过程很狼狈。 \
\
 后来好几次作业和其中考试都是在月子会所完成的。 \
\
 【期中考试】 \
 期中考试难度不大，晚上9点到12点，我是在月子会所考试的。题目我觉得比较简单，2个多小时就做完了，最后做的题目都对了，但是读题不行，有两题没给出运行时间复杂度的证明，扣了7分，最后93 \
\
 【大作业】 \
 大作业挺有意思，用最少根的横竖线分割网格上的点，要求每个点都在不同的区域，问题最少几根线。 \
 这是个NP问题，老师曾经写过相关的论文。 \
 作业要求两人组队，一个用贪心算法，一个用启发式搜索。我写的是贪心，自己yy了个贪心思路，最终运行出来的结果还不错，但是收到助教的邮件，说实现得有些问题，几个邮件来回交流了几个案例之后，发现贪心的策略有限制，不是随便写的，要按照题目的要求实现规定的贪心策略，后来熬夜更新代码，最后大作业得了100分。 \
\
 【期末考试】 \
 期末三道题，两道水题，一道完全背包，作为动态规划的题目，稍具难度，作业里做过01背包。我因为以前学习过《背包九讲》，所以完成得比较好，最后还是因为读题的原因，漏了一些证明，扣了6分，最终94分。 \
\
 【期末成绩】 \
 非加权平均分是92.1%, 原定是90分以上A， 后来86分以上就A了。中国学生这边，班上大概40-50左右的学生，13个A。 \
\
 第一门课因为之前有基础，碰巧拿了个A，导致我有些飘，然后第二学期有些冒进，吃了大苦头。具体的内容，详见下回分解。 \
\
 如果有任何问题，欢迎留言交流~ \
