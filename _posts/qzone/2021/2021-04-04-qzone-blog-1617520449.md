续上一篇，记录一下我和hp交流的一些收获： \
\
\
 a. 时代在变化，各种收藏品，理财产品，爱好，造富手段，都在变化： \
\
 1. hg:看最近发布的中国富豪榜里IT圈子的人是做什么的，60后70后以移动互联网居多，80后主要是手游圈子的，90后上榜几乎都是币圈的。不同时代，有不同的发家致富方法 \
 2. hg:看到很多美国的拍卖活动，比如爷爷收藏了一个印第安人的藏品，若干年前是什么价格，现在还是差不多的价格，完全不能抗通胀。还举了一批游戏卡牌的例子，也是如此，当年晚的人多，价值高，现在年轻人有更好玩的手游，这些藏品不值钱了。 \
 3. 和父亲交流，父亲关注了南京书画圈多年，知道这些年的价格走势，大致结论是：大部分人已经退出江湖，作品一文不值，无底价排名，现在再不出手，以后会跌得更厉害。头部名家的作品抗通胀，升值高，拍卖价格水涨船高。他的结论：长期看艺术价值，中期看市场行情，短期看运作。 \
 4. hp现在在玩加密货币，和上面是一样的道理，每年都有新的玩家入局，很多都是空气，能形成共识的会价值猛增。 \
 5. 对于90后 00后在玩什么，不能抱有偏见，不理解会导致被淘汰的。这是新金融，融合了数学，互联网，哲学在里面，要好好学习，而不一定是投机。 \
 6. hp给我讲了个叫做 NFT的东西，当时我还不知道这是什么，随后的一个月，几乎每天都能看到关键词，NFT xxx 的拍卖价格又创新高。。。 \
\
 结论：年轻人不接老人的盘，他们会有新的玩法 \
\
\
 b. 有钱的地方，就有顶尖的大脑 \
\
 1. hp在认识了很多90 00后优秀的人，他们思维，理解，生活的有趣程度都碾压大部分上一辈的人，从聊天就能看出来，非常得厉害。 \
 2. 他们的执行力非常强，美股，港股，打新，币等有些门槛的东西，玩得都很溜。 \
 3. 新行业，做个半年的收获，可能抵上在老行业做8-9年 \
\
 c. 一家之主 \
 1. 我们的孩子都出生了，现在理应是一家之主了，未来的生活怎么规划，要拿出点实际行动了，不能总等着父母安排吧。 \
 2. 我也是个爱尝鲜的人，比如每年会尝试不同的新体育运动，马拉松，铁三，越野，皮划艇，桨板都玩过。 后面建议应该过尝试不同的赚钱方法，有想法要早点干。 \
\
\
 聊天之后的action: \
\
 1. 几年前注册过一个火币账户，大概买了几千块比特币吧，按照市值，现在应该翻了3-10倍，可惜账号写了所在地美国，现在被封，试了几次都没找回来，很郁闷，不知道有没有人有路子？ \
\
 2. 在币安开个新账户，做些定投，计划从收入的1%开始，逐步做些资产配置吧。 \
\
\
 最后： \
 当时打了好几次电话，聊了很多东西，记录了好几页的笔记，感觉很有收获。可惜没有及时消化，比如用自己的语言记录下来，现在回忆起来，也没有多少东西，很遗憾。 \
\
 补充： \
 最近在看《我们终将变富》这边书，几年前认识作者，他学习并实践的事情，比如买房，买基金，配置保险，其实我也做过，时间节点差不多。 \
 但是他做完了，还写公众号分享，做小范围布道，现在也出书了。 \
 我基本上是短期目标完整之后就没有了，由于没系统输出（比如写作、做视频等方式），现在我已经忘掉了大部分曾经学到的知识，于是只能看他的书复习，说起来真是遗憾啊。（在铁三等运动上，我也是一样的情况，之前对于功率骑行，大铁训练，有研究有实践，现在变成180斤的大胖子，TMD全忘了） \
 他大概是和我同一年毕业，这几年看着他一步步换工作，在北京和深圳买房，还真是实践了书名，我们终将变富。 \
