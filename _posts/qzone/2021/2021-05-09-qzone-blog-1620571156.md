最近每个几周都会和一个老朋友聊一个小时左右，我自己比较真诚，问我的问题都认真回答，所以也能反问到一些不错的故事。 \
\
 昨天联系的是一个前同事，她和我是同一年的。 \
 本科毕业于重庆工某高校，学自动化。 \
\
 毕业后回云南老家工作了几年，工作比较闲，没什么挑战。 \
\
 后来去了北京发展，一是追求个人发展，二是因为爱情。 \
 在北京转了程序媛，可能是接受了职业培训，然后在外企做外包，工作内容是功能测试，这个岗位主要是做手动测试，她做功能测试的时候，工作认真负责，老板们的印象都不错，但是这个岗位上限比较低，在大公司里几乎都是外包岗位，如果转测试开发，上限就比较高了，但是几乎要和开发拥有类似的代码能力，比功能测试难度大不少。当时应该是14-15年，这个岗在北京的收入大概是大几千块，生活压力还是比较大的。十点多上班，五六点就可以下班，工作压力不算大。 \
\
 后来有个一起做功能测试的同时考研上了北大，给了她很多启发，她也决定考研。因为外包的办公室和正式工在不在一起，工作之余可以有足够的时间学习。 \
 后来大概15年10月左右辞职，没和任何人说去哪里，其实是回家考研了。大概12月底考试。中间11月的时候情绪有写反复，后来还是坚持下来了。 \
 考研没敢报北大，报了北航，也是985牛校。分数不够高，感觉全日制够不着，后来找了学校，改成非全日制，成功，顺利上岸！ \
 上岸到开学还有大半年时间，找了份工作做起来。 \
 9月份开学后，就是在职研究生了，周中有三个晚上要上课，周末也要上课，课业压力还是很大的。 \
 北航软件工程专业，当时全日制的学生不上课的时候都在给老师做项目，非全日制在企业里工作，其实如果工作的内容合适的话，几年的里能学到的东西和经历并不会比全日制的同学差。当然她这几年并没有做到好的项目，读书花的精力挺多，工作还是以划水为主。 \
 在研二到研三的时候完成了怀孕到生子的过程，这两年特别辛苦，工作，读书，孩子。哺乳期睡不好，毕业论文答辩期间更是鸭梨山大。 \
\
 全日制的同学，平时好好做项目，毕业前好好刷题，能进大厂，拿到不错的Offer。她因为不是特别爱写代码，毕业后转了产品经理，既可以参加校招，也可以参加社招。这次是名校毕业，求职无论是岗位，还是待遇，都比之前好了很多。后来去了一个在线教育的公司做产品经理，但是老板是线下转型线上的教育，思路还是线上给线下导流量，没有发展一般，上个月跳到了一个新的纯在线教育公司。 \
 因为我也是这个在线教育公司的用户，所以有了我们这次交流。 \
\
 最后我们约每隔半年到一年可以再通话一次，这个频率比较合适，平时朋友圈电子就好了。 \
\
 PS: 主要是聊奋斗经历，所以省略很多其他东西，这里稍微补充一下家庭生活现状：她的父母来北京帮忙带孩子，现在是全家5人住在海淀的一个租房里，每个月租金大几千。婚后在朝阳买了个小的学区房，大约50平方，计划是未来几年换个大点的房子，能住进全家5人。
