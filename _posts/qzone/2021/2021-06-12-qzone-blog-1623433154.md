今年开始在线上读远程的计算机硕士学位，第一学期结束了，记录一下过程和体会吧。 \
\
 一： 报名+申请+录取： \
\
 1.1 想法转变 \
 早几年的想法一直是我是搞工程的，计算机本科毕业就够了，早点开始上班，多打拼几年，升职加薪，不必读没有的硕士差。 \
\
 这两年的想法有些改变，诸如人工智能的岗位，毕业之后待遇优厚，起点高。而且有些技术门槛，我这种底层码农基本绝缘了，而且现在校招生越来越厉害，面试越来越内卷，后浪们真得太厉害了，很怕自己被淘汰，怕35岁输送回社会，于是这两年逐渐有提升学历的想法。 \
\
 另外家属是985硕士毕业，我是211本科毕业，感觉差了一大截，得提高文凭，提高在家里的地位。 \
\
 1.2 明确目标 \
 深造我大概考虑过几个方向： \
\
 【国内全日制研究生】考研很痛苦，要学数据政治，还要和一群nb的全职学习毕业生竞争。难度太大，放弃。（另外我对于脱产读国内硕士的收获性价比比较怀疑，耽误3年时间，有可能天天做一些没用的项目，学到的东西，还没在公司多，并且公司是带薪的） \
\
 【国内非全日制研究生】对于我来说，这个选项比上一个好很多。工作还在，家庭的开支有了保障（房贷压力不小），然后利用业余时间，上上课，就能混个学位。身边也有些例子，比如好朋友Lucas在北京工作，考人大的研究生，后来调剂到首都师范吧；以前同事杨叔，在北京工作期间读了北航的硕士。不过非全日制研究生有个隐含的限制，就是地域问题，北京上海这样大学多的城市，比较好，而杭州只有一所985和211，就是浙大，其他学校的学位对于我来说，含金量不太够。我关注过浙大非全日制的招生通知，计算机方向在杭州没有非全日制的学位，比较遗憾。我猜想，杭州有很好的IT人才储备，如果招计算机方向非全日制的学生，应该会有很出色的生源吧。 \
\
 【MBA/EMBA】这个是后来接触到的方向，有一次听我老板的老板的老板的老板分享（研究员P10），他说认真复习，参加了全国统考，上了浙大的EMBA，后来我当面去问过他这方面的建议，他的意思是MBA/EMBA这样的学位，更适合老板、CEO、创业者这样的人去读，学到工商管理的知识只是一部分，更重要的积累人脉，我现在资历尚浅，还没到读MBA的时候，估计也很难被录取。 \
\
 【海外全日制硕士】这个选项几乎一直没有考虑过，因为要考GRE，TOEFL，而且我的本科GPA不行，好的学校根本不用想。另外如果想移民美帝的话，其实还有直接从海外抽H1B的路子，虽然这两年几乎看不到了，另外外企国内分布，然后F1签证去美国的也很多，我以前在微软的同事，很多都去西雅图了。 \
\
 【海外远程硕士】这个是我最终的选择。 \
 大学毕业后的几年不知道有这样的玩法，否则我可能婚前就读了，不用等到现在还在出生了再读书，精力跟不上。 \
\
 前几年看到过coursera上有远程计算机硕士学位，比如UIUC这样的计算机名校，后来查过一些资料，申请人都是大厂里的牛人，而且对G/T/GPA也有不小的要求，总之并不好申请，我就没有什么心思。 \
\
 今年在刷知乎的时候，看到了国内几个培训机构的广告，类似于留学中介，提供ASU，IIT这样100名左右的学校的远程学位，后来我具体搜寻了这几家的资料，最后选了一个北京的创业公司提供的IIT的服务，深入了解了一下。 \
\
 提供的服务：只交学费，不收中介费，学校从学费中给机构返点。不用考GRE/TOEFL，四六级成绩就可以申请。第一年远程读，学费低，第二年还可以选择转线下，交全日制的费用。提供助教、辅导等增值”保姆“服务，绝对不是申请上了就不管你了。 \
 线上550美金一个学分，30个学分可以毕业，全线上大概11w元吧，线下每个学分的价格大约是线上的3倍，另外食宿费用也不低。 \
 这个挺符合我的口味的，11w的学费比国内读研贵多了，但是比浙大的MBA还是要便宜一点的。学校大概全美排名91吧，等同于末流211吧，另外还可以转线下，我暂时没去线下的打算，同学们去线下的目的主要有两个，1)获取OPT/CPT留美工作，2)获得留学生认证，从而获取体制内的职称，或者上海户口。 \
\
 去年疫情，很多留学生都被迫在家上网课，大部分和我这种都差不多了。在B站上看到有康奈尔的本科生，可以去清华交换一学期，选清华的课，感觉好厉害！ \
\
 这里最好再说说申请的流程：在网上搜索并做了一番调研之后，基本上确定了读美国远程计算机硕士的方向，然后加了机构的顾问（销售），详细了解的流程，时间差不多是春节前一整子，IIT的春节学期开学前一两周吧，未来赶上春节的申请，迅速做决定，一天时间之内搞定了大部分材料，只差本科英文的成绩单了，顾问帮忙咨询的我的本科学校，需要去现场开证明（很多学校都可以网上远程开成绩单了，尤其是疫情+ 最多跑一次之后），因为疫情，我暂时还进不了学校，找了老朋友尹博士帮忙，刚好距离学校放寒假只有几天的时间， ，尹博士接到我的电话之后，第二天上午就帮忙开到本科成绩单，本来学校也有翻译服务的 ，但是放假了。后来是该机构帮忙做的翻译。申请提交上去后，大概一周左右就接到了录取通知书，开学后几天，我完成了第一门选课，进了班级群，正式开学啦。只耽误了半周课程，不影响的。 \
\
 后来看了班级同学的自我介绍，发现我发背景还算好的，有很多跨专业申请的同学，还有一些在家脱产读书的同学，也有在海外的同学。与之前机构公众号上的宣传：”有清华北大的本科生，现在一边创业，一遍读这个远程学位“，相去甚远。 \
 不过该机构的服务还是不错的，助教，班级群，都有不错的氛围。独学而无友，则孤陋而寡闻，能找到一群志同道合的同学，非常得有帮助。 \
\
 写到这里，已经好多字了，这篇原来标题叫做《IIT第一学期学习总结》，本来是想写一点学习的感受，结果 《一：申请》的内容写太多了，学习的内容就放到下一篇里吧，以后争取每个学期都能写一篇。一句话概括第一学期的，就是学校可能比较水，但是课程不水。 \
\
