转眼间又是大半年没写日志，上一篇是19-09-02，现在是20-06-15, 9个多月，外面世界大不一样（疫情），我的生活也完全不同（工作）。 \
\
 去年12-31离职，然后去了黄山+名古屋+北海道，今天1-13入职新工作，现在在阿里云-混合云做工程效率的工作。 \
\
 大概是四五年前开始对DevOps感兴趣，虽然没有全职干这个，但是一直主动在(大公司的)组里/(小工程的)公司里主动揽相关的活，搞搞持续集成，持续部署，自动化测试，代码检查，等等。一开始用VM，后来用docker，现在是私有云。 \
\
 随便写点体会： \
 1. 现在我算是把感兴趣的东西多做一点，并找到了对口的工作，幸福感比较高。之前搞过测开，搞多安卓，还搞过全栈，好像都是被动的，最后也没搞出什么名堂，几次换工作也都没什么亮点。 \
\
 2. 都说"面试造火箭，工作拧螺丝"，想想自己的现状，面试没有到造火箭🚀的程度，工作倒是挑战很大，感觉比招我进来的时候的难多了。后来听说，是去年年底招聘放水混进来了，最近口子收严，还是当时的面试表现，说不尽就进不来了。。。 \
\
 3. 现在的直接老板，是个敢派活的人。比如组里两年前校招进来的新同学，就敢派个难度很大的活下去做，初生牛犊不怕虎，居然敢接，然后奋斗了两年，结果非常好。看看和他同一批校招进来的，差异很大，scope的大小差了很多。我现在接的活，也是在试用期没满，没搞清楚的情况下接的，不知道之前已经干倒了两拨人，据说之前有些"老司机"之前也思考过，后来还是没接，哈哈。 \
\
 4. 有时候想想看，现在的压力大，很大程度上是业务倒逼，而不是无聊。现在做的东西业务价值显而易见，就是不好做（之前干倒了两拨人）。这种项目，比难度小，但是不容易落地，找不到业务价值的，更值得挑战啊。 \
\
 5. 现在的直接老板，敢派活，要求高。受不了的，走了不少，抗过来的，也拿到了不错的结果。想想看，是不是和体育里经常出现的”魔鬼教练“很像？混日子的，显然不适合。但是有想法的，如果一直没遇到好的教练，似乎也锤炼不出来啊？我自己的，前几年过得太安逸了，太舒服了，家长都看不下去。现在换了份压力大的工作，家人又开始心疼了，哈哈~ \
\
 6. 之前一直喊缺人，事情多，搞不完。最近倒是摸索到一些诀窍，就是搞"共建"，身边有些团队有人力冗余，不仅没好的项目做，而且新人培养也需要消耗精力啊。我把人借过来，一边帮忙培养，一边也能分担一些事物性工作，虽然没轻松多少，但是能做更多的事情了呀~ \
\
 7. 不同层级有完全不同的工作内容，我现在还处于一线写代码的阶段，想进化，得观察下一个层级的人都在干什么。是合并周报还是思考未来？多看看吧~ \
\
 时间有点晚了，今天先瞎扯到这里~
