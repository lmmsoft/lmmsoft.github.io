# 前言

第一次参加骑行赛，成绩惨淡，失误连连，只完成了最低目标，一定要记录一下，大涨经验值~

![](/images/qzone/edbbd536a25ab6da25f9fa59.jpg)\

# 比赛原因，目的

6-4本来最想参加的比赛是泰州标铁，这是中铁协联赛，A级赛事，组织水平高，离苏州近。可惜报名人数限制，苏州ibike只有10个名额，我水平比较菜，在苏州排不上号，报上的都是速度比较快的选手，倒也公平。

\

遗憾之余，看到太湖边有骑行比赛，报名几乎是免费（10元保险，100元保证金，完赛退还），就在苏州，比较近，而且项目很全，有精英/大众/乐活/个人计时/团队计时。从来都没参加过大组赛，可以感受下比赛，就报了大众组合个人计时组。苏州铁三队的别克和我一样，泰州没报上，报了大众和个人计时，另外还有很多认识的骑行大神/苏州的骑友参赛，很兴奋能和这些高手同场竞技，看看差距有多大。

![](/images/qzone/033e4990f623841d002f7e48.jpg)\
 # 上午的大组赛 Criterium

我报的是男子大众组，选手比男子精英组弱些，和女子精英组一起，3.5km一圈，一共6圈。比赛开始，左脚上锁耽误了一些时间，出发不久的发卡弯拐弯还不太适应，启动慢了，然后后面的女选手就从身边超过去了，我追了一会儿，没追上，后来不断的掉队，一两圈之后发现前面两个大集团已经形成，我落后不少，彻底没了机会。三四圈基本上跟在一个上海链轮的女车手后面，发现前面的大集团也没跑太快，似乎不太会被套圈，估计都在留力等着冲刺吧。最后两圈一直有场外观众大喊“男选手帮女孩子领骑”，想想一直蹭女选手的分，也不好意思，就一直领了。中间两圈成绩平稳，最后一圈猛冲了一把，超了近十个选手。比赛的心率一直在170以上，最后的冲刺心率达到了192，这是平时训练从没有过，大组赛强度太大，虽然时间短，但过程还是比较痛苦的，不太喜欢。。。 \

# 下午的个人计时赛 ITT

下午报的个人计时赛，基本上上午参加精英组的大神都报了ITT和TTT，能和大神们同场竞技，机会难得。比赛一共3圈，10.5km，大神们都是很牛的TT车，外加前大刀后封闭轮，气场就很强。

![](/images/qzone/528958077ba7ab117bd8cc61.jpg)\

第一次从高台上发车，怕摔，起步比较慢，后来提速，第一圈还相对快一点，第二圈掉了不少速度，第三圈又追回一些。之前看了环意的ITT决赛，选手都是看着路上的线，不抬头，我还是不太敢，几秒钟就抬头一次。最后第一圈5:39 第二圈6:06，第三圈 5:50，总成绩17:35(+04:39.131) 排名全场56/61，差距很大很大，冠军ITT均速快要47了，我才33，实在是太弱了，比赛的折返湾太多，要不然冠军的速度应该能上50的。

# 比赛失误

1.[装备]大组和TT车的功率计都没电池了，导致比赛基本在盲骑，而且失去了重要的比赛数据，以供赛后分析

2.[装备]大组赛没带水壶，口渴难耐

3. [装备]TT车没带水壶，也没带码表坐，导致码表没地方放，手表的表盘也没翻到手腕上，导致比赛基本盲骑

4. [装备]没带心率带，只能用手表自带的光点心率，有两个问题，一是变化比较慢，大组赛骑了有5分钟心率还是110左右，太滞后了，后来才正常；二是心率广播的时候不会存储到24小时的数据了，失去了峰值数据

5.[安排]没早到赛场，观看相对精彩的男子精英组大组赛

6.[Social]没提前做好准备，现场认不出高手，失去了了social的好机会

7. [装备]下午比赛把墨镜忘在车子上了~

8. [备战]上午赛前几乎没热身，下午赛前完全没热身，连装备都没调好。相比场边自带骑行台热身的选手，差距真大呀~

![](/images/qzone/0b210da1cb451c01f26cbea1.jpg)\

# 比赛收获

给自己设立的比赛的最低目标是1和2，最后都完成了，但也没取到更满意的结果，中规中矩吧

1. 不受伤

2. 不被精英组女选手套圈

3.和顶尖业余选手差距很大，诸如冠军大组赛均速45km/h，我只有32，冠军ITT的官方均速是48.7我的ITT只有35.8，官方数据的距离长了，实际速度还要更慢一点。

4.有氧和无氧能力完全不同。我最近半年都在练大铁，95%以上的训练都是有氧，大部分以功率二区的的LSD为主，而大组赛需要很多无氧能力，出发之后为了跟上大集团，折返之后的追击，都需要无氧能力，而我这方面严重缺练，比赛过程痛苦不堪。本以为现在是我这几年体能状况最好的时候，这次比赛应该能看出自己的水平，比完才知道现在只能算是我有氧耐力最好的时候，肌耐力/爆发力都远远不行。
